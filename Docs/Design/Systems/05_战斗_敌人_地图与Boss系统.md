# 战斗、敌人、地图与 Boss 系统

- 文档版本：`0.1.0`
- 文档状态：初版正式模块
- 权威范围：战斗决策、敌人角色、刷怪、地图规则、目标和 Boss 设计边界
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)
- 相关模块：[局内核心循环](02_局内核心循环.md)

## 1. 战斗职责

本节状态：`ACCEPTED`

武器自动攻击，但玩家持续负责：

- 生存与输出位置；
- 角色技的释放方向和时机；
- 构筑选择；
- 经验、掉落和地图收益的收集路线；
- 地域目标与风险收益；
- 精英、中段危机和关底高潮。

战斗不设置所有角色共有的普通攻击键、通用闪避键或大量主动技能栏。角色可以通过自己的角色技
拥有突进、穿行或防御，但不把它们变成所有角色的相同保命方式。

## 2. 有限地图

本节状态：`ACCEPTED`

- 主要秘境采用有限手工地图；
- 地图边界必须由地形、交叠范围或地域规则解释；
- 中央安全路线与边缘高收益路线之间形成明确取舍；
- 地标、捷径和关底方向应能通过场景辨认，不只依赖小地图；
- 地图更换美术后仍应通过路线、目标、事件和敌人组合保持差异。

## 3. 地域目标

本节状态：`ACCEPTED`

- 每张主要地图至少拥有一个与当地历史和规则相连的地图目标；
- 目标可以是胜利条件，也可以是削弱关底、取得资源、救援、开启捷径或获得证据的可选内容；
- 可选目标不得伪装成不完成就无法公平通关的隐藏强制条件；
- 目标的完成影响必须通过场地、敌人、Boss 招式或奖励清楚可见；
- 唯一内容不能依赖无提示的极低概率掉落。

## 4. 敌人生态

本节状态：`ACCEPTED`

每张地图的敌人组合至少覆盖若干不同战斗职责：

| 职责 | 作用 |
|---|---|
| 群聚 | 建立密度、经验和基础走位压力 |
| 追袭 | 打破单一方向移动 |
| 阻路 | 改变路径并抵抗普通击退 |
| 远程 | 迫使玩家利用遮挡和改变位置 |
| 支援 | 要求识别优先目标 |
| 区域危险 | 形成延迟范围、地形或可反用的环境压力 |

敌人必须有可读前摇、轮廓和音效。真实居民、野兽与新脉生命不能只因外形陌生就成为可无限击杀的
基础敌人；大群优先使用脉影、器物和符灵等可复现形体。

## 5. 刷怪与压力曲线

本节状态：设计原则 `ACCEPTED`

- Encounter 由预设阶段、预算、组合、区域入口、随机种子和性能上限驱动；
- 不根据玩家当前伤害实时抬高敌人生命；
- 普通敌人默认在屏幕外或合法入口生成；
- 特殊伏击与固定入口必须有场景或规则提示；
- 后半段通过组合职责、空间和事件提高复杂度，不只增加生命与数量；
- 高频模拟继续遵守集中更新、对象池和性能预算。

## 6. 精英与中段 Boss

本节状态：`ACCEPTED`

- 精英是普通生态的强化变体或独立强敌，不只是随机属性倍增；
- 精英词缀必须有明显外观、前摇和提示；
- 中段 Boss 负责阶段转折、完整强敌教学或地图叙事；
- 配置中段 Boss 时，其败后必定提供一个显化宝匣；
- 中段 Boss 是否存在由地图内容文件决定。

## 7. 关底 Boss

本节状态：`ACCEPTED`

- Boss 必须有守住目标或进入战斗的具体理由；
- 击败 Boss 是取得处置权或达成胜利状态，不强制叙事死亡；
- 阶段提升优先增加招式组合、空间要求和目标变化，不以突然倍增生命制造难度；
- 关键攻击不能只依赖颜色提示；
- 地图可选目标对 Boss 的影响必须数据驱动且可观察；
- Boss 被判定击败后立即停止本局成长掉落并进入结算。

## 8. 地图与 Boss 内容文件

地图文件拥有：

- 胜败条件与目标时点；
- 地图拓扑、区域、入口、地标和捷径；
- Encounter 阶段与敌人引用；
- 地图目标、事件、首通和重复局结果；
- Boss 与地图目标的修正关系；
- 灰盒验证与观测项。

Boss 文件拥有：

- 身份、动机、是否可叙事存活；
- 阶段、招式、前摇、场地要求；
- 状态、免疫、掉落和结算事件；
- 表现、可访问性和验证。

两者通过稳定 ContentId 引用，不能在地图脚本中硬编码具体 Boss 类型分支。
