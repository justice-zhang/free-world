# 内容与技术边界

- 文档版本：`0.1.0`
- 文档状态：正式边界
- 权威范围：设计内容进入当前冻结框架前必须遵守的技术、Schema、资产和验证规则
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)
- 工程权威：仓库根目录 `AGENTS.md`、`Docs/ARCHITECTURE.md`、`Docs/CONTENT_SCHEMA.md`

## 1. 权威优先级

```text
用户当前明确指令
→ AGENTS.md
→ 已接受 ADR
→ ARCHITECTURE.md / CONTENT_SCHEMA.md
→ 正式设计总索引和系统模块
→ 具体内容文件
→ 非权威归档与原始大纲
```

## 2. 数据驱动要求

- 新角色不创建角色专用 Controller 子类；
- 新地图、敌人、Boss、器法和解锁不在核心程序集按具体 ContentId 分支；
- 存档只保存稳定 ContentId 和明确状态，不保存运行时索引或 Unity Object；
- 表现 Profile 不进入模拟真值；
- UI 不重新实现模拟规则；
- 新机制先检查现有模块组合，无法表达时提交 Change Request；
- 代码、Schema、作者数据、验证器、测试和文档保持一致。

## 3. 当前设计超出冻结框架的内容

正式实施前需要逐项评估并可能提交 Change Request：

- 角色技及统一输入通道；
- 行脉图节点、额度、配置和存档；
- 初始武器与初始心法引用及不可移除规则；
- 角色对公共器法的通用修正；
- 显化宝匣与普通升级候选分流；
- 多配方稳定随机显化和补偿表；
- 地图级胜败条件和统一结算触发；
- 可选地图目标对 Encounter 与 Boss 模块的修正；
- 首通、重复局、教程与候选保护；
- 灵砂、行脉点额度、角色阅历、脉标和公共内容解锁；
- 旧庭锚点、秘境通路与据点状态。

M10 已冻结公共 API，设计文档不授权直接绕过 Change Request、ADR、Schema 迁移、API 基线和测试。

## 4. ContentId

- 内容文件可以记录“预留 ContentId”，但在作者资产进入正式 Catalog 前标记为未发布；
- 一旦发布不得修改；
- ID 使用小写字母、数字、下划线和点号；
- 显示名称、本地化 Key 与 ContentId 分离；
- 模块化文件名可以调整，不能据此自动改写已发布 ID。

## 5. 资产边界

- 框架和灰盒阶段只使用程序化 Placeholder；
- 不复制或改造参考项目资产、代码、品牌或演示资源；
- 正式 AI 资源进入 `Assets/GameAssets/AI` 并登记 provenance；
- 第三方内容进入 `Assets/ThirdParty` 并登记许可证；
- 来源、商业权利或 Hash 不清时阻止 Release。

## 6. 验证真实性

任何完成声明必须使用：

- `PASS`
- `FAIL`
- `NOT RUN`

内容文件在进入实现前要拥有自己的验收门禁。修改 Schema、场景、输入、性能或构建门禁时，按
`AGENTS.md` 运行相应测试和实际构建，不以历史结果代替当前证据。
