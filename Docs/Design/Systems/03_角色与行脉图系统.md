# 角色与行脉图系统

- 文档版本：`0.1.0`
- 文档状态：初版正式模块
- 权威范围：角色组成、角色技、行脉图、本命器法关系
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)
- 内容目录：[正式内容目录](../Content/README.md)

## 1. 角色构成

本节状态：`ACCEPTED`

每名正式角色由以下内容组成：

| 组成 | 是否专属 | 是否进入局内随机池 | 是否占器法槽 |
|---|---:|---:|---:|
| 角色技 | 是 | 否 | 否 |
| 行脉图 | 是 | 否 | 否 |
| 本命武器关系 | 否，引用公共武器 | 开局直接携带 | 占正常武器槽 |
| 本命心法关系 | 否，引用公共心法 | 开局直接携带 | 占正常心法槽 |
| 角色与本命器法额外效果 | 是 | 否 | 否 |

“本命器法”只是角色与一对公共武器、公共心法的最佳适配关系，不是新的内容类型。

## 2. 角色技

本节状态：`ACCEPTED`

- 所有角色共用一个角色技输入通道；
- 具体角色技可以主动释放，也可以在蓄力完成后自动触发；
- 角色技不进入武器、心法或奇物随机池；
- 角色技不占武器、心法或奇物槽位；
- 被动差异优先进入行脉图，不把所有角色差异塞进角色技；
- 新角色技通过通用模块组合，不能要求创建角色专用 Controller 子类。

角色技必须改变即时决策、资源节奏或空间策略，不能只提供常驻伤害百分比。

## 3. 行脉图

本节状态：`ACCEPTED`

- 每名角色拥有独立行脉图；
- 全部节点最终均可解锁，不设置永久二选一删除；
- 玩家拥有有限激活点数，不能同时激活全部节点；
- 每套配置最多激活一个终端节点；
- 重置免费，不消耗洗点道具或货币；
- 行脉点逐步获得，不在新存档开始时一次给满；
- 节点可包含被动、角色技修正、公共标签修正和对本命器法的额外效果；
- 高阶节点可以改变器法形态、音效或行为，但不是每名角色都必须采用同等复杂度。

行脉点的账号归属与取得方式见[局外成长模块](06_局外成长_资源与青岚旧庭.md)。

## 4. 本命器法局内规则

本节状态：`ACCEPTED`

- 角色开局直接携带本命武器和本命心法；
- 两者占用正常槽位并从正常等级开始成长；
- 本命武器和心法不能替换、移除、封禁或在开局丢弃；
- 本命器法以外的槽位完全自由构筑；
- 本命器法仍使用公共配方和普通器法合鸣规则；
- 其他角色取得同一武器和心法时也能完成同一显化；
- 角色专属额外效果不能成为公共内容脱离该角色后正常运作的前提。

## 5. 角色内容文件的权威边界

每个角色使用一个独立内容文件。该文件拥有：

- 身份、性格和叙事立场；
- 角色技完整规则；
- 行脉图结构；
- 本命武器与心法的引用；
- 角色和公共器法之间的额外效果；
- 教学、UI、音画和验证要求。

角色文件不得重新定义公共武器、公共心法或合鸣结果；这些字段由对应公共内容文件拥有。

## 6. 首批待确定项

1. 行脉图标准节点数量与每层成本；
2. 行脉图账号进度与角色阅历的具体解锁曲线；
3. 角色技冷却、充能和自动触发的通用模块；
4. 角色选择界面的比较信息；
5. 首发角色数量与逐个内容方案。
