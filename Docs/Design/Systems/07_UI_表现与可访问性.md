# UI、表现与可访问性

- 文档版本：`0.1.0`
- 文档状态：基础信息要求正式，具体版式待定
- 权威范围：用户可见信息、关键反馈和可访问性边界
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)

## 1. 通用原则

本节状态：`ACCEPTED`

- UI 展示模拟结果，不重新计算候选、伤害、胜利或显化资格；
- 用户可见文本全部使用本地化 Key；
- 核心预警不能只依赖颜色；
- 重要状态同时使用形状、位置、动画或音效；
- 教学短促、可重看、重复局可跳过；
- 暂停、升级和结算期间的模拟冻结规则必须一致。

## 2. 角色选择

至少显示：

- 角色技名称、激活方式和基础效果；
- 本命武器和本命心法；
- 本命器法的合鸣结果；
- 当前行脉点额度和已激活终端节点；
- 角色玩法关键词与难度提示。

## 3. 局前地图信息

至少显示：

- 主要胜利条件；
- 失败条件；
- 目标时长或关底出现条件；
- 地域规则；
- 首通与重复局标记；
- 已知地图目标、Boss 和重要奖励；
- 尚未锚定或缺少条件的原因。

## 4. 战斗 HUD

至少支持：

- 生命与必要角色资源；
- 角色技可用、充能或自动触发状态；
- 局内等级与经验；
- 主要目标、阶段和计时；
- 武器、心法、槽位和等级；
- 器法合鸣条件进度；
- 地图目标和 Boss 模块状态；
- 不遮挡战斗的短促教学与解锁提示。

## 5. 升级与显化

升级候选至少显示：

- 名称、当前等级或新获得；
- 当前效果和升级后变化；
- 槽位类别；
- 配套器法与当前条件。

显化只展示随机结算后的最终结果：

- 原武器与配套心法；
- 显化名称和图标；
- 新增或改变的规则；
- 必要的形态、动画、特效和音效反馈。

## 6. Boss 与环境预警

- 同类危险使用一致的预警语法；
- 延迟范围需要边界、倒计时变化和声音；
- 锁定、推拉、残剑和安全区必须可区分；
- 玩家可以调节屏幕震动、闪光、伤害数字和高密度特效；
- 重要音频线索提供字幕、方向提示或可视化替代。

## 7. 仍需确定

1. 战斗 HUD 版式；
2. 键鼠与手柄完整映射；
3. 字号、对比度、色觉和动态效果档位；
4. 地图与路线标记；
5. 伤害统计和结算页；
6. 三声剑鸣的方向可视化辅助。
