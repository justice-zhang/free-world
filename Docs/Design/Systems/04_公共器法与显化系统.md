# 公共器法与显化系统

- 文档版本：`0.1.0`
- 文档状态：初版正式模块
- 权威范围：公共武器、公共心法、本命关系、器法合鸣、显化宝匣和升级候选边界
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)
- 内容目录：[正式内容目录](../Content/README.md)

## 1. 核心术语

本节状态：`ACCEPTED`

| 术语 | 正式含义 |
|---|---|
| 武器 | 用于自动战斗的公共攻击内容，占武器槽并可升级 |
| 心法 | 提供属性、条件强化或规则修正的公共内容，占心法槽并可升级 |
| 器法 | 武器与心法共同组成的构筑语法，不是额外物品类别 |
| 本命器法 | 某角色开局携带且与其角色技、行脉图最契合的一对公共武器与心法 |
| 器法合鸣 | 指定武器和指定心法均满级后，通过显化媒介把武器升级为新形态 |
| 显化宝匣 | 结算当前有效合鸣或提供有效补偿的局内媒介 |

世界观包装：

> 器有其性，法有其路；器法相合，真名显化。

## 2. 公共归属与独立价值

本节状态：`ACCEPTED`

- 所有武器和心法都是公共内容；
- 不建立角色专属武器池或角色专属心法池；
- 武器和心法脱离任何角色后必须具备完整基础价值；
- 没有组成配方时，武器和心法仍正常发挥自身效果；
- 角色可以通过角色技或行脉图改变公共内容的数值、触发、形态或表现；
- 这些角色额外效果不能写入公共内容的基础定义。

## 3. 槽位与升级

本节状态：边界 `ACCEPTED`，具体数字 `OPEN`

- 武器和心法使用相互独立的槽位；
- 新内容占用一个对应槽位，已有内容升级不再占槽；
- 满槽时不能提供无法加入的新内容；
- 满级内容不能继续获得普通等级提升；
- 标准槽位数、标准最高等级和每级数值尚未确定。

## 4. 固定合鸣配方

本节状态：`ACCEPTED`

每条基础合鸣配方至少包含：

- 基础武器 ContentId；
- 配套心法 ContentId；
- 两者需要达到的等级；
- 显化后的武器 ContentId；
- 规则变化；
- 表现 Profile 与本地化 Key。

基础条件：

```text
指定武器满级
+ 指定心法满级
+ 获得显化宝匣
= 该配方具备显化资格
```

基础游戏不包含二阶段显化或连续进化。显化必须增加或改变行为规则，不能只换名称、伤害倍率和
视觉资源。

## 5. 显化宝匣

本节状态：`ACCEPTED`

### 5.1 来源与结算时点

- 关卡若配置中段 Boss，该 Boss 必定掉落一个显化宝匣；
- 精英具有较低概率掉落显化宝匣，具体概率和保底尚未确定；
- 地图目标可以明确奖励宝匣；
- 以关底 Boss 为胜利目标时，Boss 被判定击败后立即结算，不掉落仅对本局有效的宝匣；
- 生存局达到胜利时点后立即结算，最终敌潮不强制掉落宝匣。

### 5.2 开启流程

```text
读取开启瞬间的构筑快照
→ 收集所有满足条件且尚未显化的配方
→ 有一条：完成该条
→ 有多条：使用本局稳定随机流随机选一条
→ 无有效配方：进入补偿表
→ 界面只展示最终结果
```

玩家不能在普通宝匣中从多条有效配方里直接选择最优解。高品质宝匣未来可以连续结算多次，但不
属于基础规则。

### 5.3 无合鸣时的补偿

补偿必须有效，候选方向包括：

- 提升已有且未满级的武器；
- 提升已有且未满级的心法；
- 治疗、护盾或复苏；
- 适用于当前构筑的局内资源。

补偿优先级和权重尚未确定。

## 6. 升级候选边界

本节状态：`OPEN`

当前只确定：

- 候选可以包含新武器、新心法、已有武器升级和已有心法升级；
- 本命武器和心法开局直接获得，不需要从随机池寻找；
- UI 只展示结果，不重新实现资格和权重；
- 没有有效普通候选时必须提供有效替代项。

待确定：

1. 每次展示数量；
2. 新内容和升级的基础权重；
3. 已有内容升级保护；
4. 配方另一半是否提高权重；
5. 刷新、放弃和局内封禁；
6. 局外封禁数量；
7. 地域权重和新内容保护；
8. 幸运的影响边界。

## 7. 内容文件权威边界

- 武器文件拥有基础行为、等级成长、标签和独立价值；
- 心法文件拥有基础效果、触发、层数和独立价值；
- 合鸣文件拥有配方、结果行为和表现变化；
- 角色文件只能引用这些 ContentId，并定义角色额外效果；
- 地图文件只能改变候选权重、来源或奖励，不能重新定义公共内容行为。
