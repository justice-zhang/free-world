# 局外成长、资源与青岚旧庭

- 文档版本：`0.1.0`
- 文档状态：首版资源方案待确认
- 权威范围：局外资源分类、取得与保留、解锁、行脉点、据点职责
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)

## 1. 设计目标

本节状态：边界 `ACCEPTED`

- 局外成长增加选择权、配置空间、内容和有限容错；
- 不使用无限永久攻击、防御或资源倍率；
- 不建立大量只服务单件武器或单张地图的碎片货币；
- 免费重置行脉图，不出售洗点道具；
- 失败不扣除已经结算或永久发现的资源。

## 2. 首版资源分类

本节状态：`PROPOSED`

首版只保留一种可消费通货、一个全局配置容量、一个角色进度记录和两类非消费解锁记录：

| 名称 | 类型 | 账号范围 | 是否消费 | 主要用途 |
|---|---|---|---:|---|
| 灵砂 | 通用软货币 | 全账号共享 | 是 | 一次性研习已发现的公共武器、心法和有限据点功能 |
| 行脉点额度 | 配置容量 | 全账号共享 | 否 | 决定每名角色当前可激活的行脉节点总成本 |
| 角色阅历 | 自动进度 | 每角色独立 | 否 | 解锁该角色的行脉节点、故事和挑战，不直接购买属性 |
| 脉标 | 世界里程碑 | 全账号唯一记录 | 否 | 记录主要秘境首通、锚定稳定通路并推进据点与主线 |
| 器谱与心诀录 | 内容发现记录 | 全账号共享 | 否 | 证明公共内容已经被发现，使其可在百器阁研习 |

藏品、行迹残页、图鉴和挑战记录属于收藏数据，不作为可消费资源。

## 3. 灵砂

本节状态：`PROPOSED`

### 3.1 来源

- 局内拾取和结算；
- 精英、中段 Boss、地图目标与关底胜利奖励；
- 首次发现和挑战的一次性奖励；
- 失败时保留本局已经取得的灵砂，不设置死亡扣款。

### 3.2 用途

- 已获得器谱或心诀录后，在百器阁进行一次性研习，使内容进入公共随机池；
- 解锁少量、固定层级、可封顶的候选控制和便利功能；
- 修复不影响战斗数值的据点展示或功能入口。

灵砂不得用于：

- 无限购买攻击、防御或资源倍率；
- 逐级强化某一件武器的局外伤害；
- 洗点；
- 抽取随机角色或随机内容；
- 购买主线脉标。

## 4. 行脉点额度与角色阅历

本节状态：`PROPOSED`

### 4.1 行脉点额度

- 行脉点额度由主线首通、重要脉标和账号级挑战逐步提高；
- 额度全账号共享，新解锁角色可以立刻使用当前账号额度，不必从零重复刷点；
- 每名角色各自保存行脉图配置，但不会永久消耗额度；
- 免费重置，最多激活一个终端节点；
- 最大额度有限，不能最终同时激活整张图。

### 4.2 角色阅历

- 使用角色完成或失败结算均可获得阅历，胜利与角色挑战提供额外奖励；
- 阅历解锁该角色行脉图中的可见节点、故事和挑战；
- 阅历不直接增加战斗属性；战斗效果只来自玩家实际激活的节点；
- 全部节点最终可解锁，但仍受共享行脉点额度限制。

这种结构让长期使用一名角色有内容进展，同时避免新角色因永久点数从零而无法参与当前难度。

## 5. 脉标

本节状态：`PROPOSED`

“脉标”不是背包中的消耗钥匙，而是青岚旧庭对一条稳定秘境通路的世界状态记录：

- 主要秘境首次通关后建立；
- 每个主要秘境最多一条首通脉标；
- 不能重复刷取、出售或消费；
- 用于开放稳定往返、据点区域、主线阶段和后续脉路；
- 具体地图可以先提供线索，完成对应胜利条件后才真正建立脉标。

## 6. 器谱、心诀录与公共内容解锁

本节状态：`PROPOSED`

```text
在地图、角色故事、挑战或势力关系中发现记录
→ 器谱或心诀录进入百器阁
→ 支付一次性灵砂完成研习
→ 对应公共内容进入账号随机池
```

- 本命器法在对应角色可用时必须随角色开局可用，不因尚未研习而阻塞角色；
- 完成研习后，内容对所有角色开放；
- 器法合鸣配方在玩家取得必要内容时显示条件，首次成功显化后记录完整图鉴；
- 不为每件武器设置独立碎片、熟练度货币和重复强化等级。

## 7. 胜败保留

本节状态：`PROPOSED`

| 数据 | 失败保留 | 胜利额外获得 |
|---|---:|---|
| 已拾取灵砂 | 是 | 胜利结算加成 |
| 角色阅历 | 是 | 胜利与角色挑战加成 |
| 器谱、心诀录、藏品和行迹发现 | 是 | 关底与首通限定发现 |
| 设置、图鉴与统计 | 是 | 完成统计 |
| 脉标 | 否 | 仅满足主要首通条件时建立 |
| 主线篇章和据点阶段 | 否 | 仅相应胜利条件完成后推进 |

青岚旧庭首通前失败时，资源先保存在存档中；由于据点尚未开放，玩家要在稳定旧庭后才能使用对应
设施。失败的主要代价是没有首通脉标、胜利加成和主线推进，不是删除已取得资源。

## 8. 青岚旧庭据点职责

本节状态：基础职责 `ACCEPTED`，设施名称与开放顺序 `OPEN`

旧庭只承担必要的局外闭环：

- 选择角色与行脉图配置；
- 选择已锚定秘境并查看胜利条件；
- 查看和研习公共器法；
- 查看角色故事、世界记录、图鉴与藏品；
- 接收新角色、势力人物和新脉生命；
- 通过场景变化展示脉标、路线和主线后果。

据点不是自由建造游戏，也不恢复传统青岚宗对天下的统治。

## 9. 仍需验证

1. 灵砂的平均局产出、研习价格和胜负加成；
2. 行脉点最大额度与主线发放节奏；
3. 角色阅历曲线和新角色追赶；
4. 器谱发现加灵砂研习是否产生不必要双重门槛；
5. 据点设施的首通开放顺序；
6. 挑战模式是否发放主进度资源。
