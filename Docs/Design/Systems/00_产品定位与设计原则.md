## 1. 产品形态

本节状态：`ACCEPTED`

《剑起青岚》是一款以 Windows PC / Steam 为首发平台、单人且可离线完成的清朗中国幻想俯视角
动作 Roguelite。战斗以 Survivors-like 的自动武器攻击、密集敌群、局内升级和构筑成型为基础，
以独立角色技、有限手工秘境、主动路线探索、角色行脉图和持续推进的世界叙事形成差异。

一句话定位：

> 玩家选择拥有独立角色技与行脉图的行脉者，从青岚旧庭进入不断显现的秘境，在移动、自动御器
> 和主动探索中运用公共武器、公共心法与战场奇物形成构筑、完成器法合鸣，并最终决定天下应当
> 恢复十二脉、永续封界还是接纳新生第十三脉。

## 2. 五层核心体验

本节状态：`ACCEPTED`

| 层级 | 玩家持续做什么 | 必须产生的结果 |
|---|---|---|
| 战斗 | 移动、自动攻击、角色技、躲避、控场 | 清晰且持续的即时判断 |
| 构筑 | 获得并升级武器、心法和奇物，完成器法合鸣 | 每局形成有取舍的战斗方案 |
| 探索 | 在有限地图中寻找地标、事件、目标和收集物 | 偏离安全路线获得明确收益 |
| 角色 | 使用角色技、配置行脉图、理解本命器法关系 | 更换角色即改变玩法逻辑和叙事视角 |
| 世界 | 处理秘境接触、带回人物、器法、证据和藏品 | 每局行动持续推进据点与主线 |

自动攻击不等于挂机。玩家始终负责移动、角色技、构筑、路线、地图目标和关底危机。

## 3. 设计支柱

本节状态：`ACCEPTED`

### 3.1 清朗且有生命力的中国幻想

- 可以有废墟、灾害和牺牲，但不以尸骸、末日感和持续压抑作为唯一情绪；
- 每个地域都要有草木、动物、季候、生活痕迹和继续生长的可能；
- 中国文化来源应进入建筑、器物、行为、关系和规则，不只停留在名词与纹样。

### 3.2 角色是玩法逻辑

每名角色至少由角色技、行脉图、本命公共器法关系和独立人物立场组成。角色差异不能退化为基础
属性皮肤，也不能通过建立角色专属随机池实现。

### 3.3 器法是公共构筑语法

- 武器说明“用什么手段战斗”；
- 心法说明“如何运转和强化力量”；
- 器法合鸣说明指定武器与心法如何显露新形态；
- 所有武器和心法脱离任何角色后仍要具备完整价值。

### 3.4 移动与探索都是战斗决策

地图边缘、危险区域和主要地标必须提供清楚收益。玩家可以选择较安全路线，但不能因一直停留在
开局附近而获得与主动探索相同的机会。

### 3.5 秘境差异进入规则层

新秘境不能只替换背景和敌人数值。空间、敌人生态、事件、目标、资源倾向和关底结构必须形成
灰盒状态下仍可辨认的差异。

### 3.6 局外成长增加选择权

局外成长提供角色配置、公共内容、候选控制、有限容错、故事、地图和据点变化；不以无限永久
攻击、防御或资源倍率替代局内判断。

## 4. 产品边界

本节状态：`ACCEPTED`

核心体验不依赖：

- 开放世界；
- 实时多人或 PvP；
- MMORPG 式随机装备词条和多层材料；
- 抽卡、付费数值、体力、日常任务或通行证；
- 自由宗门建造；
- 在线账户才能运行的核心内容；
- 大量通用主动技能按键；
- 无限永久属性成长。

## 5. 内容生产原则

本节状态：`ACCEPTED`

- 角色、器法、敌人、Boss、地图、事件和解锁通过稳定 ContentId 与作者数据接入；
- 新增正常内容不修改核心程序集；
- 表现资源可替换而不改变模拟真值；
- 用户可见文本使用本地化 Key；
- 正式资源的来源、许可证和 AI provenance 可审计；
- 现有模块无法表达的新机制先提交 Change Request；
- 每项正式内容必须具备明确体验目的、验证门禁和所属权威文件。
