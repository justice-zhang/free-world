## 1. 总循环

本节状态：`ACCEPTED`

```text
青岚旧庭整备
→ 选择角色并配置行脉图
→ 选择已经锚定的秘境
→ 明示本局胜利条件和地域规则
→ 战斗、探索、升级和构筑
→ 精英、中段危机、显化与地图目标
→ 关底高潮
→ 胜败结算
→ 返回旧庭，处理解锁、行脉图、藏录和下一条脉路
```

局内与局外必须形成同一闭环；叙事不能长时间打断战斗，局外成长也不能替代每局重新构筑。

## 2. 多种胜利条件

本节状态：`ACCEPTED`

标准局不统一限定为计时生存或击败 Boss。每张地图必须在出发前声明主要胜利条件。

| 基础类型 | 主要胜利条件 | 关底高潮 | Boss 使用方式 |
|---|---|---|---|
| 讨伐局 | 击败指定关底 Boss | Boss 战及其阶段变化 | 关底 Boss 必需；计时只推进敌潮、事件或出场 |
| 生存局 | 存活至规定时点或事件完成 | 最终敌潮、环境极值、守点或撤离 | 可以没有关底 Boss；中段和可选 Boss 不改变主要胜利条件 |

以后可以增加护送、封印、夺取、撤离或复合目标，但必须通过通用目标模块表达，并定义失败条件、
HUD 信息、结算时点和重复局规则。

## 3. 标准局共同阶段

本节状态：阶段职责 `ACCEPTED`，各地图时间与曲线由内容文件负责

| 阶段 | 共同职责 |
|---|---|
| 入境 | 明示目标、失败条件与地域规则 |
| 成形 | 让初始器法和首批升级形成方向，并观察附近路线 |
| 施压 | 引入敌人组合、精英、环境变化或地图事件 |
| 成熟 | 提供中段高压与显化机会，使构筑接近完成 |
| 高潮 | 以 Boss 或最终生存阶段检验构筑、角色技和路线选择 |
| 结算 | 停止本局成长奖励，记录首通、局外收益和解锁 |

阶段是体验职责，不要求所有地图使用相同分钟数或同一事件表。

## 4. 秘境入口与旧庭通路

本节状态：`ACCEPTED`

- 同一秘境可以拥有多个地方入口；
- 地方入口不稳定，其他势力无需经过青岚旧庭也能进入；
- 青岚旧庭位于青岚转枢共同边界，具有连通全部秘境的潜力；
- 每条稳定通路必须先取得入口、坐标、信物、知路者或相邻旧痕等脉路依据，再由旧庭完成锚定；
- 锚定后玩家从旧庭稳定出发并在结算时返回。

## 5. 首次通关与重复挑战

本节状态：`ACCEPTED`

- 主要秘境首次通关是唯一发生的主线事实；
- 重复挑战解释为余潮、邻近交叠面、深层或挑战抽象；
- 不统一使用时间循环，也不重复同一名角色的首次死亡与首次相遇；
- 首通和重复局可以共享地图与 Encounter 资产，但必须使用不同的叙事入口和唯一奖励状态。

## 6. 通用胜败规则

本节状态：部分 `ACCEPTED`

- 达成地图声明的胜利条件后立即切换结算，不继续发放只对本局有效的成长奖励；
- 关底 Boss 的“击败”是系统状态，不强制等同于叙事死亡；
- 玩家生命归零且没有可触发免死效果时判定失败；
- 失败不删除存档或已完成的唯一发现；
- 具体资源保留规则由[局外成长模块](06_局外成长_资源与青岚旧庭.md)统一定义。
