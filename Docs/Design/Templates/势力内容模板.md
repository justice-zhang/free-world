# 势力内容模板

- 内容名称：`OPEN`
- 文档状态：`OPEN`
- 共同体形态：`道门 / 宗派 / 城池 / 家族 / 行旅共同体 / 其他`
- 成立时代：`青岚之隐前 / 青岚之隐后 / OPEN`
- 根基地域：`OPEN`
- 上级规则：[世界观、势力与主线](../Systems/01_世界观_势力与主线.md)

> 先证明这个势力在世界里为何存在，再讨论它为玩家提供什么。现行技术 Schema 没有 Faction
> 内容类型；本模板不自动创建 `ContentId`、声望、商店或运行时阵营系统。

## 1. 一句话定位

用一句话说明它由什么人构成、从哪段历史中长出，以及真正要保护什么。

## 2. 起源与沿革

- 青岚之隐以前是否存在：
- 成立原因：
- 与青岚宗的旧关系：
- 青岚脉消失时失去了什么：
- 在十一脉时代又获得或创造了什么：
- 秘境重现以前的当前处境：

势力不能只因本作主线开始才突然成立。

## 3. 根基与日常

- 所在山川、城池或行旅范围：
- 主要成员与普通居民：
- 衣食、物产和延续组织所需的现实基础：
- 平日承担的责任：
- 如果这个势力消失，谁会先受损：

## 4. 传承与修行观

- 主要道统、技艺或生活方法：
- 如何取得和使用灵气：
- 如何理解人与天地的关系：
- 最看重的德行：
- 容易由这种德行滑向的偏执：

不得把势力只写成一种战斗职业或器法流派。

## 5. 组织形态

- 谁能成为成员：
- 谁拥有决定权：
- 山门、城中居民、附属者与外来者的关系：
- 组织内部如何处理异议：
- 能做到的事：
- 明确无权替谁作决定：

## 6. 真正要保护的东西

- 具体的人：
- 具体的土地、传承或生活：
- 不能轻易退让的底线：
- 愿意支付的代价：
- 不应被美化的既得利益：

## 7. 面对秘境与第十三脉

- 最初如何解释秘境：
- 秘境重现对它带来的机会：
- 秘境重现对它造成的威胁：
- 对复脉、续封和化脉分别可能出现的意见：
- 哪类事实足以改变内部判断：

三种终局意见必须能在组织内部出现，不能把组织直接等同于一种结局。

## 8. 内部矛盾

- 不同世代的分歧：
- 不同地域或身份的分歧：
- 理想与现实利益的冲突：
- 最可能造成分裂的事件：
- 即使站在对立面也仍然合理的观点：

## 9. 与其他势力的关系

逐项写明历史关系、现实依赖、公开矛盾和仍未偿还的旧债，不只写“友好/敌对”。

## 10. 表现锚点

- 建筑与生活痕迹：
- 标志性器物或共同记号：
- 衣着与材质方向：
- 礼仪、称谓和语言习惯：
- 不得使用的刻板符号：

## 11. 关键人物

- 能代表主流但不能代表所有人的人物：
- 公开反对主流的人物：
- 受组织保护却没有发言权的人物：
- 与青岚旧事有私人关系的人物：

## 12. 玩法映射

本节在世界观定案前保持 `OPEN`。后续可以讨论商人、据点设施、角色来源、局内事件、声望或解锁，
但玩法职责不得反过来改写势力的成立原因。

## 13. 验收条件

- [ ] 即使没有玩家和秘境商店，势力也有充分成立理由
- [ ] 名称符合其真实形态与自我认知，不像现代职能部门
- [ ] 有明确历史、根基、成员、传承与日常生活
- [ ] 青岚之隐让它既有损失，也可能有新的所得
- [ ] 真正保护的对象具体可见，不只是抽象口号
- [ ] 德行与偏执来自同一根源
- [ ] 内部能够形成至少两种有现实依据的意见
- [ ] 不替所有地方或整个封境垄断发言权
- [ ] 未提前绑定商店、内容解锁或未经批准的运行时系统
