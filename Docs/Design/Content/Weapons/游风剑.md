## 1. 公共定位

游风剑以弧线出剑、回锋归身，兼顾前方点杀和移动中的两次路径覆盖。它不要求使用陆青野，也不
依赖角色技才能运作；任何愿意持续走位、拉扯敌群的角色都能获得完整价值。

## 2. 基础行为

1. 冷却完成时选择有效范围内最近目标；无目标时沿角色当前朝向出剑；
2. 飞剑以可读弧线经过目标附近，去程对每个目标最多命中一次；
3. 到达最远点或持续时间结束后，飞剑返回角色当下位置；
4. 回程可以再次命中同一目标一次；
5. 多柄飞剑以扇形错开路径，不完全重叠；
6. 地形阻挡、视野外回收和目标死亡均使用通用投射物规则，不为陆青野写专用分支。

## 4. 八级成长

本节状态：`TUNING`

| 等级 | 变化 |
|---:|---|
| 1 | 解锁弧线出剑与回锋 |
| 2 | 基础伤害提高 |
| 3 | 飞剑数 +1，多剑扇形错开 |
| 4 | 飞行距离和判定宽度提高 |
| 5 | 冷却缩短 |
| 6 | 飞剑数 +1，去程穿透数量提高 |
| 7 | 基础伤害与回程速度提高 |
| 8 | “归鞘”：回程首次命中精英或 Boss 时追加一次小型风刃，不递归触发 |

具体百分比在战斗标尺和首关灰盒形成后调整。升级只增强公共武器本身，不引用具体角色。

## 5. 弱点与取舍

- 自动寻敌不保证覆盖玩家身后，玩家需要通过走位塑造回程路径；
- 多剑擅长线性和弧形覆盖，但不等同于全屏清场；
- 原地不动时仍可出剑与归鞘，只是路径利用率低于持续拉扯；
- 对高速散开的小目标可能产生空程，这是速度与范围构筑需要补足的缺口。

## 6. 实现与验收

- 用通用目标、投射物、回返、伤害和等级补丁模块组合；
- 回程目标为角色当前位置，不保存 Unity Object 引用；
- 高频路径不分配临时集合，不逐飞剑使用独立 `MonoBehaviour.Update`；
- 单柄、多柄、目标死亡、无目标、地图边界和低帧率下的回程均需测试；
- 正式表现资源只在灰盒通过后制作。
