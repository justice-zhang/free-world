# 正式内容目录

- 文档版本：`0.1.0`
- 上级索引：[正式游戏系统方案](../剑起青岚_正式游戏系统方案.md)

本目录采用“一项正式内容一份文件”。系统规则由 `Systems` 定义，本目录只描述具体角色、关卡、
器法、敌人、Boss 和反复登场的正式组织如何使用这些规则。

## 状态说明

| 状态 | 含义 |
|---|---|
| `ACCEPTED` | 已由当前讨论确认，可作为后续设计约束 |
| `PROPOSED` | 已形成可评审首案，仍允许在内容评审中修改 |
| `TUNING` | 仅为灰盒起测值，不能视为平衡结论 |
| `OPEN` | 尚无足够信息定案 |

文件中的预留 `ContentId` 只有在内容进入实现并通过内容验证后才成为发布 ID；发布后不得改名。

## 新增内容规则

1. 先复制对应模板，不在总索引中堆叠完整内容正文；
2. 明确系统依赖、稳定 ID、状态、公共价值、验收条件和未决项；
3. 新内容不能通过角色名、地图名或具体器法 ID 在核心代码中硬编码；
4. 现有模块无法表达时，先走 Change Request、ADR、Schema 和测试流程；
5. 势力必须先定义历史、根基、传承、所护之物与内部矛盾，再讨论商人、事件或解锁职责；
6. 各地本土与封境共同体须各自建档，不得共用一个虚构联盟；
7. 势力文档不自动创建运行时 Faction 类型、ContentId 或关系系统；
8. 正式资源制作必须晚于玩法灰盒，并满足来源、本地化和稳定 ID 规则。
