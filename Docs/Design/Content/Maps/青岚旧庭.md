## 1. 一句话体验

陆青野误入仍在执行最后闭庭剑令的青岚外庭，一边在持续敌潮中构筑，一边决定是否平复三处庭阵
剑印，最终穿过旧山门，击败守庭剑灵“听风”，把青岚旧庭稳定为连通各地秘境的大本营。

## 2. 已确定边界

本节状态：`ACCEPTED`

- 这是讨伐局；计时归零不等于胜利，击败听风才会结算；
- 关底开放目标时点 `T = 30:00`，听风战不计入 `T`，首通总时长预期略长于 30 分钟；
- 三处剑印全是可选优势，不是开门条件；
- 新存档不依赖局外数值、器法合鸣或剑印，也必须能够首通；
- 听风败而不灭，首通后成为旧庭守护者与据点 NPC；
- 第一关只确认最后剑令要求关闭旧庭仍维持的一处危险通口、听风从未收到解令、第三声不属于旧庭；
  它不在一关内完整解释封源事故、整脉为何移境或第十三脉。

## 3. 序章与入境

本节状态：`ACCEPTED`

1. 陆青野在青岚旧址附近避雨，听见第一声剑鸣，玩家获得移动控制；
2. 第二声由旧庭剑阵回应，云雾与断墙间短暂显出不应存在的纵深；
3. 第三声的音色和方位均不属于前两声，闭合旧路出现片刻入口；
4. 陆青野以为有人受困，自行跨过断墙；他不是被神器、血脉或天命选中；
5. 入境后开始正式计时，听风以剑阵示警，第一批守庭脉影出现。

## 4. 地图结构

本节状态：区域职责 `ACCEPTED`，尺寸与路线 `TUNING`

| 区域 | 职责 | 主要内容 | 路线要求 |
|---|---|---|---|
| 中央练剑场 | 开局和基础交战 | 开阔场地、练剑痕迹、草木脉影 | 至少三条出口，不形成永久安全绕圈 |
| 西侧药圃 | 恢复与持续风险 | 草木、恢复物、爆裂种囊、息风剑印 | 视野较窄，但必须有清晰撤离线 |
| 东侧藏剑廊 | 高风险构筑 | 残剑、剑架、练习飞剑、藏锋剑印 | 狭长但有外廊出口，不做死胡同 |
| 南侧迎客亭 | 远程压力与叙事 | 亭台、浅水、石灯、旧信、照客剑印 | 柱廊可遮挡，并有回中央捷径 |
| 北侧旧山门 | 主目标与关底 | 封闭山门、战前补给、听风战 | 开局可辨认，30:00 开放 |

中央与三个侧区均有直接通路，侧区之间另有外环或捷径。玩家探索时仍能持续战斗、获得经验并返回
主路线，不能用长空走廊换取奖励。

## 5. 三处庭阵剑印

本节状态：名称与职责 `PROPOSED`

剑印是青岚宗布置的守庭剑阵组成，不是天然灵脉的阀门。靠近后自动触发，不新增专用交互键。

### 5.1 息风剑印：逐风归息

- 位置：西侧药圃；
- 场地中依次出现三个沿固定短路线缓慢移动的“静风眼”；
- 玩家需在每个静风眼中累计驻留一段时间，离开只暂停该眼进度，不清零；
- 固定守印波、爆裂种囊与较差视野迫使玩家跟随安全区移动，而不是原地站桩；
- 平复后，药圃风势与音效立刻变缓；听风二阶段的风场推拉强度和持续时间明显降低。

灰盒起点：三个静风眼各累计 `8 秒`，挑战总长约 `45—60 秒`。

### 5.2 藏锋剑印：百剑归匣

- 位置：东侧藏剑廊；
- 挑战开始后，两侧剑架按可读顺序释放残剑，形成交替的直线封路；
- 守印精英“藏锋执剑影”会换位到发亮剑架附近，玩家需在躲避残剑时击败它；
- 精英败北后，散剑沿原路归架，狭廊恢复通行；
- 平复后，听风二阶段少一组环行残剑，且残剑存在时间缩短。

灰盒起点：挑战 `60—75 秒`，同一时刻最多两组剑架发射，始终保留一条可读通路。

### 5.3 照客剑印：灯照来客

- 位置：南侧迎客亭；
- 四盏石灯依次点亮，在柱廊与浅水间投出可识别的亮区和转移路线；
- 玩家需完成四轮守印，每轮在当前亮区中累计停留，并在灯灭前转向下一处；
- 石灯守卫与纸鹤从亮区外施压，但攻击不能把唯一转移路线完全封死；
- 平复后，听风二阶段的追踪剑印缩短锁定距离与追踪持续时间，预警轮廓也更稳定。

灰盒起点：四轮各 `10 秒`，转移窗口 `3 秒`，总长约 `55—70 秒`。

### 5.4 共同奖励与边界

- 每处平复时给予经验归拢和一次小型恢复，不直接提供永久属性；
- 三处全部平复后，旧山门前出现一次大型恢复与一个额外显化宝匣；
- 额外宝匣仍从全部有效合鸣中随机结算；没有有效配方时按普通补偿规则处理；
- 未平复的模块会在听风战前预览中明确显示，不能以隐藏百分比惩罚玩家；
- 任一挑战失败或离开区域不会导致整局失败，稍后可以重试。

## 6. 敌人生态

本节状态：`PROPOSED`

| 敌人 | 战斗职责 | 世界解释 |
|---|---|---|
| 草木脉影 | 低生命群聚 | 庭院生息痕迹被剑阵暂时唤起 |
| 纸鹤符灵 | 快速追袭 | 传讯纸鹤响应闭庭剑令 |
| 练剑木傀 | 抗击退阻路 | 外庭练习器具被守庭剑阵调用 |
| 石灯守卫 | 定点远程 | 迎客灯具承担照见与拒客职责 |
| 鸣风铃灵 | 支援强化 | 风铃替守卫报位并短暂催动剑阵 |
| 爆裂种囊 | 延迟区域危险 | 药圃植物因两界交叠产生防卫反应 |

第一关的大群以脉影、符灵和器物为主，不把大量持续人格的居民包装成无穷杂兵。导演只使用预设
阶段预算、组合和区域入口调度压力，不读取玩家即时伤害后动态抬高敌人生命。

## 7. 三十分钟时间轴

本节状态：`PROPOSED`

| 时间 | 事件 | 玩家预期状态 |
|---|---|---|
| 计时前 | 三声剑鸣、循声、跨墙 | 掌握移动，理解主动入境动机 |
| 00:00—04:30 | 草木脉影、自动攻击、首次升级 | 初始器法开始成长 |
| 04:30—10:30 | 纸鹤、角色技教学、地图与最近剑印、首只固定精英 | 开始主动选路和构筑 |
| 10:30—18:00 | 木傀、石灯，三个侧区全部开放 | 接触可选剑印和远近组合 |
| 18:00—21:00 | 试剑傀·折枝出现 | 获得必掉显化宝匣，构筑进入成熟期 |
| 21:00—27:00 | 铃灵、种囊与复合波次 | 完成器法和可选目标 |
| 27:00—30:00 | 最后闭庭，高压波次把路线导向北门 | 补给并确认关底模块 |
| 30:00 以后 | 旧山门开放，进入后开始听风战 | 计时不结算，胜利条件仍是讨伐 |

30:00 后不再生成唯一收集物或可无限获利的新波次。玩家未立即入门时只承受有上限的追击波与明确
引导，不使用瞬杀、强制传送或不可避免伤害。

## 8. 教学顺序

本节状态：`PROPOSED`

1. 序章教学移动与目标方向；
2. 首波教学自动武器、受击、经验与升级；
3. 第一组可读包围教学陆青野的“回风步”；
4. 首只固定精英前显示主目标、地图和最近剑印；
5. 折枝教学完整强敌、宝匣及合鸣结果；
6. 旧山门开放时列出三处剑印对听风的实际影响。

除移动和首次升级外，提示优先短促、非阻塞；重复挑战默认跳过序章与基础提示，可在设置中重播。

## 9. 胜败与首通

| 结果 | 叙事 | 系统 |
|---|---|---|
| 首通前失败 | 剑阵把失去战斗能力的陆青野逐出现世 | 返回入口；按局外资源规则保留已结算进度 |
| 首次胜利 | 听风确认封境自行重接，改守受控锚点 | 立即结算，建立青岚旧庭脉标，解锁据点与听风 NPC |
| 首通后失败 | 稳定锚点把行脉者带回旧庭 | 普通失败结算 |
| 重复胜利 | 旧庭余潮或剑阵复演 | 不重复唯一剧情，发放重复局奖励 |

最终 Boss 击败判定后立即结算，不掉落只服务已结束战局的显化媒介。

## 10. 验收条件

1. 新存档、零剑印、零合鸣仍能公平击败听风；
2. 玩家能说清胜利条件是讨伐听风，而不是等到 30:00；
3. 三个侧区均有收益、风险和安全返回路线；
4. 每处剑印改变一个肉眼和听觉都可辨认的 Boss 模块；
5. 首局自然升级本命器法时，有现实机会在关底前完成一次合鸣；
6. 首通只揭示规定的三项事实，不提前解释第十三脉；
7. 首通、失败和重复挑战的剧情与局外保留互不矛盾。
