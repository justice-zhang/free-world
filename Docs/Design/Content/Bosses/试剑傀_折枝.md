# 中段 Boss：试剑傀·折枝

- 文档版本：`0.1.0`
- 内容状态：`PROPOSED`
- 预留 ContentId：`base.enemy.zhezhi_trial_puppet`
- 所属地图：[青岚旧庭](../Maps/青岚旧庭.md)

## 1. 定位

折枝是被听风调用的外庭训练傀儡，不具备听风的人格或历史地位。它在约 18:00 出场，承担第一次
完整强敌教学、关底剑招语言预演和中段必掉显化宝匣三项职责。

## 2. 招式

- `横枝试剑`：明显抬臂后进行宽扇形横扫，要求玩家绕侧而非持续后退；
- `落木剑影`：预判玩家当前方向，在前方依次留下三道延迟剑痕，教学主动变向；
- `演武木桩`：召出少量固定木桩释放低频直线剑气，木桩可被击破，形成 Boss 与场地目标取舍；
- 每次只使用一个主招式；木桩存在时减少落木剑影频率，避免首个中段 Boss 过度叠压。

## 3. 结算

- 败后固定掉落一个显化宝匣，并触发一次大范围经验归拢；
- 宝匣立即按公共规则随机结算；没有满足条件的合鸣时提供有效升级、治疗或其他补偿；
- 折枝不产生唯一剧情死亡，也不在重复局中额外解锁主线状态。

## 4. 验收

- 玩家在不读文字时能分辨扇形、延迟直线和可破坏场地目标；
- 击败时间不会挤占处理剑印和完善构筑的主要窗口；
- 宝匣出现时，持续选择本命器法的新玩家有现实机会满足一次合鸣条件；
- 无有效合鸣时的补偿始终对当前状态有用。
