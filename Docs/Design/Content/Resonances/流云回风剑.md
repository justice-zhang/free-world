# 器法合鸣：流云回风剑

- 文档版本：`0.1.0`
- 内容状态：`PROPOSED`；数值 `TUNING`
- 预留 Evolution ContentId：`base.evolution.youfeng_sword_xingyun_jue`
- 预留结果 Skill ContentId：`base.skill.liuyun_huifeng_sword`
- 必需武器：[游风剑](../Weapons/游风剑.md)满级
- 必需心法：[行云诀](../HeartMethods/行云诀.md)满级
- 显化媒介：显化宝匣按公共规则随机选中

## 1. 真名与意象

“器有其性，法有其路；器法相合，真名显化。”游风剑原本只知出而复返，行云诀使它记住持有者
刚刚走过的路；显化后，飞剑循流云旧迹回锋，因此真名为“流云回风剑”。

## 2. 显化行为

1. 保留游风剑的自动寻敌、弧线去程和多剑成长；
2. 飞剑抵达最远点后，不直接沿最短线归身，而是取得玩家最近一段有效移动轨迹；
3. 飞剑从轨迹末端向前一段一段回溯，在拐点留下短暂、可读的流云剑痕；
4. 每个敌人受飞剑实体和同一轮剑痕的命中次数均有上限；
5. 最近没有足够移动轨迹时，退化为强化的普通回程，不让静止角色失去武器；
6. 行云诀保留原有效果，显化武器的合法释放也可以正常消费行云层数。

## 3. 公共价值

- 任意角色都能用自身走位塑造回程覆盖，不依赖陆青野的回风步；
- 弯折路线提高对密集敌群的区域覆盖，但路径有限长，不形成全图追踪；
- 静止或狭小 Boss 场仍有强化普通回程，不成为特定地图废件；
- 陆青野的“剑循旧路”只额外调用这套公共行为，不改变其基础定义。

## 4. 视觉与声音语言

本节状态：`PROPOSED`

- 去程保持清晰单剑轮廓，回程才展开淡青色流云剑痕；
- 轨迹拐点以短促风铃音提示，不用持续高亮淹没敌方预警；
- 剑痕伤害范围与视觉宽度一致，低特效档仍保留边界线；
- 陆青野使用时可以追加角色专属收剑音，但不能改变公共判定。

## 5. 显化与结算边界

- 只有游风剑与行云诀都满级时进入有效候选；
- 宝匣从当时所有有效合鸣中随机选一项，界面只展示最终结果；
- 显化替换游风剑，不消耗或移除行云诀；
- 胜利已触发时不再生成只用于本局的显化宝匣；
- 特殊高品质宝匣未来可多次结算，但不是本内容的基础规则。

## 6. 实现与验收

- 最近移动轨迹使用固定容量模拟缓冲，不在高频路径创建临时列表；
- 路径采样、简化、最大长度、拐点数和同目标命中上限必须可配置且有硬上限；
- 测试静止、短路径、折返路径、传送、回风步、地图边界和大量敌人；
- 与陆青野以外角色组合时仍能完成完整循环；
- 正式实现前确认当前 Skill/Evolution 模块能否表达轨迹回放，否则提交 Change Request。
