# 角色：陆青野

- 文档版本：`0.1.0`
- 内容状态：叙事身份与本命器法关系 `ACCEPTED`；角色技和行脉图首案 `PROPOSED`；数值 `TUNING`
- 预留 ContentId：`base.character.lu_qingye`
- 系统依据：[角色与行脉图](../../Systems/03_角色与行脉图系统.md)
- 本命公共器法：[游风剑](../Weapons/游风剑.md) + [行云诀](../HeartMethods/行云诀.md)
- 合鸣结果：[流云回风剑](../Resonances/流云回风剑.md)

## 1. 角色定位

本节状态：`ACCEPTED`

陆青野是一名普通游历者，不属于青岚宗，也没有被血脉、神器或天命选中。他因听到三声剑鸣，
误以为旧址内有人受困，凭自己的判断进入青岚旧庭。第一关后，他选择继续追查各地秘境的重现，
由行动而非出身成为故事的第一名行脉者。

## 2. 玩法辨识度

本节状态：`PROPOSED`

关键词：`主动走位`、`记录路线`、`回走成锋`。

陆青野把玩家刚刚走过的路线变成攻击和控制。他擅长在敌群中画出一条可返回的路，但没有完整
无敌位移；错误路线仍会受到投射物、地形和 Boss 攻击惩罚。即使换用完全不同的公共器法，他也会
因为“回风步”和行脉配置而保持辨识度。

## 3. 角色技：回风步

- 预留 ContentId：`base.skill.huifeng_step`
- 激活方式：统一角色技键主动释放，可再次按键提前结束
- 基础职责：位移规划、路径伤害、轻控制

### 3.1 基础流程

1. 首次按键进入短暂“录迹”，记录角色实际可通行的移动路径；
2. 录迹期间提高移动速度，但不提供完整无敌、穿墙或解除控制；
3. 再次按键或持续时间结束时，陆青野立即恢复正常移动；
4. 一道回风剑痕从结束点沿记录路径反向走到起点，命中的每个敌人受到一次伤害和轻微击退；
5. 冷却从回风释放时开始，而不是从首次按键开始。

录迹期间接触普通杂兵不会中断路线，但接触伤害、投射物、精英、Boss 和地图危险仍按正常规则
结算。路径被地形截断时只记录真实移动距离，不能隔墙产生回风。

### 3.2 灰盒起测值

本节状态：`TUNING`

| 参数 | 起测值 |
|---|---:|
| 最长录迹时间 | 2.5 秒 |
| 录迹移动速度 | +30% |
| 冷却 | 14 秒 |
| 回风宽度 | 1.6 米 |
| 同一目标命中 | 每次释放最多 1 次 |
| 击退 | 轻，不打断 Boss |

基础伤害采用角色技统一系数，待战斗标尺建立后再给绝对值。

### 3.3 独立价值与失败保护

- 没有游风剑或行云诀时，回风步仍有明确的路线调整、群体伤害和轻控价值；
- 没有记录到有效距离时，释放一个很短的身边回风，不吞掉输入且不制造高额伤害；
- 暂停、升级和阻断模拟的演出期间，录迹时间与冷却都冻结；
- 自动瞄准不会替玩家决定路线，角色技保留主动决策意义。

## 4. 与本命公共器法的额外效果

本节状态：`PROPOSED`

- `行随云起`：回风步录迹期间的实际移动距离，按 `150%` 计入行云诀的蓄云距离；
- `剑循旧路`：结束回风步时，若持有游风剑或流云回风剑，额外唤出一柄 `70%` 效果的剑沿本次
  回风路线运行；它不占用武器正常冷却，也不消耗行云层数；
- 额外效果属于陆青野的角色 Trait，不改变游风剑、行云诀和流云回风剑在其他角色手中的规则；
- 因本命器法固定占正常槽，这组协同每局可用，但仍需正常升级才能合鸣。

百分比是灰盒起测值。若一次技能同时触发多个追加武器，只允许本条指定的游风剑响应一次，避免
通用重复链无限递归。

## 5. 行脉图首版骨架

本节状态：`PROPOSED`

全图节点最终都可被角色阅历解锁，但每套配置受账号行脉点额度限制，并且最多激活一个终端节点。
重置免费。节点效果必须通过通用 Trait、Modifier 和 Effect 模块表达。

```text
听风辨路
├─ 逐风线：轻履 → 长息 → 借势 → 终端「长风在野」
├─ 回锋线：锐响 → 宽痕 → 借剑 → 终端「风回两度」
└─ 拾野线：携尘 → 护行 → 归息 → 终端「一路生青」
```

| 节点 | 首版效果方向 |
|---|---|
| 听风辨路 | 根节点；显示本次回风路径与剩余录迹时间，不提供隐藏战斗倍率 |
| 轻履 | 小幅提高录迹期间移动速度 |
| 长息 | 延长可记录时间，同时限制最大路径长度防止无限延伸 |
| 借势 | 达到最低记录距离时小幅返还回风步冷却 |
| 长风在野 | 终端；释放点追加一次强推风环，返还量随有效路径增长但有上限 |
| 锐响 | 提高回风路径伤害 |
| 宽痕 | 增加路径命中宽度，不延伸视觉以外判定 |
| 借剑 | 提高“剑循旧路”追加剑效果；换掉本命器法时转换为通用回风伤害提升 |
| 风回两度 | 终端；反向回风结束后，一道较弱剑痕再沿原路正向返回 |
| 携尘 | 回风经过时吸引附近经验与普通掉落 |
| 护行 | 有效路径达到阈值后获得短时小额护盾 |
| 归息 | 回风命中足够数量目标时获得一次有限恢复，单次释放有上限 |
| 一路生青 | 终端；路径上留下少量短时青息点，首次经过时恢复，敌我都不能反复触发 |

三条线分别强化移动控制、攻击回路和容错续航。终端节点改变玩法节奏，但不能把角色技变成无敌
逃生键、无限治疗或只对本命器法有用的死分支。

## 6. 首版角色内容边界

- 基础数值倾向中等生命、中高移动速度，不靠初始攻击倍率制造身份；
- 开局游风剑和行云诀占用正常武器、心法槽，不能替换、封禁或移除；
- 角色技不进入升级候选，不占器法槽；
- 角色解锁方式、人物支线、外观和语音属于 `OPEN`；
- 正式实现前需要角色技引用、初始心法引用、行脉配置和存档字段的 Change Request。

## 7. 验收条件

1. 不装备其他移动器法时，玩家仍能通过路径形状表达熟练度；
2. 换掉本命之外的全部构筑，陆青野仍与其他角色有明显玩法差异；
3. 游风剑、行云诀和合鸣结果交给其他角色时仍各自成立；
4. 回风步没有完整无敌、穿墙、无限冷却返还或无限追加触发；
5. 三个终端分别形成位移、伤害和续航取向，且一次只能激活一个。
