# Change Request：通用状态查询、消费与引爆事务

- 编号：CR-2026-006
- 状态：Approved
- 提交日期：2026-08-04
- 提交人：Codex
- 目标里程碑：G0.3、G1.4、G1.5
- 关联 ADR：ADR 0013、ADR 0014；对应 Demo CR-03

## 1. 变更摘要

扩展模块操作数，使 Trigger/Condition/Targeting/Effect 能按稳定状态或标签查询层数、消费状态并在触发位置引爆，形成可复用且原子的状态协同事务。

## 2. 触发场景

- 用户或设计需求：技能按目标状态层数增伤、消费层数，并在击杀或到期位置产生范围效果。
- 当前限制：模块参数缺少稳定内容引用操作数、状态计数查询和 `TriggerPosition` 上下文。
- 可复现示例：先读后写分散在多个系统时，同 Tick 多次命中会重复消费同一层状态。

## 3. 现有模块为何不足

现有状态效果能施加/到期，但通用 Condition 和 Effect 无法以稳定 ID/Tag 引用、计数和事务消费；硬编码具体状态不允许。

## 4. 提议方案

- 新增或修改的模块：Condition 状态查询、Effect 消费/引爆、Targeting 触发位置。
- 公共 API：只读状态计数查询、原子消费结果和带位置的 Trigger Context。
- 数据结构：Schema 6 模块操作数支持稳定 ContentId/Tag 引用与消费策略。
- 注册方式：新操作码显式注册，加载期解析为紧凑句柄。
- 编辑器工作流：校验引用 kind、最大层数、消费量和缺失目标行为。

## 5. 影响分析

| 领域 | 影响 |
|---|---|
| Assembly 依赖 | Simulation 内部单向调用 Status Runtime |
| Content Schema | Schema 6 扩展模块操作数 |
| Save Schema | 无影响 |
| Addressables | 无影响 |
| 性能 | 加载期绑定；热路径不做字符串查询 |
| 测试 | 同 Tick 原子消费、标签查询、位置、击杀/到期边界 |
| 平台 | 无影响 |
| 资产与许可 | 无影响 |
| 兼容性 | 旧操作数保持原 wire 语义 |

## 6. 备选方案

为每个状态组合新增专用 Effect 实现更快，但不可复用且会持续膨胀注册表，因此拒绝。

## 7. 迁移与回滚

- 迁移步骤：Schema 6 增加可选操作数；旧模块按缺省“无状态条件”读取。
- 旧数据处理：Schema 1—5 参数不重解释。
- 回滚步骤：先删除新内容引用，再移除操作码和上下文字段。

## 8. 验收标准

- [ ] 两组不同状态协同 Fixture 使用同一模块
- [ ] 消费与引爆在同一确定性事务内
- [ ] 自动测试覆盖竞态、零层和无效引用
- [ ] 热路径零字符串查找和临时集合
- [ ] ADR、Schema、API Freeze 已更新
- [ ] 旧内容 Golden Fixture 不变
