# AI_ASSET_POLICY

## 目标

确保后续 AI 生成的角色、场景、特效、图标、音频和其他表现资源具有可追溯来源、人工质量控制和商业发布审查记录。

## 适用范围

- 概念图

- 角色与敌人立绘

- Sprite、贴图、材质输入

- 场景和 UI 视觉

- VFX 贴图与序列帧

- 音频、语音和音乐

- 文案和本地化辅助输出

## 强制要求

- 每个正式资源有唯一 AssetId。

- 每个资源有 provenance.json 或等价数据库记录。

- 保存提示词、工具、模型版本、生成日期、输入引用和人工修改。

- 保存最终文件 SHA-256。

- 由人工确认商业使用、相似性、内容安全和平台披露状态。

- 上线前按当时最新平台规则复核。

## 禁止

- 使用无权使用的参考图。

- 使用参考开源项目素材作为生成输入。

- 生成或保留明显模仿知名角色、商标或界面的内容。

- 缺少记录时标记为 Release。

- 用 AI 生成字体替代有明确授权的字体。

- 将模型输出直接视为可发布成品，跳过人工修整。

## 构建门禁

Release 构建必须阻止：

- placeholder

- development-only

- provenance 缺失

- Hash 不一致

- commercialUseReviewed 不为 true
