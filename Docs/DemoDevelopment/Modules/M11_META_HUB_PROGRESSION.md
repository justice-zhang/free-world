# M11 据点、行脉、嵌片、收藏与故事

## 1. 目标与经济边界

据点只提供选择权、内容解锁、信息和有限容错，不形成永久攻击/生命无限叠加。Demo 只有灵砂一种
可重复消费资源；山河脉印是一次性关键进度，不是可刷货币。依赖 CR-09。

## 2. 四个设施

| 设施 | Demo 功能 | 解锁 |
|---|---|---|
| 问脉台 | 地图/出发、风脉台与脉印信息 | 初始可用 |
| 藏卷楼 | 3 篇故事与断衡线索 | 首次故事触发 |
| 百器阁 | 武器/心诀/显化图鉴与封存配置 | 首次升级后 |
| 万象阁 | 6 藏品、3 专题、敌人/Boss 记录 | 首次获得藏品后 |

设施不是自由建造；状态为 Locked/Available/Visited/Updated，UI 由 Profile 快照投影。

## 3. 陆青野行脉图

12 节点分三支，每支 4 个；最多同时激活 6 节点和 1 个终端，免费重置。具体数值在 G0.4 平衡表锁定。

| 分支 | 设计方向 | 示例通用输出 |
|---|---|---|
| 本命 | 游风剑/乘风亲和、构筑控制 | 起始标签权重、机制阈值小幅调整、终式资格 |
| 身法 | 移动宽容、路线、受伤恢复 | MoveSpeed、受击后短时保护、拾取范围 |
| 心性 | Reroll/Banish/信息与风险选择 | 候选次数、地标提示、失败保留上限 |

禁止节点无条件、无限累积地增加 Damage/Health。终端节点互斥，重置只改变 Loadout，不退回已花灵砂
或由产品规则明确全部免费；两者必须在 G0 锁定。

## 4. 剑匣嵌片

Demo 有 3 枚，开放 2 个槽：

| 嵌片 | 方向 | 限制 |
|---|---|---|
| 青岚风纹片 | 攻势：移动/风势亲和 | 不保证游风剑候选 |
| 药圃生春扣 | 护行：恢复/灵物效率 | 有总恢复/护盾上限 |
| 旧庭寻脉针 | 探寻：地标/候选控制 | 不直接揭示唯一藏品精确位置 |

嵌片通过稳定 Definition 输出 Trait/候选权重/地图信息规则；不在 UI 写 Modifier。装配在开局快照冻结，
局中不能换装。

## 5. 故事、藏品和专题

故事：山脚听剑、旧剑与酒葫、不认传承。触发顺序必须稳定；第三篇固定在首次击败听风后。跳过演出
只跳表现，不跳过已满足的 Profile 解锁事务。

六件藏品组成三专题：止衡剑庭、沈停云线索、旧庭生活。正式名称/文案由叙事任务锁定；获得方式必须
可追踪、首局指定内容有保底，不用极低概率唯一掉落。

## 6. Profile 模型（CR-09 输入）

建议保存：

- `currencies[spirit_sand]`；
- `unlockedContentIds`：设施、节点、嵌片、故事、藏品、脉印；
- `metaUpgrades`：节点解锁等级，不保存运行时索引；
- `activeMetaLoadoutIds`：6 节点、1 终端、2 嵌片；
- `firstClearMapIds`、`claimedUniqueRewardIds`；
- 可审计统计：Runs/Wins/Deaths/BossKills/Landmarks。

现有 Profile 没有 Active Loadout/FirstClear 专用字段。可否用现有稳定 ID 集合无损表达须在 CR-09 审核；
若扩 Save Schema，必须提供 v2→新版本迁移和旧存档 Fixture。

## 7. 失败与首通

失败保留已取得灵砂、合法藏品、已触发故事和统计；脉印、第三故事、首通设施进度只在胜利事务写入。
重复胜利不得重复唯一奖励，但可以提供灵砂/普通收藏保底替代。

## 8. 测试与验收

| 类型 | 必须覆盖 |
|---|---|
| Validation | 12 节点拓扑、成本、互斥、输出、设施/故事/藏品引用 |
| EditMode | 6＋1＋2 容量、免费重置、非法/缺失 ID 降级 |
| Save | 新旧迁移、主/备份、首通幂等、失败/重复规则 |
| UI PlayMode | 四设施、节点/嵌片装配、手柄导航、重置确认 |
| Extension | 新角色行脉/新嵌片不修改核心程序集 |

退出条件：局外成长改变选择和信息而非碾压；所有永久内容可验证、可迁移、可重置且由稳定 ID 保存。
