# M08 青岚旧庭地图、目标、事件与地标

## 1. 地图布局

青岚旧庭为大型有限手工地图，五个子区域通过至少两条可绕行通道连接：

| 区域 | 战斗功能 | 内容 |
|---|---|---|
| 中央练剑场 | 开局/中段 Boss/路线汇合 | 宽阔基础区、演武木桩锚点 |
| 西侧药圃 | 生长区域/狭窄通道 | 药圃复苏、异种地标 |
| 东侧藏剑廊 | 直线/折角走廊 | 旧剑共鸣、封存匣 |
| 北侧旧山门 | 最终 Boss 主场 | 听风台/门前开阔区 |
| 南侧迎客庭 | 教学/恢复/叙事 | 迎客亭旧信、风脉旧碑 |

地图必须有清楚地标和回路，不能用隐形墙制造假探索。普通敌人使用 Steering/轻量障碍规避；
障碍烘焙为有限矩形或获批通用几何代理。

## 2. 地图目标状态机（CR-06）

```text
Hidden → Revealed → Available → Activating → Defending → Completed
                                    └→ Interrupted/Available
Any invalid content → DisabledWithError
```

交互期间玩家可移动并继续战斗。目标完成依据区域击杀/防守/护送等通用条件，不要求长按站桩。
状态、进度、锚点、激活者和奖励只存在纯运行时；Scene 只提供显式锚点/表现绑定。

## 3. 三座风脉台

| 目标 | 激活玩法 | Run 输出 | 对听风的稳定修正 |
|---|---|---|---|
| 听风台 | 在真实/假剑鸣中防守并辨认正确脉息 | `altar.listen.completed` | 移除/削弱遮蔽风场与假剑鸣 |
| 引风台 | 引导风流穿过若干区域击杀/节点 | `altar.guide.completed` | 减少残剑上限、扩大安全路线 |
| 止衡台 | 在衡律压制区持续移动完成击杀 | `altar.stop_balance.completed` | 延缓交叉风痕、削弱旧誓强化 |

每座目标输出稳定 Modifier/Rule ID，不直接写 Boss 私有字段。BossPhaseRuntime 在 Run 装配时注册可接收
的目标修正；未知修正必须验证失败或结构化忽略，不能字符串猜测。

## 4. 三个动态事件

| 事件 | 触发窗 | 玩法 | 奖励 |
|---|---|---|---|
| 风脉暴动 | 6:30 后固定/候选锚点 | 移动风带改变路线并强化风系敌群 | 灵砂、事件记录、奇物权重 |
| 药圃复苏 | 探索西区＋条件 | 在生长区击杀/护持灵植 | 即时灵物、藏品/地标线索 |
| 旧剑共鸣 | 探索东区＋武器/击杀条件 | 残剑周期响应玩家攻击 | 武器升级/故事线索/灵砂 |

事件选择使用独立 MapEvent RandomStream。Demo 承诺三个事件存在，但单局是否全部出现必须在 G0 锁定；
建议首局至少保证一个、重复局从其余事件中抽取，以验证重玩。

## 5. 五个地标

地标状态：Undiscovered→Discovered→Claimed。发现可由距离/视线代理，领取可要求短交互或区域清理。

| 地标 | 主要产出 | 唯一规则 |
|---|---|---|
| 风脉旧碑 | 断衡背景、灵砂 | 文本首次解锁，资源可重复 |
| 藏剑封存匣 | 百器遗珍/武器线索 | 唯一藏品有保底 |
| 药圃异种 | 灵植异种/即时灵物 | 不被聚灵葫芦远程吸取 |
| 断墙剑痕 | 青岚剑道/故事进度 | 固定发现记录 |
| 迎客亭旧信 | 沈停云线索/人物旧物 | 固定故事触发 |

唯一藏品不得使用极低概率掉落；未命中首次指定藏品时使用可追踪保底计数或固定位置。

## 6. Anchor 与 Scene 契约

每个 Anchor：稳定 ID、二维模拟位置、用途标签、允许 SpawnPattern、表现 Transform 引用。Bake 时验证
ID 重复、位置有限、位于 Walkable、目标/事件引用存在。运行时只保留纯值位置和 ID。

## 7. Boss 修正组合

三座风脉台有 8 种完成组合。每种组合必须得到确定 Boss 参数快照，未完成不等于任务失败，但对应
规则更强。目标影响规则、上限或节奏，不直接按百分比削掉 Boss 当前生命，避免最佳路线变成唯一答案。

## 8. 测试与验收

| 类型 | 必须覆盖 |
|---|---|
| Validation | 5 区、Anchor、目标/事件/地标引用、Walkable |
| EditMode | 目标状态转移、防重复、事件 Seed、地标幂等 |
| EditMode | 8 组风脉台→Boss Modifier 快照 Golden |
| PlayMode | 目标期间可移动/战斗；导航和提示可读；事件清理 |
| Save/Result | 完成/发现集合进入 RunResult，首通合并正确 |
| Performance | 目标/事件无逐对象 Update；区域实体有上限 |

退出条件：地图不是背景图，三个目标真实改变 Boss，探索同时提供战斗、局外或叙事收益。
