# 00 Demo 范围与验收基线

## 1. 产品目标

Demo 是完整版第一章“青岚旧庭”的可发布垂直切片。玩家必须能从标题界面完成角色/地图选择、
约 12 分钟战斗、最终 Boss、结算、据点、存档和再次出发。它验证的不只是战斗原型，还包括：

- 移动御器的差异化手感；
- 三条可辨认构筑路线；
- 地图目标真实改变 Boss；
- 胜败与首通的局外闭环；
- 正式资产、本地化、输入、可访问性和发布门禁。

## 2. 固定数量口径

| 内容 | 数量 | 口径 |
|---|---:|---|
| 角色 / 地图 | 1 / 1 | 陆青野 / 青岚旧庭 |
| 本命器 / 公共武器 | 1 / 5 | 共 6 条武器成长线 |
| 公共心诀 / 显化 | 6 / 6 | 每把武器一条标准显化，本命器额外联动乘风 |
| 普通敌人 / 精英词缀 | 6 / 4 | 词缀需通用组合，不复制四套敌人 |
| 中段 / 最终 Boss | 1 / 1 | 6:00 与 12:00 后 |
| 即时灵物 / 战场奇物 | 6 / 6 | 前者立即消费，后者改变本局规则 |
| 风脉台 / 动态事件 / 地标 | 3 / 3 / 5 | 地图目标、动态规则、探索叙事 |
| 唯一藏品 / 故事 | 6 / 3 | 首通固定奖励不得受幸运影响 |
| 行脉节点 / 剑匣嵌片 | 12 / 3 | 最多激活 6 节点、1 终端、2 嵌片槽 |
| 据点设施 | 4 | 问脉台、藏卷楼、百器阁、万象阁 |

## 3. 体验闭环

```text
首次启动
→ 标题 / 设置 / 新档
→ 陆青野 / 青岚旧庭
→ 12 分钟移动、升级、探索、风脉台、事件和精英
→ 6:00 折枝 / 显化宝匣
→ 12:00 停止普通刷怪 / 听风三阶段
→ 胜利或失败结算
→ 保存灵砂、合法收藏、故事、脉印与首通状态
→ 旧庭据点选择行脉和嵌片
→ 再次出发验证重复通关
```

暂停、升级、剧情和结算只暂停 `SimulationClock`；UI 与表现时钟继续工作。失败不清除本局已合法
取得的局外资源，但局内武器、心诀、奇物、状态和临时目标状态必须销毁。

## 4. 目标构筑

| 构筑 | 最低组成 | 可读性目标 |
|---|---|---|
| 移动御剑 | 游风剑＋踏风步＋乘风相关奇物 | 真实移动提高输出，贴墙和暂停不积累 |
| 符阵爆发 | 镇邪黄符＋清心诀＋印记/引爆强化 | 叠印与爆发窗口清楚，Boss 不被无限控制 |
| 草木铺场 | 灵藤种＋采灵诀＋生长/治疗奇物 | 击杀点形成可读网络，不造成区域实体失控 |

其他三条武器线必须可通关，但 G2 平衡验收优先保证以上三条形成明显不同的路线决策。

## 5. 胜败、首通与重复通关

| 情形 | 必须保存 | 必须清空/不得给予 |
|---|---|---|
| 失败 | 已拾取灵砂、合法藏品、已触发故事、行迹统计 | 山河脉印、首通故事、局内构筑与目标状态 |
| 首次胜利 | 上述内容＋青岚山河脉印＋指定藏品＋第三篇故事＋据点进度 | 不重复生成唯一奖励 |
| 重复胜利 | 灵砂、重复通关统计、合法随机/保底收藏 | 不重复脉印和唯一收藏 |
| 中途退出/崩溃 | 仅按已批准恢复格式处理 | 不把不完整 Run 当胜利结算 |

## 6. 非目标

- 联机、移动端、主机、开放世界、无尽模式；
- 装备随机词条、强化、背包、宠物、声望、自由建造；
- 复杂五行克制、每日任务、通行证、多货币；
- 全面 DOTS/Jobs/Burst 迁移；
- 运行时 AI 资产生成或来源不明的正式资源。
