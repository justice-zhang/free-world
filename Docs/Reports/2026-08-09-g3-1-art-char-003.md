## 3. 关键架构决定

- 本批不使用 ImageGen：只以 Python/Pillow、固定 Seed 31003、仓库原创规格和几何图元确定性生成，
  两次运行的 8 张 PNG SHA-256 完全一致。
- 四档不依赖颜色单独辨认：静风为断环方钉、微风为单弧叶片、疾风为双弧箭羽、乘风为三弧翼冠；
  环数、标记形状/数量和最高档翼冠均形成独立轮廓。
- Alpha≥16 覆盖率按档位为 3.27%、5.41%、12.02%、19.50%，最高档仍低于 21%；全部 final
  至少保留 40 px 安全边且四角 Alpha=0。
- 正式地址固定为 `qinglan/character/lu-qingye/riding-wind/tier-0` 至 `tier-3`。Simulation 档位到
  叠加图的运行时选择留在 G3.1 最终集成，当前批次不改变机制真值或模拟 API。

## 4. 实际执行的命令

```text
python Scripts/generate-qinglan-riding-wind-overlays.py --spec ... --source-dir ... --final-dir ...
同命令第二次运行并逐文件 Compare-Object SHA-256
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（首次直接启动 GUI 子系统）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（Start-Process -Wait，tier-0 至 tier-3 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtChar003
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtChar003
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtChar003/validation.log
```

第一次 Unity 批量调用只生成 0 字节日志，未产生导入证据，判为 `NOT RUN`；改用
`Start-Process -Wait` 后四次均以退出码 0 并在独立日志中输出 `[Qinglan Visual Import] PASS`。
