# 《剑起青岚》完整版完整游戏系统方案

**版本：** v1.0
 **产品形态：** 中国风俯视角动作Roguelite / Survivors-like
 **建议商业模式：** PC买断制，首发不依赖在线服务，不设计付费数值成长
 **核心主张：** 大世界观、差异化境域、角色化构筑、有限地图探索、长期但克制的局外成长

------

## 1. 完整版产品愿景

《剑起青岚》不是简单的“中国风吸血鬼幸存者换皮”。

完整版需要形成四个层次：

1. **战斗层**：大量敌人、自动攻击、走位、升级与流派成型；
2. **探索层**：有限地图、地标、区域机制、事件和收集；
3. **角色层**：不同人物拥有独立操作逻辑、立场和故事；
4. **世界层**：各个风格差异巨大的境域，共同指向天衡断裂后的文明选择。

玩家长期体验应当是：

```
体验新角色
→ 学习新区域规则
→ 解锁新武器和心诀
→ 发现新的器法组合
→ 带回藏品和故事
→ 改造自己的行脉与剑匣
→ 挑战更高脉潮
→ 逐渐理解世界真相
```

------

## 2. 完整版设计支柱

### 2.1 清朗中国幻想

即使出现遗迹、灾难和执念，也不把阴暗作为唯一审美。

不同地区可以非常差异化：

- 青绿宗门废墟；
- 火山机关都市；
- 珊瑚覆盖的沉海商港；
- 极光雪原观星台；
- 金色沙海蜃都；
- 云海浮岛驿站；
- 节庆不夜城；
- 发光菌群地下生态；
- 横跨现实与记忆的天衡中枢。

### 2.2 角色决定玩法逻辑

角色差异不能只依靠初始属性。

每名角色必须拥有：

- 本命器；
- 独有机制；
- 专属行脉图；
- 专属显化；
- 人物故事；
- 地域和阵营立场。

### 2.3 百器与心诀来自真实世界结构

武器和被动的来源必须能在世界中被追溯。

玩家获得的不只是数值卡牌，而是在学习天下各地的技艺。

### 2.4 关卡差异进入规则层

不同关卡不仅更换地图和敌人，还必须改变：

- 路线；
- 目标；
- 时间节奏；
- 环境；
- 事件；
- Boss结构；
- 可用构筑倾向。

### 2.5 局外成长保持克制

长期成长提升：

- 构筑可控性；
- 开局选择；
- 角色机制；
- 容错；
- 探索效率。

不允许形成无限永久属性叠加。

## 3. 世界观总纲

### 3.1 天衡时代

天衡十二脉曾将天下连接为一个统一的灵脉网络。

它带来了：

- 稳定季候；
- 跨域交通；
- 技艺传播；
- 城邦繁荣；
- 灵气调度；
- 灾害治理。

但天衡也在缓慢抹平地方差异。

不同地区的灵气、思想、文化和记忆都逐渐流向天衡中心。

### 3.2 断衡之变

百年前，青岚宗参与斩断了天衡。

表面记载认为青岚宗未能阻止灾难。

真实情况可能是：

> 断衡并非失败，而是青岚宗主动做出的选择。

如果不斩断天衡，天下不会立即毁灭，却会逐渐失去真正的地方差异。

### 3.3 灵结与斩结

断衡后，原本应当分开的事物纠缠在一起：

- 过去与现在；
- 现实与记忆；
- 人与机关；
- 自然与执念；
- 生长与毁灭；
- 愿望与事实。

这些纠缠被称为“灵结”。

剑修的真正能力不是单纯杀敌，而是：

> 重新划定边界，让混乱纠缠的事物恢复选择。

因此，Boss战在叙事上通常是“斩结”，不一定是彻底消灭对方。

## 4. 主要势力

### 4.1 守衡司

主张恢复旧天衡。

优点：

- 重视稳定；
- 保护普通聚居地；
- 拥有成熟灾害治理体系；
- 能够快速恢复道路。

问题：

- 容易牺牲地方差异；
- 掩盖部分旧时代真相；
- 把秩序置于个人选择之上。

代表角色：宁照微。

### 4.2 百工联社

由工匠、商人、机关师和航路经营者组成。

主张研究并利用境域。

优点：

- 推动技术；
- 重建交通；
- 改善生产；
- 务实而高效。

问题：

- 容易将境域和脉印资源化；
- 低估生态、记忆和人的感情；
- 可能制造新的垄断。

代表角色：墨榫。

### 4.3 山海盟约

由各境域本地势力组成。

主张各地自行决定未来。

优点：

- 尊重地方文明；
- 保护新生生态；
- 反对中央控制。

问题：

- 组织松散；
- 难以处理跨域灾害；
- 部分成员主张永久封闭。

代表角色：槐婆、白汀。

### 4.4 新青岚

随着玩家推进，青岚旧庭逐渐形成第四种方向：

> 天下需要重新连接，但不必回到旧时代唯一中心化的连接方式。

新青岚不是传统宗门复辟，而是新的巡脉者网络。

------

## 5. 主线结构

### 第一幕：断路

玩家从青岚旧庭出发，发现天衡并非天然神迹，而是旧文明建造的世界级系统。

包含：

- 青岚旧庭；
- 赤炉天工城；
- 镜海沉市。

第一幕主题：

> 旧秩序为什么会断裂？

### 第二幕：诸域

玩家进入差异更大的境域，认识断衡后产生的新生命、新文明和新选择。

包含：

- 霜钟天台；
- 金砂蜃都；
- 云鲸驿；
- 百戏不夜城；
- 万菌幽谷。

第二幕主题：

> 新产生的世界是否有权继续存在？

### 第三幕：新衡

玩家进入天衡中枢，确认青岚宗当年的选择，并决定天下未来如何连接。

包含：

- 天衡中枢；
- 最终脉议；
- 终局Boss；
- 不同尾声。

第三幕主题：

> 天下需要统一的秩序，还是自愿连接的道路？

## 7. 每个区域的标准内容包

每个主要区域至少包含：

- 1张大型有限地图；
- 5个清晰子区域；
- 1套地域核心机制；
- 1个主要目标；
- 3至5个地图事件；
- 5至7种普通敌人；
- 2种地域精英模板；
- 1个中段Boss；
- 1个最终Boss；
- 1名关联角色；
- 3至4件公共武器；
- 2至3部公共心诀；
- 4至6件区域战场奇物；
- 8至12件藏品；
- 1条主线章节；
- 1至2条角色故事；
- 1套环境音；
- 1套动态战斗音乐。

地形采用手工设计，事件、精英、部分地标和收集位置在预设锚点中随机变化。

## 8. 完整角色阵容

### 8.1 陆青野

- 身份：自由少年剑客；
- 地域：青岚旧庭；
- 本命器：游风剑；
- 机制：乘风；
- 玩法：持续移动、追踪、高频御剑；
- 主题：自由不是逃避，而是不让别人替自己决定道路。

### 8.2 宁照微

- 身份：守衡司巡律使；
- 本命器：朱律符；
- 机制：定界；
- 玩法：在方形阵域中提高精准、穿透和攻击效率；
- 主题：稳定秩序是否值得以选择为代价。

### 8.3 墨榫

- 身份：赤炉机关师；
- 本命器：离火机匣；
- 机制：炉温；
- 玩法：机关召唤、过热、爆发和停机风险；
- 主题：不是所有问题都能被当作工程问题解决。

### 8.4 白汀

- 身份：镜海引潮人；
- 本命器：听潮珠；
- 机制：涨落；
- 玩法：吸附与击退交替、周期控制；
- 主题：由记忆形成的意识是否拥有生命权利。

### 8.5 钟无昼

- 身份：霜钟观星者；
- 本命器：寒星钟；
- 机制：迟响；
- 玩法：部分伤害记录为星债，在下一次钟鸣时爆发；
- 主题：看见未来不代表必须服从未来。

### 8.6 迦遥

- 身份：金砂照镜客；
- 本命器：蜃影刃；
- 机制：真伪；
- 玩法：移动残影、诱敌、暴击真身；
- 主题：虚假道路是否可能通往真实结果。

### 8.7 风栖迟

- 身份：云鲸驿飞使；
- 本命器：穿云梭；
- 机制：航程；
- 玩法：高速穿阵、折返投射、路线规划；
- 主题：总是离开究竟是自由，还是害怕留下。

### 8.8 祝红绡

- 身份：百戏焰伶；
- 本命器：红绡焰扇；
- 机制：喝彩；
- 玩法：持续击杀维持节奏，满值进入压轴状态；
- 主题：谢幕不等于快乐消失。

### 8.9 槐婆

- 身份：万菌谷守种人；
- 本命器：孢灯；
- 机制：共生；
- 玩法：菌群铺场、持续伤害、恢复网络；
- 主题：人类并不是衡量所有生命的唯一尺度。

## 9. 角色关系结构

### 陆青野与宁照微

```
个人选择
vs
公共秩序
```

两人不需要一方彻底认输，而是在长期同行中互相修正。

### 墨榫与槐婆

```
工程利用
vs
生态共生
```

两人最终可能共同建立不破坏菌群的修复方式。

### 白汀与钟无昼

```
过去的记忆
vs
未来的可能
```

白汀害怕遗忘，钟无昼则被未来束缚。

### 迦遥与祝红绡

```
幻象
vs
表演
```

一个质疑虚假，一个认为虚构也能带来真实慰藉。

### 风栖迟与陆青野

两人都追求自由，但风栖迟会质问陆青野：

> “一直离开，是自由，还是不敢留下？”

## 10. 完整游戏模式

### 10.1 巡脉主线

标准剧情模式。

- 单关18至22分钟；
- 中段Boss；
- 最终Boss；
- 固定主线解锁；
- 可探索藏品和角色故事。

### 10.2 境域重访

主线通关后自由选择地图。

用于：

- 收集；
- 角色任务；
- 构筑实验；
- 区域挑战；
- 高难度解锁。

### 10.3 脉潮等级

逐级增加难度。

增加的不是单纯血量，而是：

- 敌人组合；
- 精英词缀；
- 地图事件；
- Boss新技能；
- 灵物稀缺；
- 环境危险。

建议正式版设置0至10级。

### 10.4 境域异变

玩家主动选择挑战词条。

例如：

- 草木疯长：部分道路变窄；
- 逆风而行：风向周期影响移动；
- 旧令重启：机关类敌人增多；
- 灵潮高涨：经验增加，但敌群同步增加；
- 镜影重重：部分敌人生成幻象；
- 寒刻迟行：技能冷却与敌人行动周期交替变化。

### 10.5 角色试炼

每名角色拥有专属挑战。

例如：

- 陆青野：长时间维持高风势；
- 宁照微：在阵域中击败Boss；
- 墨榫：只使用机关类武器；
- 白汀：完整经历多次涨落周期而不受伤。

### 10.6 长途远征

连续挑战三个境域。

规则：

- 保留部分武器和心诀；
- 中段Boss掉落的境域遗器可继续使用；
- 关卡之间进行有限调整；
- 最终获得高阶脉印和稀有收藏。

该模式用于解释强力“本局遗器”为何可以跨Boss继续生效。

### 10.7 演武场

- 武器测试；
- 伤害统计；
- Boss练习；
- 自定义敌群；
- 角色机制教学。

------

## 11. 完整局内结构

### 11.1 槽位

- 武器：4槽；
- 心诀：4槽；
- 战场奇物：3槽；
- 境域遗器：1至2槽，仅远征或特定模式；
- 随身灵物：完整版后期可解锁1槽。

保持4＋4而不是无限扩槽，可以让每次选择持续具有代价。

### 11.2 典型20分钟节奏

| 时间      | 阶段                       |
| --------- | -------------------------- |
| 0—4分钟   | 建立基础构筑、探索首个区域 |
| 4分钟     | 第一精英                   |
| 6—8分钟   | 地域事件与首个主要目标     |
| 10分钟    | 中段Boss与显化宝匣         |
| 11—15分钟 | 地域规则强化、复合敌群     |
| 15分钟    | 第二精英或区域挑战         |
| 18分钟    | 高压敌潮                   |
| 20分钟    | 最终Boss                   |
| Boss后    | 结算、故事、藏品与脉印     |

- 青岚宗；

- 剑冢；

- 30条标准器法合鸣；

## 13. 本命器与传习版本

角色本命器拥有：

- 角色机制联动；
- 专属动画；
- 专属显化；
- 专属行脉节点。

完成角色故事后，可以解锁“传习版本”进入公共池。

例如：

```
陆青野：
游风剑
→ 青岚流影剑
→ 万剑乘风

其他角色：
游风剑·传习
→ 风回剑轮
```

这样既保留天下技艺流通，也不会削弱角色辨识度。

## 14. 完整心诀体系

### 心诀类

强化攻击、冷却、暴击和稳定性。

### 身法类

强化移动、转向、闪避和穿行。

### 炼体类

强化生命、防御、恢复和护盾。

### 驭器类

强化数量、穿透、投射速度和召唤物。

### 阵法类

强化领域、范围、持续时间和控制。

### 观想类

强化经验、幸运、掉落和构筑控制。

### 调脉类

强化节奏、资源循环和状态稳定。

### 异修类

高风险高收益，例如低生命、长时间不攻击或持续高速移动。

建议正式版包含24至30部公共心诀。

------

## 15. 器法合鸣系统

标准显化条件：

```
武器满级
＋
对应心诀达到要求
＋
开启显化宝匣
```

完整版本包含三类显化。

### 标准显化

任何角色均可完成。

### 本命显化

本命角色使用对应武器时触发，拥有角色机制联动。

### 终式显化

完成角色故事、激活终端行脉节点，并在局内满足附加条件后触发。

终式显化不能只是伤害更高，应改变行为方式。

------

## 16. 随机池管理

随着内容增加，随机池会被稀释，因此需要以下机制：

### 角色亲和

角色更容易出现与自身标签相合的内容。

### 地域权重

当前地图更容易出现当地武器、心诀和奇物。

### 流派倾向

出发前选择一个标签倾向，例如：

- 御剑；
- 机关；
- 领域；
- 草木；
- 控制；
- 探寻。

### 封存

局外允许临时封禁少量已经解锁的内容。

### 刷新与放弃

通过行脉图和模块增加有限次数。

### 新内容保护

首次解锁的新内容在接下来数局中拥有适度出现权重，确保玩家可以体验。

## 17. 局内道具层级

### 17.1 即时战斗灵物

- 吸取；
- 护盾；

最终Boss负责永久内容：

- 境主脉印；
- 唯一藏品；

- 区域解锁；

- 震地；

### 死亡词缀

## 20. 刷怪导演

完整导演由三层构成。

### 固定节奏骨架

确保每关的叙事、Boss和压力阶段稳定。

### 预算组合系统

根据阶段预算组合敌人，不直接按秒生成固定数量。

### 保护规则

只用于避免异常体验，不动态惩罚高输出玩家。

保护规则可以包括：

- 场上敌人过多时停止部分生成；
- 玩家长期没有升级时提高经验合并效率；
- 玩家极低生命时降低回血物的抑制权重；
- 不实时提高敌人血量追赶玩家。

## 21. 地图与关卡目标

每关都保留生存计时，但必须拥有一个地域目标。

### 青岚旧庭

激活风脉节点。

### 赤炉天工城

关闭失控生产线并控制炉温。

### 镜海沉市

在潮水淹没前点亮沉海灯塔。

### 霜钟天台

校准时间错位的星钟。

### 金砂蜃都

辨认真实城门并拆除蜃景核心。

### 云鲸驿

修复航路并追上失控飞舟。

### 百戏不夜城

完成庆典段落并允许演出真正谢幕。

### 万菌幽谷

重建被破坏的菌群网络。

### 天衡中枢

重组天脉连接方式。

目标不应要求玩家长时间停止战斗。互动期间仍需移动、防守或完成区域击杀。

- 5个主要兴趣点；
- 8至12件区域藏品；
- 1至2个角色专属行迹；
- 1个隐藏挑战；
- 1个可选高风险区域。

兴趣点需要明确风险收益。

例如：


## 23. Boss设计原则

Boss不能只是高生命值敌人。

每个Boss至少具有：

- 三阶段或两阶段＋终结阶段；
- 区域机制联动；
- 明确前摇；
- 移动路线要求；
- 至少一个改变战场空间的技能；
- 与未完成关卡目标的联动；
- 斩结后的叙事结果。

最终Boss奖励服务局外。

中段Boss奖励服务本局。

## 26. 角色行脉图

每个角色包含三条分支：

### 本命

强化本命器和角色专属战斗逻辑。

### 身法

强化移动、位置、容错和角色节奏。

### 心性

强化构筑控制、奇物选择和角色策略。

规则：

- 节点可以全部解锁；
- 每次出发只能激活有限节点；
- 只能选择1至2个终端节点；
- 免费重置；
- 纯数值增幅受限；
- 主要价值是机制分支。

## 29. 故事与世界选择

关键章节结束时进行“脉议”。

玩家面对的不是简单善恶选择，而是：

- 恢复中心化旧天衡；
- 建立分布式新天衡；
- 让各境域独立，仅保留自愿开放的门。

为控制制作规模：

- 大部分关卡内容保持一致；
- 选择主要改变角色态度、终局Boss阶段、结局旁白和据点尾声；
- 不制作三套完全不同的后半部游戏。

可形成三种尾声：

### 复衡

恢复旧秩序，天下稳定，但地方差异开始收缩。

### 共衡

建立分布式天脉，各地共同维护连接，代价是持续协商与不确定性。

### 开界

诸域保持自治，仅开放自愿连接的脉门，世界更自由但也更脆弱。

## 34. 美术方向

- 轮廓优先；
- 年龄、身形、动作明显区分；
- 不全部设计为年轻俊男美女；

- 2D俯视或轻斜俯视；
- Universal 2D光照；
- 手工地图；
- 局部动态天气；
- 适度视差；

### 34.3 特效

- 玩家和敌方危险色分离；

## 47. 完整版完成定义

完整版本只有满足以下条件才可视为完成：

1. 九个主要境域均具备独立玩法机制；
2. 九名角色均具备本命器、独有机制、行脉图和完整故事；
3. 所有区域均可以从进入运行到结算；
4. 武器、心诀、奇物和显化形成稳定构筑语法；
5. 随机池扩大后仍可通过亲和、倾向和封存控制；
6. 局外成长不会替代局内构筑；
7. 主线、角色故事和藏品叙事相互连接；
8. 三种主要尾声逻辑完整；
9. 普通关卡、脉潮、角色试炼和远征均可独立运行；
10. 存档可以跨版本迁移；
11. 所有内容包通过自动校验；
12. 目标性能达成；
13. 手柄、键鼠和可访问性完整；
14. 连续长时间测试不存在阻断性错误；
15. 所有AI和第三方资产具备来源记录；
16. Windows正式构建可离线完整游玩。
