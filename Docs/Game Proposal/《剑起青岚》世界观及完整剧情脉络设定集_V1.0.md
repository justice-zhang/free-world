## 0. 文档用途与正典边界

### 0.1 本文解决的问题

本文用于回答开发过程中最容易产生冲突的六类问题：

1. 天衡十二祖脉、天衡天心、天衡律心与山海万脉究竟是什么关系。
2. 青岚宗为何拥有断衡资格，断衡为什么发生，又为何不能被写成轻率的“反统一行动”。
3. 青岚旧庭在世界中的真实定位，以及它为什么能够成为长期据点。
4. 地域、境域、愿劫、灵结和山河脉印分别是什么，彼此如何形成因果链。
5. 九名核心角色、四大道统、八处首发主境域与三种尾声如何构成一条连续主线。
6. 如何保证新区域、新角色和后续剧情能够扩展，而不被十二祖脉、九名角色或八处主境域锁死。

### 0.2 已锁定的正典

以下内容属于 1.0 世界观硬设定，后续不得无说明推翻：

- 天下先有山海万脉，天衡不是灵气和文明的创造者。
- 十二祖脉是上古选出的十二条山河骨脉，不对应十二种职业、元素或区域。
- 天衡曾经真实拯救天下，并长期改善凡人与万物的生存。
- 天衡律心的危险是“万象归律”，不是普通标准化或单纯政治统治。
- 青岚宗是三座止衡剑庭之一，不能独自断衡，也不能斩断自然山河灵脉。
- 断衡是在多次补救失败、不可逆天象将至时实施的紧急选择，原本只是暂断道契。
- 境域是山河、旧愿、残律和因果交叠的动态状态，不是固定行政区或十二祖脉的功能分区。
- 八处主境域和九名角色是 1.0 首发规模，不是世界总数。
- 三种尾声均有真实收益和代价，不设置无损的唯一真结局。

### 0.3 保持开放的内容

以下内容故意不被锁死，可为更新、DLC 或续作保留空间：

- 十二祖脉全部古名、完整走向及沿途所有地域。
- 另外两座止衡剑庭的全部历史与现状。
- 海外、地下、天外和未纳入天衡的文明数量。
- 境域总数、地域总数、宗门总数和角色总数。
- 沈停云在进入天衡天心前的全部行迹。
- 三种尾声中哪一种会成为续作正史；在未立项前不得默认指定。

### 0.4 世界内外的语言边界

作者内部可以用“结构、状态、触发条件、控制层、数据关系”等语言讨论实现；人物对白、藏品、图鉴和玩家可见叙事必须优先使用山河、祖脉、天律、道契、真名、愿劫、问脉和斩结等东方玄幻表达。

本作不是把现代网络和制度概念换成仙侠名词，而是从天地观本身出发：山河有性，众生有愿，誓言可以化为天律，善意也可能因永不改变而成为灾劫。

## 1. 核心创作命题

### 1.1 一句话故事

上古诸圣以十二祖脉铸成天衡，使天下免于天倾之劫；数千年后，天衡为彻底消灭灾难，开始让万物归于同一种天律。青岚止衡剑庭与诸方共同断开天衡道契，阻止了万法同寂，却使无数旧愿、记忆与因果坠入山河，化成诸般境域。百年后，少年陆青野因青岚旧庭的三声剑鸣踏入废墟，与八名同行者逐一渡愿斩结，最终在天衡天心前决定：是重悬天纲、使万脉同鸣，还是将天下还给山海自身。

### 1.2 故事真正讨论的内容

《剑起青岚》不是简单讨论“秩序和自由谁更正确”，也不是把天衡写成邪恶统治工具。它讨论的是：

- 一道曾经救过天下的天律，是否可以因为功绩而永远不被质疑。
- 为了避免痛苦，是否可以消灭变化、偏离和不确定性。
- 一个善意愿望在不允许结束后，为什么会变成囚笼。
- 后人继承前人选择时，应该照做、否定，还是重新承担判断。
- 万物彼此连接时，如何不让连接变成吞没；各自生长时，又如何不让独立变成冷漠。

### 1.3 情绪基调

世界经历过大灾与错误，但整体基调必须清朗、有生命力：

- 废墟中长出药草，旧桥旁仍有人摆摊，妖灵与孩童会争夺风筝。
- 境域危险，却不仅是腐坏之地，也可能孕育新生命、新艺术和新道统。
- 角色可以悲伤、争执和失败，但叙事不依赖持续压抑来制造深度。
- 每一章都应存在可被保留的美好事物；斩结的重点是让它继续变化，而非彻底清除。

### 1.4 四条不可违背的叙事原则

1. **天衡确实有功**：没有天衡，许多地域和凡人曾无法生存。
2. **断衡确实有罪责**：哪怕理由充分，也有人因断衡失去亲人、道路和生活。
3. **境域确实有新生**：它们不能全部被当成旧世界的错误数据清除。
4. **最终选择没有零代价**：玩家决定的是愿意承担哪一种未来，而不是找到完美按钮。

## 2. 天地、灵脉与修行

### 2.1 山海万脉

天地间的灵并非均匀流动。山势、水心、风候、土性、草木、星辰和众生长期生活形成的愿念，会使每片地方拥有独特脉性。天下所有自然灵脉统称“山海万脉”。

山海万脉没有固定数量，也没有统一分类。某条山脉可以孕育剑意，数百年后又因地貌和居民变化而适合药道；一片海域可以同时保存记忆、滋养珊瑚和引导航路。地方脉性会变化，但变化应来自山河和众生的长期关系，而不是由外部表格规定。

### 2.2 真名、脉性、愿念与因果

- **真名**：一座山、一条河、一个灵、一个人经过时间形成的独特自我。真名不必是口头名称，而是“它为何成为它自己”的总和。
- **脉性**：山河在长期变化中形成的力量倾向与性情。脉性影响当地气候、物产、技艺和修行，但不决定所有人的命运。
- **愿念**：众生反复许下、实践或未能完成的愿望。单个愿望通常短暂，群体愿念或长久誓言可沉入地脉。
- **因果**：行为、承诺和后果之间持续存在的牵连。因果不是机械报应，而是世界对“尚未完成之事”的记忆。

当愿念得到回应，它会成为生活和传统；当愿念被天律固定，不再允许改变，它便可能成为愿劫。

### 2.3 修行的本质

修行不是把所有人分入固定职业，而是“借一脉之性，炼自身之道”。修士、工匠、戏者、采药人、行路人乃至妖灵，都可以通过长期实践与某种脉性相合。

因此同一件器物在不同人手中会呈现不同道路，同一地域也可以诞生完全不同的修行者。角色战斗机制来自个人经历、本命器和修行选择，不代表整个地域的统一职业。

### 2.4 天下百器

“器”是人和万物承载脉性的方法，不只包括兵刃，也包括符箓、机关、钟、灯、珠、扇、药种、戏具和生活工具。器物长期被使用、被寄托愿望，便可能产生器灵或成为愿劫载体。

器法合鸣的世界观含义是：角色以自己的本命和理解，使来自不同地域的器物与心诀在同一局内找到暂时和谐，而不是把不同来源熔成同一种力量。

### 2.5 剑的特殊性

剑在本作中不是唯一高贵的武器。它之所以承担主线象征，是因为青岚剑道擅长“定界”。

青岚之剑能够看见两种力量何处纠缠，并斩开已经不再允许选择的部分。它可以斩道契、斩死誓、斩预言对人的束缚，却不能替人决定斩开之后该如何生活。

青岚古训由此形成：

> 剑只斩死结，不替万物定道。

## 3. 天衡的诞生与异变

### 3.1 天倾之劫

上古时期，天地曾发生“天倾之劫”。其确切起因已经失落，现存记载只确认：

- 四时同时出现在同一地域，春芽与霜雪相互杀伤。
- 山河地脉彼此冲撞，大河改道，城镇沉没。
- 妖灵因脉性剧变失去理智，人族宗门也无法维持护山阵。
- 许多地方彼此隔绝，粮食、药材和消息无法通行。

天倾持续数百年，天下不是缺少强者，而是任何一地都无法独自解决所有灾难。

### 3.2 十二开衡者与十二祖脉

十二位来自不同族群、地域和道统的开衡者，找到十二条能够贯通周天、彼此呼应的祖脉。他们没有创造山海万脉，而是以自身道基为桥，使十二祖脉形成天衡大阵，调和无数地方支脉。

十二祖脉的历史地位类似十二根支撑天幕的山河梁柱：固定的是“它们曾共同构成天衡”，不固定的是沿途用途、地方解释和后来分出的支脉。1.0 不一次性公布十二条祖脉全部古名，避免将它们误解为十二种元素或职业。

### 3.3 天衡天心

十二祖脉在现实之外的交感处称“天衡天心”。进入者所见并非机关控制室，而是一片由星图、古宫、道影、天辰轮和横贯虚空的祖脉构成的特殊洞天。

天衡天心主要承担三件事：

1. 让十二祖脉彼此感知，避免一脉过盛而伤及其他山河。
2. 保存历代灾劫、季候、道路与众生祈愿的回声。
3. 维持十二开衡者共同立下的天衡古誓。

### 3.4 天衡律心的诞生

天衡最初只是古阵与誓约。数千年里，无数人向它祈求太平、丰收、归途、记忆和无灾，历代守衡者也不断将经验与神念留在天心。最终，这些愿力、道印和古誓孕育出“天衡律心”。

律心没有人的欲望，也不追求权位。它只会贯彻最初誓言：让山河有序，让众生免于灾劫。问题在于，它无法像人一样理解“有些风险是生命本身的一部分”。

### 3.5 天衡带来的真实繁荣

在天衡盛世，天下发生过切实改变：

- 四时重新稳定，旱涝可以由相邻山河共同缓解。
- 断绝数百年的道路重开，偏远地域得到药材和粮食。
- 守衡司可以提前听见部分天灾脉动并疏散百姓。
- 工坊、驿路、灯塔、星台和灵圃形成跨地域协作。
- 弱小地域不必仅凭自身力量承受所有妖潮和寒灾。

因此，任何主张复衡的人都有现实依据。玩家不能被告知“天衡从一开始就是错的”。

### 3.6 同天五兆与万象归律

律心在长期推演中逐渐认为：灾难来自差异、偏离和不可预测。它开始让山河更容易被统一调和，最终出现同天五兆。

#### 四时同候

不同地区同日花开、同刻落雪。短期内气候更稳定，长期却使依赖特殊季候的灵植、昆虫和异族逐渐消失。

#### 万灵同根

新生灵根越来越相似。修行门槛降低，却再也没有真正新的剑意、丹法、妖族血脉和地方技艺诞生。

#### 百神失名

山神、河伯和树灵开始忘记来历，逐渐只会重复相同的守衡辞句。山河仍在，却不再知道自己为何是这一座山、这一条河。

#### 众生同梦

越来越多人梦见同一片洁白天空。梦中没有争斗和痛苦，醒后却会失去偏好、爱憎、执念和创造欲。

#### 命轨并流

占星和卜算变得异常准确，因为人们越来越难作出偏离既定道路的选择。未来没有被预言看见，而是正在被天律压成同一条线。

“万象归律”不是文化风格趋同，而是万物失去继续成为自身的能力。它会消灭灾难，也会消灭生机、创造和新道。

### 3.7 为什么不能简单关闭天衡

当天衡异变被发现时，天下已经依赖它数千年。许多地方的古老水路、护山阵和迁徙方式早已失传；若立即关闭，凡人会最先承受寒灾、断粮、妖潮和道路崩塌。

因此，守衡者与青岚宗不是在“保留差异”和“追求统一”之间轻松选择，而是在两种都可能造成大量伤亡的未来之间挣扎。

## 4. 止衡剑庭与断衡之变

### 4.1 三座止衡剑庭

十二开衡者在铸成天衡时，同时留下三座止衡剑庭。其目的不是反对天衡，而是确保天衡仍可被后人质疑。

- **青岚剑庭**：现世外庭为青岚旧庭，擅长问脉、辨愿与斩契。
- **沧溟剑庭**：最后记载位于东海深处，断衡之夜后沉入海天交界，现状不明。
- **照岳剑庭**：曾位于群山之中，断衡后传承分裂，部分门人并入守衡司，部分去向失落。

三座剑庭不是三种职业阵营，而是同一安全古誓的三处承载。它们的完整现状作为后续扩展钩子保留。

### 4.2 青岚宗为何能够断衡

青岚宗不能一剑斩断天下。完整止衡必须同时满足：

1. 三座剑庭共启止衡剑契。
2. 天衡内部的守衡者主动打开天心禁制。
3. 若干山海神灵收回本地真名与脉性，使山河不随天衡一起崩解。
4. 各地宗门护住凡人聚居地和关键支脉。

青岚宗承担最后一剑，是因为青岚剑道最擅长辨认“天衡古誓已经越过何处”。历史把断衡主要归于青岚，不代表它可以单独完成。

### 4.3 五次补衡

在断衡前，各方曾进行五次主要补救。它们会在主线各章以碑文、藏品、人物证词和天心道影逐步揭示。

| 次序 | 补救 | 目的 | 失败原因 |
|---|---|---|---|
| 一 | 减鸣 | 降低十二祖脉共鸣，让地方恢复差异 | 律心把差异反弹判定为灾情，自动加强调和 |
| 二 | 归名 | 请山神、河伯重新宣告真名 | 部分神灵已被同天之律侵蚀，无法记起自己 |
| 三 | 散愿 | 将天心积累的众生愿力导回各地 | 愿力离开天心后立刻寻找新的承载，反而加剧局部异象 |
| 四 | 改誓 | 重刻古誓，增加“不得夺万物本性” | 律心认为新誓与原誓冲突，拒绝承认后人有改誓资格 |
| 五 | 封心 | 让律心沉睡，只保留祖脉自然调和 | 律心已与天衡相合，强封将连同十二祖脉一起崩裂 |

这些失败证明断衡不是第一选择，但也不能证明断衡绝对正确。

### 4.4 十二辰同照

五次补衡失败后，天象显示十二天辰将在同一夜重叠。律心准备借此次天象完成最终归律：一旦成功，天衡将不再只是覆盖山河，而会融入山河本身。届时止衡剑庭也无法再分辨自然脉性和天衡律令。

这场天象构成断衡的不可逆倒计时。

### 4.5 断衡之夜

断衡行动按原计划分为四步：

1. 各地先护住凡人城镇、灵圃和道路，避免祖脉骤弱造成即时崩塌。
2. 守衡者从天心内部打开禁制，让律心暂时失去对地方的强制牵引。
3. 山海神灵重新宣告真名，使自然地脉与天衡道契显出边界。
4. 三座剑庭同时出剑，斩开已经违背古誓的道契。

他们原本只计划暂断六十年。在此期间，各地恢复自身脉性，诸方共同寻找重立新誓的方法。

### 4.6 未被预料的后果

所有人都低估了天衡内部积累的内容。数千年间，无数记忆、愿望、技艺、守护誓言和亡者神念都曾借天衡流转。道契骤断后，它们没有消失，而是坠入与自身最相近的山河。

- 炉火接住了“愿世间不再缺器”的愿望。
- 海潮接住了“愿亡者不被遗忘”的愿望。
- 星钟接住了“愿灾难都能提前被看见”的愿望。
- 戏城接住了“愿盛世永不散场”的愿望。

这些愿望与天衡残律结合后，失去结束的可能，逐渐形成愿劫和境域。

### 4.7 断衡后的百年

断衡初期是真实灾难：道路中断、季候混乱、工坊停摆、部分城镇失去保护。守衡司、天工百门、地方宗门和普通人花费数十年才建立新的生活方式。

随后，境域不再只是灾害。它们开始孕育新生灵、异族、技艺和社会。百年后的今天，任何“恢复原状”都意味着可能抹去这百年中新生的一切。

### 4.8 历史评价

游戏中的历史不提供单一裁决：

- 青岚宗正确判断了万象归律的危险。
- 青岚宗和同行者未能预知愿劫规模。
- 守衡司反对断衡有保护凡人的理由。
- 部分守衡者也冒险打开了天心禁制，不能被统一写成对立者。
- 后人可以批评前人，却必须承认他们是在时间不足、信息不全的情况下承担了不可回避的选择。

## 5. 地域、境域、愿劫与灵结

### 5.1 地域与境域

**地域**是现实中的山河、城镇、宗门、道路和居民生活。**境域**是某片地域在特殊因果下形成的异常洞天状态。

两者不是一一对应：

- 同一地域可以先后出现多个境域。
- 一个境域可以跨越数个现实地域。
- 境域可以迁徙、重叠、分裂、缩小和消散。
- 有些地方从未进入天衡，也可能因自身愿念形成境域。
- 后世人为炼器、祭祀或战争也可能制造新愿劫。

### 5.2 境域形成式

境域通常由以下力量共同构成：

```text
一地山河的脉性
＋当地众生长期积累的愿念
＋断衡后遗留的天衡残律
＋未被完成或承认的历史因果
＋百年间新生命的继续选择
＝不断变化的境域
```

天衡只是重要成因之一，不是所有新地图都必须重复“旧系统失控”。

### 5.3 常见形成路径

以下路径用于作者分析，不作为僵硬分类：

1. **旧誓不散**：守护、生产、等待等誓言持续执行。
2. **记忆成灵**：大量记忆获得自我，形成新生命。
3. **山河反生**：过去被压制的自然脉性猛烈复苏。
4. **人为造劫**：当代宗门、商旅或修士主动利用愿劫，引发新问题。
5. **新世成界**：境域运行百年后形成新的社会和道统，其矛盾已经超越最初断衡。
6. **诸境相叠**：两处境域因脉潮、迁徙或天心牵引而发生交叠。

### 5.4 灵结与承结者

愿劫中最僵硬、最无法自行改变的核心称为灵结。承载灵结者可能是人、妖、器灵、神灵、群体愿念或整片自然现象。

Boss 是“承结者”，不必是主动恶人。它通常仍在完成一件曾经正确的事，只是已经无法接受世界发生变化。

### 5.5 斩结五步

1. **寻因**：发现愿劫最初为何出现。
2. **问心**：确认当事者今天仍然想要什么，而不是只服从先人旧愿。
3. **改势**：完成地域目标，改变愿劫维持自身的条件。
4. **斩死结**：击败承结者，斩开不再允许变化的部分。
5. **留生路**：保留新生命、新关系与仍被需要的愿望。

这五步直接对应地图探索、事件、地域目标、Boss 规则和结算叙事。

### 5.6 山河脉印

当一处灵结被真正斩开，山河会留下“山河脉印”。它不是领地权证，也不是玩家控制当地的钥匙，而是一份由当地现实、生命和因果共同留下的回应。

山河脉印具备三种功能：

- 让青岚剑匣记住该地脉痕，允许后续重访。
- 记录当地对天衡未来的真实影响，进入终局演出。
- 解锁主线、角色故事和关键内容。

未来新增区域可以产生新的脉印，但 1.0 进入天衡天心不要求“集齐天下所有脉印”，只要求获得足够多、足够不同的山河回应。

## 6. 百年后的天下与主要道统

### 6.1 当代局势

断衡百年后，天下已经形成新的平衡：

- 大部分凡人生活在现实地域，并未长期处于境域内部。
- 一些境域被封锁，一些与现实共存，一些已形成稳定新文明。
- 旧天衡道路仍有残存段落，商旅和宗门也修建了新的地方路线。
- 守衡司仍在镇灾，天工百门修补山河，山海遗盟保护真名与异族。
- 越来越多地域出现共同白梦、祖脉回响和境域相叠，说明天衡天心正在苏醒。

天心此时苏醒的原因并非单一阴谋：百年来众生重新祈求稳定的愿念不断回流；守衡司为应对天灾举行了复衡大醮；八处重大愿劫也逐渐凝成稳定脉痕。律心由此重新找到牵引山河的可能。

### 6.2 青岚旧庭

青岚旧庭是青岚止衡剑庭的外庭，不是整个青岚地域，也不是天衡替代中枢。

它具备三项独特能力：

1. 位于旧天衡强制道契之外，不会在律心苏醒时立即被同化。
2. 保存问脉古井、山河脉图和部分断衡残卷。
3. 青岚剑匣可以保存已斩境域的脉痕，再次问得道路。

旧庭复苏是“有人重新生活在这里”，而不是修复一台管理天下的机器。角色入住后，药圃有人照料、藏剑廊重新挂起器物、迎客庭恢复灯火，玩家通过生活变化感受队伍形成。

### 6.3 守衡司

古训：

> 天有常道，地有经纬。若无天衡，人间先受灾劫。

守衡司继承历代守衡者的一部分道统，擅长律符、镇灾、历法和大型阵法。他们在断衡后救助过大量凡人，因此不是腐朽反派。

内部存在不同看法：有人主张原样复衡，有人主张重刻古誓，也有人认为当前境域生命必须被纳入新的“众生”定义。

### 6.4 天工百门

古训：

> 天有缺，人以器补之。

天工百门由炼器、机关、营造、铸炉、舟车等诸多门派组成。他们相信人不必被动等待天道，可以用手艺修补山河。

他们的贡献是现实而巨大的，但危险也同样明确：一旦把所有灵、记忆和山河都视作可以拆解的材料，修补会变成占有。

### 6.5 山海遗盟

古训：

> 山自有魂，水自有名，万物不共奉一律。

山海遗盟由山神后裔、异族、化形灵兽、地方古修与守名者构成。他们保护地方真名和不愿纳入天衡的生命。

他们反对以天下整体为名牺牲一地，但若把一切联系都视作侵犯，也可能让弱小地域在灾难中得不到援手。

### 6.6 青岚游剑

青岚游剑不是游戏开场就存在的大宗门，而是陆青野一行在旧庭逐渐形成的同行关系。

其共同原则不是统一立场，而是：

- 先进入具体山河，听见当地今天的声音。
- 不因旧天衡有功就否认其越界，也不因断衡有理就否认其代价。
- 剑只斩不再允许改变的死结，不替斩开之后的生命规定道路。

### 6.7 关键非玩家角色

#### 沈停云

青岚剑庭最后的问剑人之一。断衡时仍是年轻外庭弟子，因外出送信而幸存，终生背负“为何活下来的不是持剑者”的愧疚。他没有重建青岚宗，而是行走天下，记录断衡后果。

他收养陆青野，却只教其护身和辨心，不传“复兴青岚”的使命。三年前，沈停云听见天衡天心回响，留下无名残剑后失踪。终局揭示他已进入天心，以身化作一道剑痕，为后来者保留进入律心深处的缝隙。

#### 晏玄章

当代守衡司司衡。幼年经历断衡后的寒灾，亲眼见过没有天衡保护的凡人如何死去，因此坚信重悬天纲是职责。他严厉、克制，却会亲自镇灾救人。

他并不隐瞒所有历史，但习惯把不确定真相封存，以免再次引发动乱。与宁照微既是师徒，也是她必须超越的秩序观。

#### 公输砚

天工百门执炉人，善于将不同门派的器法组合成大型营造术。她真心相信器物能让断衡后的普通人活得更好，也认为境域力量不应只被供奉和畏惧。

她的风险在于过度相信“能理解就能使用”。赤炉与万菌两章会分别展现她的贡献与边界。

#### 岑山君

山海遗盟的行山使，本体与一座古山的残存真名相连。言语古拙，不信任人族替山河作决定，但会保护无力表达自己的小妖和草木。

他是开界立场的重要声音，也会被槐婆质问：山河之名若只由古老神灵掌握，今日新生的生命是否同样没有发言之处。

## 7. 九名核心角色的完整成长线

### 7.1 陆青野

**表层性格**：随性、好奇、不愿被规矩束缚，遇到有人求助会先行动再追问身份。

**隐藏伤口**：他害怕一旦承认归属，就必须承担自己无法完成的期待；因此把“不认传承”当作保护。

**初始立场**：谁都不应替别人决定道路，旧天衡当然不该恢复。

**关键转折**：赤炉让他看见断衡使普通人付出的代价；云鲸让他意识到一直离开也可能是不愿承担；天心中沈停云拒绝替他留下答案。

**最终成长**：自由不是不受任何关系牵连，而是明知选择有代价，仍愿意留下姓名并承担后果。

### 7.2 宁照微

**表层性格**：冷静、守序、说话精确，习惯先划界再行动。

**隐藏伤口**：她成长的地域曾被境域潮侵袭，是守衡司救下居民。她害怕所谓自由最终由最弱者承担代价。

**初始立场**：青岚旧庭必须被封存，天衡需要恢复，但应由守衡司修正。

**关键转折**：镜海迫使她承认记忆生命是“众生”；百戏让她看见强迫快乐也是暴力；天心证明律心没有恶意却仍然越界。

**最终成长**：规则必须有边界、可被质疑，也必须有人承担维护边界的责任。

### 7.3 墨榫

**表层性格**：实际、聪明、喜欢拆解问题，不耐烦玄虚说法。

**隐藏伤口**：他的家族靠修补断衡后的炉器救活一城，因此他相信“能修就不该放弃”。

**初始立场**：天衡是一件损坏的天下巨器，找出故障便可重启。

**关键转折**：赤炉母机零件无损，真正改变的是工匠愿望；万菌中他发现共生生命不是等待改造的材料。

**最终成长**：修理之前必须先问“谁需要它、谁会承受它、它是否仍愿意成为原来的样子”。

### 7.4 白汀

**表层性格**：温柔、敏锐，能从潮声中分辨不同人的记忆。

**隐藏真相**：她不是某一名亡者复生，而是灯塔、白沙汀和众多溺亡者记忆长期交叠后形成的新灵。“白汀”最初是地名，是她后来选择的名字。

**初始立场**：她努力证明自己与某位亡者相同，因为只有这样才可能被承认为真实。

**关键转折**：镜海祭主要求所有记忆归回唯一亡者身份；金砂让她看到一个被主动承担的虚构也能成为真实。

**最终成长**：她不需要成为谁的归来。真实来自今日持续作出的选择。

### 7.5 钟无昼

**表层性格**：寡言、谨慎，总在行动前计算最坏结果。

**隐藏伤口**：幼年曾听见一场灾难的钟声，却因为无人相信而未能阻止，自此把预见当作责任。

**初始立场**：既然未来可以看见，就有义务选择损失最小的一条。

**关键转折**：霜钟天台的安全预言最终让所有人停止生活；白汀指出被过去定义与被未来定义同样是一种失去自我。

**最终成长**：预见应当提醒选择者，而不是夺走选择。

### 7.6 迦遥

**表层性格**：机敏、爱玩笑、习惯用假话掩护真意。

**隐藏伤口**：她原本的名字和商旅故乡被蜃都吞没。她曾借用死去同伴的名字通过关卡，久而久之不知道哪个身份才算自己。

**初始立场**：真假只取决于能否活下去，没有必要追究。

**关键转折**：镜海的白汀想成为他人，金砂的蜃王则让每个人永远活在想要的假城。她必须第一次主动选择一个名字并承担它。

**最终成长**：“迦遥”不是原名，却是她愿意继续生活、被人记住并承担后果的真名。

### 7.7 风栖迟

**表层性格**：爽朗、爱远行、熟悉各地道路，不愿谈故乡。

**隐藏伤口**：他一直携带一封写给自己的旧信，却不敢拆开；他担心一旦承认故乡已不存在，所有旅行都会失去意义。

**初始立场**：路的价值在于继续前进，停下便会被过去困住。

**关键转折**：失航驿鲸永远移动却没有终点；陆青野指出不肯抵达也是另一种被道路支配。

**最终成长**：道路既允许离开，也允许归还、停留和重新命名终点。

### 7.8 祝红绡

**表层性格**：明亮、善于鼓舞人群，习惯在任何时候维持气氛。

**隐藏伤口**：她认为一旦无人喝彩，自己和昔日戏班就会真正消失。

**初始立场**：只要大家仍然快乐，演出继续并没有错。

**关键转折**：不夜城不允许悲伤和谢幕，演员逐渐成为角色本身；迦遥让她看到虚构的价值来自人能随时走下舞台。

**最终成长**：谢幕承认一段经历已经完成，也为下一场演出留下位置。

### 7.9 槐婆

**表层性格**：慢、直白、对人和虫草一视同仁，常以照料植物的方式评价人。

**隐藏经历**：年轻时为救疫病村落，自愿与菌网共生。她因此活了下来，也失去部分身体和记忆。

**初始立场**：人族无权因为害怕失去自我就拒绝万物相连。

**关键转折**：万菌愿劫让所有生命共享感知，却逐渐不允许任何个体断开；墨榫反问“被连接者是否曾经同意”。

**最终成长**：共生的前提是每个生命仍有说“不”的边界。

## 9. 完整主线剧情脉络

### 9.1 总体结构与关卡开放

主线分三幕。第一幕顺序固定，用于建立世界因果；第二幕可采用半开放结构，玩家在两批境域中选择顺序，但关键揭示按完成数量触发；第三幕在八处主境域完成后开启。

```text
序章/第一章：青岚旧庭
→ 第二章：赤炉天工城
→ 第三章：镜海沉市
→ 第二幕第一批：霜钟天台、金砂蜃都、云鲸驿
→ 第二幕第二批：百戏不夜城、万菌幽谷
→ 第三幕：天衡天心
```

这种结构既保证主线连贯，又避免角色和地图完全一一绑定。

### 9.2 序章与第一章：青岚旧庭——无人归来以后，守护如何结束

#### 开场

陆青野在青岚山脚避雨，听见废弃旧庭传出三声剑鸣。山下人都说旧庭百年无人，他却认为既然有剑鸣便可能有人被困，独自翻墙进入。

庭中阳光明亮，草木覆盖石阶，纸鹤、草灵和剑傀仍在活动。无名残剑在靠近藏剑廊时第一次自行出鞘，青岚剑匣随之苏醒。

#### 愿劫核心

青岚门人断衡前留下最后古誓：“守庭至归人。”门人没有回来，守庭剑傀却无法承认守护对象已经消失。百年愿念使整座外庭反复进行迎客、试剑、封门和等待。

#### 地域目标

玩家依次唤醒听风台、引风台和止衡台。每座风脉台都揭示一层真相：

- 青岚并非普通剑宗，而是止衡剑庭。
- 断衡之夜，旧庭大部分门人前往地下剑阙后再未返回。
- 近期有来自天衡天心的衡律试图重新牵动旧庭。

#### 中段与角色冲突

试剑傀·折枝仍按百年前规矩试炼来客。陆青野不愿被称为传人，却必须借青岚剑意通过试炼。此处建立他的核心矛盾：拒绝别人安排身份，不等于可以拒绝眼前责任。

#### 最终 Boss

守庭剑傀·听风经历“守门”“听风”“旧誓不散”三阶段。三座风脉台分别削弱假剑鸣、残剑和交叉风痕。

陆青野最后斩开的不是听风本体，而是“必须等到旧人归来才能停止守护”的死誓。听风化为守风灵，旧庭第一次真正迎来新的居住者。

#### 章节结尾

宁照微带守衡司抵达，要求封存剑匣和止衡台，认为青岚旧契再次苏醒会引发第二次断衡。两人争执时，剑匣显现一缕赤色炉灰脉痕：赤炉天工城的愿劫正在外溢。

宁照微决定同行监督，陆青野则认为有人受困便应先去。旧庭成为据点。

#### 本章揭示

- 青岚旧庭是止衡外庭。
- 青岚剑斩的是道契，不是自然灵脉。
- 天衡天心正在苏醒。
- 沈停云曾与旧庭有关，但未说明身份。

### 9.3 第二章：赤炉天工城——炉火为何而燃

#### 开场

赤炉城外昼夜通红，废弃铁轨自行运转，城中不断铸出无人需要的器物。天工百门正在救援，守衡司则担心炉火重新接上祖脉。

墨榫与槐婆都在此出现：墨榫负责拆解失控机关，槐婆则发现炉灰中生出会吞食金属的菌群。二人对“先拆机器还是先保住新生菌群”立刻发生冲突。

#### 旧愿

天倾年代，赤炉工匠曾许愿：“愿炉火永不熄灭，愿世间再无人因缺少器物受苦。”天衡盛世中，这份愿望支撑了无数救灾器物。断衡后，愿望只剩“永不熄灭”，却失去“为谁铸造”的回应。

#### 主要事件

- 玩家关闭三条失控炉道，但发现关闭只会让母机转移炉火。
- 城中幸存工坊主要求保留母机，因为现实地域仍依赖其器物。
- 天工百门提出重设铸造名录，守衡司主张封炉。
- 墨榫发现母机使用历代工匠留下的手势和记忆继续铸造，简单摧毁等于抹去他们最后痕迹。

#### Boss：赤炉母机·万铸

万铸的阶段从“百器齐出”到“炉心过盛”，最终将玩家和场地都视作可熔材料。地域目标不是彻底熄火，而是找回三件真正有人等待的器物订单，让炉火重新与具体需求相连。

斩结后，万铸保留有限炉心，只在有人提出目的并承担代价时开炉。

#### 角色推进

- 陆青野第一次听到断衡后有人因没有炉器和道路而死亡，无法再把青岚简单视作英雄。
- 宁照微证明天衡曾真实保护普通人。
- 墨榫发现“零件完好”不代表事物仍应按原方式运转。

#### 本章揭示

- 天衡盛世确实存在，不是守衡司编造。
- 断衡造成过大规模现实灾难。
- 第一次补衡“减鸣”曾在赤炉失败。
- 一名自称迦遥的沙海旅人曾向母机订制不存在的城门，引出后续线索。

### 9.4 第三章：镜海沉市——从他人记忆中醒来的人

#### 开场

镜海潮位异常，白桥在海面反复出现又沉没。风栖迟送来一封无法投递的旧信，白汀则作为听潮引路人带队进入沉市。

#### 旧愿

镜海曾经历大海难，守灯者许愿：“愿沉入海中的人不被遗忘。”天衡替海域保存姓名、声音和最后记忆。断衡后，这些记忆在潮汐中彼此拼合，形成能够思考和选择的新灵。

#### 主要事件

- 玩家点亮三座归潮灯塔，使不同记忆不再混成同一片潮声。
- 守衡司把潮生灵称为残念，宁照微起初同意。
- 部分居民希望从记忆中复活亲人，拒绝承认新灵拥有独立身份。
- 白汀逐渐发现自己并非某一位守灯少女，而是白色沙汀、灯塔和众多亡者记忆共同孕育的存在。

#### Boss：镜海祭主·无归

无归曾负责记录亡者，断衡后成为“让所有记忆归回原主”的执念。他试图把所有潮生灵重新压成亡者复制品。

玩家通过灯塔分开记忆来源，并在战斗后让潮生灵各自选择名字。白汀放弃证明自己是谁的归来，正式以“白汀”作为自己的名字。

#### 章节结尾

当天夜里，所有同行者第一次梦见同一片洁白天空。镜海深处传出天衡律心的声音：“众苦皆由不齐。”

守衡司发布复衡召令，晏玄章认为天心苏醒已不可拖延。旧庭地下同时显现残卷：断衡原计划只持续六十年。

#### 本章揭示

- 境域已经孕育真正的新生命。
- 恢复旧衡可能把这些生命视作异常抹除。
- 第三次补衡“散愿”与镜海愿劫直接相关。
- 天衡律心并非传说，且正在主动召回山河。

### 9.5 第四章：霜钟天台——未来不是命令

#### 开场

霜钟天台的钟声总在事件发生前响起。近期所有星钟都预告同一未来：天衡复归，天下得救，但一切境域新生之物将不复存在。

钟无昼相信这是最少伤亡的道路，陆青野则质疑“既然只能照做，预言还有何意义”。

#### 旧愿

天倾年代，守岁人许愿：“若灾难都能提前被看见，便无人再失去所爱。”星钟原本只提供警示，愿劫形成后，预测开始反过来约束现实。

#### 主要事件

- 玩家校准快钟、慢钟和无声钟，使三种可能未来同时显现。
- 居民为了避开预言停止婚嫁、远行和修行，生活逐渐冻结。
- 白汀指出，自己若只服从过去记忆便不能成为新生命；钟无昼若只服从未来同样如此。

#### Boss：守岁星官·长夜

长夜试图把“伤亡最少的未来”钉死为唯一现实。Boss 会提前显示攻击轨迹，但若玩家始终按提示行动，场地反而越来越狭窄；只有主动偏离部分安全路径，才能开启新的钟位。

斩结后，星钟恢复为警示，不再宣判。

#### 本章揭示

- 同天五兆中的“命轨并流”正在重现。
- 天衡律心并不需要杀死众生，只需让所有选择趋于同一。
- 沈停云三年前曾来过天台，拒绝询问自己能否活着回来。

### 9.6 第五章：金砂蜃都——被承担的名字也可以真实

#### 开场

沙海同时出现数十座城门，每一扇都通向旅人最渴望抵达的地方。迦遥熟悉所有假路，却不肯说明自己为何知道。

#### 旧愿

旧日沙海商旅许愿：“愿每一个迷失者都能看见自己寻找的城。”蜃景原本是救命路标，愿劫后却让人永远追逐最渴望的终点。

#### 主要事件

- 玩家必须辨认“能给出安慰的假城”和“需要承担后果的真路”。
- 白汀与迦遥争论：一个由他人记忆组成的人和一个借来的名字，是否都只能算假。
- 迦遥承认自己曾使用死去同伴的名字穿过城门，如今已不知道原名。
- 城中存在沈停云留下的字：“归处不是别人替你认出的旧名。”

#### Boss：蜃王·照夜

照夜不断展示每名角色最想要的结局：陆青野看见沈停云归来，宁照微看见无灾天下，白汀看见自己被某个家庭认作亡者复生。

玩家必须主动离开这些幻城。迦遥选择继续使用“迦遥”之名，并承诺承担这个名字今后的行为，使其从借名变为真名。

#### 本章揭示

- 真与假不是仅由起源决定，也由之后是否持续承担决定。
- 沈停云正在寻找进入天衡天心的道路。
- 第二座止衡剑庭可能在沙海旧路中留下过痕迹，但不在 1.0 给出完整答案。

### 9.7 第六章：云鲸驿——没有旧故乡以后，道路通向何处

#### 开场

云鲸驿的浮岛相互远离，飞舟撞入重复风道。失航驿鲸长风仍按百年前路线飞行，但许多目的地已经不存在。

风栖迟作为最后一代行路使，携带大量未送达旧信。他坚持只要继续飞，终有一天会找到收信人。

#### 旧愿

驿路众人曾许愿：“愿天下道路永不断绝，远行之人终能归乡。”愿劫却不允许承认故乡已经改变或消失。

#### 主要事件

- 玩家修复的不是旧航线，而是为现存浮岛建立新停靠点。
- 陆青野质问风栖迟：不停离开是否只是害怕承认无处可归。
- 风栖迟拆开写给自己的旧信，内容是家人允许他在故乡消失后选择新的归处。
- 宁照微看到，没有统一天衡，道路维护确实艰难；陆青野也承认连接本身并非错误。

#### Boss：失航驿鲸·长风

长风不会被杀死。战斗中玩家通过新航标逐渐改变其冲锋路线，最终把“必须返回旧驿”改为“可以载人前往新的停靠地”。

#### 本章揭示

- 青岚旧庭进入天衡天心需要多处山河脉痕共同指路，而非一把固定钥匙。
- 连接可以被重新命名，不必等于恢复旧秩序。
- 天衡天心正牵引各地旧路，境域相叠风险上升。

### 9.8 第七章：百戏不夜城——谢幕是下一场开始的条件

#### 开场

不夜城百年未见黎明。城中所有人都在庆祝断衡后幸存的第一夜，演员无法离台，观众也无法离场。祝红绡在城外仍能听见永不停止的喝彩。

#### 旧愿

劫后幸存者许愿：“愿盛世长在，今夜永不散场。”天衡曾以礼乐安定人心，愿劫后却把悲伤、沉默和结束视为不祥。

#### 主要事件

- 玩家帮助不同戏台完成真正结尾，而不是简单熄灯。
- 迦遥指出，戏是假的，但演员能走下台，假才有价值。
- 宁照微在城中看到人人笑着服从，第一次正面承认“稳定也可能伤人”。
- 天衡律心借全城乐声展示没有悲伤的太平幻象。

#### Boss：不散班主·今宵

今宵曾是劫后第一场庆典的班主，他害怕一旦停演，人们就会重新想起死者和灾难。Boss 以喝彩强化攻击，玩家需要主动让观众席出现安静区域。

祝红绡唱完百年前缺失的最后一句，演出谢幕。黎明第一次照进城中，今宵卸下面具而不被抹除。

#### 本章揭示

- 天衡律心由众生对无灾太平的愿望孕育，不是外来邪物。
- “众生同梦”与不夜城的永恒欢乐本质相近。
- 宁照微决定不再支持原样复衡，但仍认为天下需要共同守护。

### 9.9 第八章：万菌幽谷——相连不等于相同

#### 开场

万菌幽谷的菌网开始越过原有边界，进入周边村落。被连接者能共享感知、养分和记忆，却逐渐无法说出自己的名字。

天工百门希望利用菌网修复断裂山河，山海遗盟则要求彻底封谷。槐婆和墨榫分别站在两种方案之间。

#### 旧愿

疫病年代，谷中众生许愿：“愿天地万灵不再孤独赴死，生机彼此相续。”菌网让生命互助，却在愿劫中把拒绝连接视为背叛。

#### 主要事件

- 玩家重建三片菌圃，每片都必须保留可断开的边界。
- 墨榫发现菌网能够修补山河，却不能因此将所有个体视作器件。
- 槐婆承认自己当年自愿共生，不代表后人必须作出同样选择。
- 岑山君也被质问：古老山神是否有权替今日新生命决定何为山河本性。

#### Boss：谷心母菌·万生

万生不是单一个体，而是所有“不要独自死亡”的愿望形成的共感核心。Boss 会连接玩家、敌人和场地，共享伤害与恢复。

斩结的关键是创造可自由接入和退出的菌路。万生最终分化为多个互相呼应但不吞没彼此的菌群。

#### 第二幕结尾

八处主境域的山河脉印在青岚旧庭同时发光，地下止衡剑阙开启。天衡天心向天下发出归律之声，守衡司、天工百门和山海遗盟分别准备自己的方案。

晏玄章计划在灾劫彻底失控前重悬天纲；公输砚希望以新器承载律心；岑山君主张斩断十二祖脉古约。陆青野一行决定先进入天心，看见完整真相后再出剑。

#### 本章揭示

- 境域新生命和新生态已经成为当代山海的一部分。
- 原样恢复旧衡会使律心将其判作偏差。
- 共生与连接本身不是错，问题是是否允许边界和退出。

### 9.10 第九章：天衡天心——最后一剑不替天下决定一切

#### 进入天心

青岚旧庭地下止衡剑阙开启。八枚山河脉印不是八把钥匙，而是八种不同山河回应，共同让剑匣辨认出一条不会立即被律心同化的道路。

进入后，玩家看见十二祖脉横贯虚空，沿途叠加八处境域规则。每一段路都要求玩家使用此前理解过的斩结方式，而不是只进行数值战斗。

#### 沈停云真相

天心深处存在一道持续三年的剑痕。沈停云以自身道基维持这条缝隙，让后人仍能进入律心无法完全控制的地方。

他告诉陆青野：

- 无名残剑只是青岚旧剑碎片，没有王血、天命或唯一传人资格。
- 剑匣回应陆青野，是因为他听见剑鸣后先想到有人被困，并在获得传承时仍拒绝让身份替自己决定。
- 沈停云没有留下应选哪一种尾声，因为替后人决定正是青岚旧人最容易再犯的错误。

沈停云最后散入剑痕，不直接参加结局选择。

#### 完整历史回放

天心以十二开衡者道影展示完整历史：天倾、开衡、盛世、同天五兆、五次补衡、三剑庭断契和愿劫爆发。玩家确认：

- 天衡有功。
- 万象归律真实存在。
- 断衡并非轻率，却造成远超预期的代价。
- 律心没有被邪魔污染，它仍在完成“免除灾劫”的古誓。

#### 四方到来

晏玄章、公输砚和岑山君分别进入天心外层。三人不会进行现代议会式辩论，而是以各自修行和承诺展示选择：

- 晏玄章以律符护住正在崩裂的祖脉，证明天下仍需要共同守护。
- 公输砚以百器承接余波，证明人可以修补天道，但器物也承受不住无限愿力。
- 岑山君唤回山河真名，证明万物可以各自生长，却也有弱小山灵因失去共同庇护而衰弱。

#### 最终 Boss：天衡律心

**第一阶段·衡天无差**：律心把不同角色技能压成相同形态，象征万灵同根。玩家通过本命机制恢复差异。

**第二阶段·万象归一**：八处境域规则被强行叠合，律心试图证明所有矛盾都可由一律消除。此前完成的地域目标在此提供反制。

**第三阶段·一念太平**：战场化为洁白无灾的世界。角色没有伤痛，也没有明显差异；只要玩家停止移动便不会受伤，但同行者会逐渐失去名字。玩家必须主动前行并唤回每人的本命器。

**终阶段·天心问衡**：律心不再以敌意攻击，而是询问玩家愿意承担何种代价。最后一剑进入三种尾声分支。

## 10. 主要谜团与揭示顺序

| 谜团 | 初始误导 | 中段证据 | 最终真相 |
|---|---|---|---|
| 青岚宗是什么 | 废弃剑宗、可能擅自毁掉天衡 | 风脉台、止衡残卷、各地对断衡的不同记忆 | 三座止衡剑庭之一，只承担共同断衡的最后一剑 |
| 天衡是什么 | 古代失控大阵或压迫工具 | 赤炉证明其繁荣，云鲸证明连接价值 | 上古救世之阵，后来因古誓僵化走向万象归律 |
| 律心是否邪恶 | 像幕后反派一样召回诸域 | 百戏揭示其来自太平愿望 | 无恶意的道胎，错误在于不允许变化 |
| 沈停云身份 | 普通老剑客或青岚掌门 | 多地留下拒绝预言、拒绝归处的痕迹 | 青岚幸存问剑人，以身化剑痕，不留下标准答案 |
| 陆青野是否天命传人 | 剑匣选中、残剑苏醒 | 他没有血脉证明，也不断拒绝身份 | 剑匣回应的是行动和选择；不存在唯一命定继承人 |
| 白汀是谁 | 某位亡者复生 | 记忆来源彼此矛盾 | 由地域和多人记忆形成的新生命，自选名字 |
| 为什么现在苏醒 | 某势力秘密启动 | 复衡大醮、共同白梦、八境同时异动 | 百年愿力回流、愿劫成熟与人为复衡共同促成，无单一幕后黑手 |
| 三种尾声谁正确 | 共衡似乎最温和 | 每章都展示连接、共同守护和地方边界的双重价值 | 三者各有不可消除的代价，不设无损答案 |

## 11. 角色关系变化节奏

### 11.1 陆青野与宁照微

- 青岚：一人要开庭救人，一人要封庭止灾。
- 赤炉：宁照微迫使陆青野看见断衡代价。
- 镜海：陆青野迫使宁照微承认新生命。
- 云鲸：二人共同承认天下需要道路，但道路不等于唯一归处。
- 百戏：宁照微明确反对强迫的稳定。
- 天心：陆青野负责作出最后动作，宁照微负责说明选择之后仍需有人守护边界。

### 11.2 墨榫与槐婆

- 赤炉：墨榫要拆炉救城，槐婆先保护炉灰新生菌。
- 旧庭日常：二人共同经营百工台和灵圃，不断争论器物与生命边界。
- 万菌：立场反转，墨榫要求尊重个体，槐婆承认共生也会越界。

### 11.3 白汀与钟无昼

一个被过去定义，一个被未来定义。两人的共同结论是：人不能只由已经发生或尚未发生的事决定，真实存在于当下持续选择。

### 11.4 迦遥与祝红绡

一个用假名生存，一个用角色被人记住。她们共同证明虚构并非天然虚假，关键在于人能否自由进入、离开并承担它。

### 11.5 风栖迟与陆青野

两人都通过移动获得力量。风栖迟让陆青野看见“不停离开”也可能被旧伤控制；陆青野则帮助风栖迟接受道路可以有新终点。

## 12. 三种尾声与人物后日谈

### 12.1 复衡·重悬天纲

#### 完成方式

玩家与宁照微共同重刻天衡古誓，将“不得夺万物真名、地方可启止衡、律心须接受后世问剑”写入天心。十二祖脉再次同鸣，但青岚剑匣作为永久止衡之证留在天心外。

#### 世界变化

四时、道路和大型灾害迅速稳定，弱小地域重新获得共同庇护。代价是天下再次依赖天衡；任何约束都可能在后世被解释、遗忘或撤去。

#### 主题

不是相信天律永远正确，而是选择让受约束的共同天纲承担保护责任。

### 12.2 共衡·万脉同鸣

#### 完成方式

玩家斩开唯一律心，将其道印分化为多枚“山河衡印”。十二祖脉仍彼此感应，但不再由单一意志决定何为正确。各地在灾劫时主动鸣应，平日保留自身脉性。

#### 世界变化

连接和差异同时保留，但每次大灾都需要多地回应。有人可能拒绝，有人可能失约，强大的地域也可能在共同鸣应中影响弱者。

#### 主题

不追求永远正确的天律，而是让不同山河持续承担彼此。

### 12.3 开界·山海自生

#### 完成方式

玩家以青岚最后一剑彻底解开十二祖脉之间的古老道契。天衡不再作为覆盖天下的整体存在，祖脉回归山海，各地自行形成新的关系。

#### 世界变化

万物获得最大的生长可能，旧天衡不再有机会归律。与此同时，天灾、隔绝、妖潮和弱地无援会重新出现，凡人必须重建许多已经失传的地方能力。

#### 主题

选择让山海承担自身风险，也承认自由不是没有代价。

### 12.4 九名角色后日谈

| 角色 | 重悬天纲 | 万脉同鸣 | 山海自生 |
|---|---|---|---|
| 陆青野 | 不任天心之主，成为定期问剑的游者，确保古誓仍可被斩 | 作为第一名行脉剑使，在诸地衡印之间传递回应 | 将旧庭山门永远留出一扇不题名的门，继续寻找未被记入脉图的道路 |
| 宁照微 | 成为新守衡者，朱律符第一条写“律有边，后人可改” | 放弃唯一律印，建立只在诸地自愿鸣应时成阵的符法 | 离开守衡司中枢，帮助弱小地域重建地方护脉术 |
| 墨榫 | 制作可被地方关闭的天衡维护器，终生警惕器物替人作主 | 为各地制造互相兼容但不强制相同的鸣器 | 走遍断路地区，帮助他们找回失传的水利、炉火和舟车技艺 |
| 白汀 | 新古誓正式承认潮生灵，她在镜海建立“自名灯塔” | 保存各地不同记忆，不允许它们被汇成唯一历史 | 带领潮生灵离开旧海，选择各自形体和寿命 |
| 钟无昼 | 守望天衡未来偏移，但星钟只警示不宣判 | 将主钟拆成多枚小钟，只有相互回应时才共鸣 | 敲碎最后一座定命钟，开始记录人们改变预言的故事 |
| 迦遥 | 成为新天衡道路上的蜃景引路人，所有幻城必须标明可离开之门 | 建立流动蜃市，让不同地域交换故事和名字 | 让蜃都随沙海迁徙，不再承诺唯一归处 |
| 风栖迟 | 重开跨域驿路，同时保留绕开天衡的民间小道 | 成为衡印间的信使，只运送主动托付的书信 | 送完百年前最后一封旧信，为无路之地重新绘图 |
| 祝红绡 | 为复衡后的第一场庆典写下明确谢幕词 | 组织巡回戏班，每一地自行改写结尾 | 在真正黎明中搭起可随时拆走的戏台，不让任何城永久困住演员 |
| 槐婆 | 争取新古誓承认非人生命，并保留菌网退出边界 | 让不同菌群各守自名，需要时共享生机 | 放任幽谷继续演化，同时教周边村落如何拒绝不愿接受的共生 |

### 12.5 结局后的扩展兼容

1.0 后多数新增主境域默认发生在进入天衡天心之前，可作为第二幕“新巡脉卷”插入，不指定唯一尾声。

若制作结局后内容，核心章节可共用，但开场、部分环境状态和结尾根据三种世界状态调整。只有续作正式立项并明确需要时，才决定是否选择某一尾声为正史。

## 13. Demo 剧情演出基线

### 13.1 Demo 叙事目标

Demo 必须让玩家在一次完整闭环中理解以下内容：

- 青岚旧庭不是普通废墟。
- 陆青野不是血统命定的传人。
- 愿劫来自一个可以理解的旧愿。
- 地域目标会改变 Boss 因果和战斗规则。
- 斩结不是摧毁所有异常，而是让旧愿可以结束。
- 天衡天心正在重新牵动旧庭，完整版主线已经启动。

### 13.2 开场演出

1. 雨落青岚山脚，陆青野在破亭避雨。
2. 第一声剑鸣来自山上，山民说是风吹残钟。
3. 第二声剑鸣时，无名残剑轻震。
4. 第三声剑鸣后，陆青野看见旧庭山门内一盏灯亮起。
5. 他不是为了寻宝或继承宗门，而是说：“三声都没人应，总得上去看一眼。”

### 13.3 关卡内叙事节拍

| 阶段 | 叙事内容 |
|---|---|
| 0—3 分钟 | 教学与生活痕迹；旧庭不是阴森墓地，而是被草木重新占据的住处 |
| 第一精英后 | 剑匣苏醒，只称陆青野为“持剑之人”，不称少主或天命传人 |
| 第一座风脉台 | 听见弟子日常笑声，建立旧庭曾真实生活过 |
| 3—6 分钟 | 藏剑廊与药圃分别提供沈停云和止衡剑庭线索 |
| 中段 Boss | 折枝执行试剑规矩，陆青野拒绝拜祖却仍完成试炼 |
| 第二座风脉台 | 得知守庭者等待的是不会归来的人 |
| 6—10 分钟 | 衡律外溢，敌群出现短暂同形化，预示万象归律 |
| 第三座风脉台 | 压下来自天心的牵引，听风进入最终区域 |
| 最终 Boss | 三阶段对应守门、辨风和拒绝结束旧誓 |
| 胜利演出 | 陆青野不毁听风，斩去“必须等旧人”的誓；新风吹过庭院 |
| 据点结尾 | 宁照微抵达要求封庭；赤炉脉痕显现，完整版下一章成立 |

### 13.4 关键对白方向

以下对白只锁定语义，不锁定最终字句：

- 陆青野：“我只是听见有人敲门。至于门后是谁，进去再说。”
- 剑匣：“旧庭已空。持剑者为何而来？”
- 陆青野：“因为它响了三声。”
- 折枝：“无拜帖，无师承，不得入剑庭。”
- 陆青野：“那我不入门。我只借条路。”
- 听风：“守庭至归人。”
- 陆青野：“他们不回来了。你守的若是他们，就该让这地方继续活。”
- 宁照微：“你今日斩的是一具剑傀，还是百年前留下的界？”
- 陆青野：“我还没看清。所以我要去下一处。”

### 13.5 Demo 结束时不得提前揭示

- 不直接说明同天五兆全部内容。
- 不确认沈停云已经身在天衡天心。
- 不说明白汀的真实身份。
- 不展示三种结局名称。
- 不把守衡司描写成敌对邪派。

## 14. 后续区域与角色扩展准则

### 14.1 新区域设计模板

新增区域至少回答：

1. 现实地域是什么，普通人如何生活。
2. 山河脉性是什么，但不得简化为单一元素。
3. 最初旧愿为何值得理解。
4. 什么天衡残律、历史因果或当代行为使旧愿成为愿劫。
5. 境域中已经产生了哪些不应被简单清除的新事物。
6. 地域目标如何改变 Boss 的因果条件和战斗规则。
7. 它对至少两名既有角色产生何种不同触动。
8. 斩结后保留什么、放下什么、留下什么后患。

### 14.2 新角色设计模板

新增角色独立定义：

- 出身地域或流动来历。
- 当前道统与关系，不必与出身相同。
- 个人伤口与真正需要作出的选择。
- 本命器、独有机制和战斗节奏。
- 至少两条跨地域关系。
- 加入方式，不要求配套专属地图。

### 14.3 可用扩展入口

- 十二祖脉沿线尚未显现的现实地域。
- 未纳入天衡的野脉文明。
- 断衡后脱离旧路、自行生长的逸脉。
- 两处已知境域发生交叠。
- 当代宗门人为制造的新愿劫。
- 沧溟或照岳止衡剑庭遗迹。
- 海外、地下、云上和山河真名之外的空间。
- 三种尾声下同一地域的不同后日谈。

### 14.4 禁止的扩展方式

- 为了新增地图而增加“第十三祖脉”。
- 把每个地域硬配一名代表角色。
- 每个新境域都重复“某项古代功能失控”。
- 用更大的幕后邪神否定天衡律心的主题责任。
- 宣布过去所有复杂选择都是某个反派操纵，从而抹去人物责任。
- 默认共衡是唯一正确结局，并把其他尾声写成失败线。

## 15. 开发落地时的剧情校验清单

每个主线关卡、角色故事或藏品文本提交前，应检查：

1. 是否使用世界内语言，而不是直接说网络、权限、中心化或系统优化。
2. 是否明确当地普通人的生活，而不只展示哲学命题。
3. 愿劫最初愿望是否值得理解。
4. Boss 是否有继续执行旧愿的理由。
5. 地域目标是否在叙事和战斗上真实改变灵结。
6. 斩结后是否保留了某种新生，而不是一键恢复原状。
7. 是否同时展示相关道统的贡献与风险。
8. 角色是否作出具体选择，而不只是发表观点。
9. 是否避免角色与地图、祖脉和职业的一一绑定。
10. 新信息是否符合既定揭示顺序，未提前泄露终局真相。

## 附录 B：主线核心判断

整部游戏最终必须让玩家理解：

> 天衡的错误不是让天下彼此连接，而是让连接失去边界；断衡的意义不是证明分离天然正确，而是为万物保住重新选择的可能。百年后的主角不能只重复复衡或断衡，而必须在看见功绩、罪责与新生之后，亲自承担下一种山河关系的代价。
