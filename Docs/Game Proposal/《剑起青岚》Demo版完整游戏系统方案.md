# 《剑起青岚》Demo版完整游戏系统方案

**版本：V1.0**
 **项目类型：中国风 Survivors-like 动作 Roguelite**
 **开发引擎：Unity 6 LTS / Universal 2D**
 **Demo主题：青岚旧庭垂直切片**
 **核心角色：陆青野（暂定名）**

------

## 1. 文档目标

本方案定义《剑起青岚》Demo版的完整产品、玩法、内容和技术范围。

Demo不是单纯验证“角色能移动、敌人会追踪、技能能造成伤害”的技术原型，而是一段可以完整运行的垂直切片，必须覆盖：

```
启动游戏
→ 进入青岚旧庭
→ 移动和自动战斗
→ 获取经验并升级
→ 构筑武器与心诀
→ 探索地标和风脉节点
→ 击败精英并取得奇物
→ 完成器法合鸣
→ 击败中段Boss
→ 击败最终Boss
→ 完成胜利或失败结算
→ 返回青岚旧庭
→ 解锁故事和局外成长
→ 调整配置并开始下一局
```

只有这条流程可以反复稳定运行，Demo才算完成。

## 2. 产品定位

### 2.1 一句话定位

玩家扮演一名自由行走天下的少年剑客，在阳光明媚、草木重新覆盖的青岚宗遗址中自动御剑战斗，通过“天下百器、诸脉心诀、战场奇物”构成流派，疏通失控风脉，并让荒废百年的青岚旧庭重新焕发生机。

### 2.2 核心特色

#### 清朗的中国幻想

游戏存在废墟、失落和历史伤痕，但不以黑暗、阴森、尸骸和末日作为主色调。

青岚旧庭应呈现：

- 暖色阳光；
- 青绿草木；
- 石缝野花；
- 青苔断墙；
- 废弃亭台；
- 风吹旧剑；
- 明亮天空；
- 动物和植物重新占据遗迹。

核心视觉主题是：

> 人已经离开，但世界仍在生长。

#### 世界观直接进入构筑系统

公共武器不是没有来历的技能图标，而是来自天下不同地域、宗门、机构和文明的器物。

公共被动也不是单纯的“攻击力增加10%”，而是来自不同修行体系的功法、身法、心诀和观想法。

#### 移动本身是战斗表达

初始角色陆青野通过持续移动积累风势。

玩家不是被动绕圈，而是在以下目标之间主动规划路线：

- 维持角色机制；
- 穿越敌群；
- 收集经验；
- 寻找地标；
- 激活风脉节点；
- 接近精英；
- 避开Boss技能。

#### 探索必须产生收益

地图不是单纯的战斗背景。

玩家主动前往地图边缘、危险区域和特殊地标，能够获得：

- 本局经验；
- 战斗灵物；
- 显化宝匣；
- 唯一藏品；
- 故事残页；
- 局外嵌片；
- Boss削弱效果。

#### 局外成长提供选择，而不是无脑碾压

局外成长主要强化：

- 构筑控制能力；
- 角色机制分支；
- 探索能力；
- 容错；
- 开局倾向。

永久纯数值提升必须保持克制。

## 4. 世界观摘要

### 4.1 天衡十二脉

过去的天下由十二条横贯山海的巨大灵脉连接。

灵脉不仅输送灵气，也传递：

- 水汽；
- 季候；
- 物产；
- 技艺；
- 声音；
- 记忆；
- 不同文明之间的联系。

这个时代被称为“天衡纪”。

### 4.2 断衡之变

百年前，十二条灵脉同时失去平衡。

现实山河与灵脉积累的记忆、执念、技艺和自然力量相互重叠，形成拥有独立规则的局部空间：

## 境域

境域不是纯粹幻境，也不是另一个世界，而是现实与灵脉记忆重叠后的异常山河。

### 4.3 境域中的敌对存在

#### 荒灵

被灵脉强化的草木、动物、岩石和自然现象。

#### 遗械

旧时代遗留的机关、傀儡、守卫和自动设施。

#### 祟念

历史记忆、职责和执念形成的重复幻象。

#### 逐脉者

主动进入境域探索、掠夺、修复或争夺资源的人类。

### 4.4 青岚宗

青岚宗并非天下最强宗门，而是负责巡查和疏通灵脉的巡脉宗门。

青岚弟子擅长：

- 听风辨脉；
- 御剑寻路；
- 斩断灵结；
- 调和不同地域的力量；
- 学习并兼容天下百家技艺。

断衡之夜，青岚宗主力进入灵脉深处，此后再未返回。

## 5. 第一关：青岚旧庭

### 5.1 地理与历史

青岚旧庭曾是青岚宗的外庭，包括：

- 新弟子练剑场；
- 药圃；
- 藏剑廊；
- 迎客亭；
- 风脉观测台；
- 通往内山的山门。

百年无人管理后，建筑逐渐坍塌，但风气和木气持续外溢，使这里成为异常旺盛的生命之地。

### 5.2 关卡异常

旧庭中的训练机关仍在执行百年前的最后命令：

> 在宗门弟子全部归来以前，不得开启内山门。

风脉重新运转后，旧庭将玩家判断为“未通过考核的闯入者”。

于是以下存在陆续苏醒：

- 木制剑傀；
- 纸鹤符灵；
- 药圃草灵；
- 石灯守卫；
- 失去主人的练习飞剑；
- 风铃和旧庭机关。

### 5.3 关卡主题

青岚旧庭不是“覆灭宗门的坟墓”，而是：

> 旧秩序已经停下，生命却仍在继续。

## 6. 初始角色：陆青野

### 6.1 基本定位

陆青野约十八九岁，没有正式门派归属。

幼时跟随一名身份不明的老剑客生活，学到一些不成体系的剑术。老剑客离开以后，他带着一柄普通旧剑独自游历。

他会：

- 替村民驱赶荒灵；
- 帮商队护送一段路；
- 在山寺屋檐下避雨；
- 为了一处好风景多留几天；
- 没钱时认真考虑是否卖掉自己的剑。

他的自由不是轻浮和逃避，而是：

> 不愿让宗门、身份和所谓命运替自己决定道路。

### 6.2 性格关键词

- 清朗；
- 松弛；
- 有分寸；
- 不服安排；
- 对世界保持好奇；
- 真正需要拔剑时不会退后。

### 6.3 外形方向

- 略微凌乱的黑色或深棕短发；
- 青灰、米白和暖棕配色；
- 轻便窄袖短袍；
- 深色束腿裤；
- 轻便布靴；
- 不对称短斗篷；
- 修补过的旧剑鞘；
- 腰间可挂酒葫芦或小布包。

角色轮廓要表现：

> 轻、快、自由，像随时准备继续上路。

### 6.4 进入旧庭的原因

陆青野在山脚避雨时，听见旧庭深处连续传来三声剑鸣。

他以为有人被困，于是翻过断墙进入遗址。

青岚剑匣随后苏醒并选择了他。

他的反应不是接受天命，而是：

> “你先别急着认主，我还没答应呢。”

## 7. 角色专属机制

### 7.1 本命器：游风剑

游风剑会自动寻找附近敌人，沿弧线穿刺目标后返回角色身边。

它不是固定围绕玩家旋转的武器，而是表现为：

```
放出
→ 寻敌
→ 穿刺
→ 回返
→ 再次蓄势
```

### 7.2 独有机制：乘风

角色持续有效移动时积累风势。

风势分为四个阶段：

| 阶段 | 效果                               |
| ---- | ---------------------------------- |
| 静风 | 无加成                             |
| 微风 | 游风剑飞行速度提高                 |
| 疾风 | 攻击间隔缩短，移动速度略微提高     |
| 乘风 | 游风剑攻击结束后额外产生一道弱风刃 |

补充规则：

- 原地贴墙不能积累风势；
- 停止移动后风势逐渐衰减；
- 受伤只降低一档，不全部清空；
- 升级和暂停期间冻结风势；
- 风势通过脚下风纹、衣摆和剑穗表现，不额外增加复杂能量条。


## 10. 基础属性体系

Demo只保留以下标准属性，禁止为单个武器随意新增同义属性。

| 属性       | 作用                                 |
| ---------- | ------------------------------------ |
| 最大生命   | 玩家生命上限                         |
| 生命恢复   | 按时间或条件回复生命                 |
| 护甲       | 降低受到的伤害                       |
| 移动速度   | 玩家移动速率                         |
| 威力       | 通用伤害倍率                         |
| 攻击间隔   | 武器两次触发之间的时间               |
| 作用范围   | 投射物、爆炸和领域尺寸               |
| 持续时间   | 领域、召唤物和状态持续时间           |
| 投射物速度 | 投射类武器飞行速度                   |
| 投射物数量 | 单次触发的实体数量                   |
| 穿透       | 投射物可额外命中的敌人数             |
| 暴击率     | 触发暴击概率                         |
| 暴击伤害   | 暴击伤害倍率                         |
| 击退       | 改变敌人位置的强度                   |
| 拾取范围   | 自动吸收经验和掉落的距离             |
| 经验获取   | 经验收益倍率                         |
| 幸运       | 影响稀有灵物、候选质量和宝匣附加奖励 |

幸运不能影响：

- 首次Boss脉印；
- 唯一故事残页；
- 必定获得的关键解锁。

## 11. 伤害与状态规则

### 11.1 伤害结算

统一经过伤害结算器：

```
基础伤害
× 武器等级倍率
× 玩家威力倍率
× 条件增伤
× 暴击倍率
× 敌人承伤倍率
× 难度倍率
= 最终伤害
```

武器脚本不能绕过统一伤害管线。

### 11.2 状态效果

| 状态 | 作用                         |
| ---- | ---------------------------- |
| 灼烧 | 周期性持续伤害               |
| 中毒 | 可以叠层的持续伤害           |
| 减速 | 降低移动速度                 |
| 定身 | 无法移动，但仍可执行部分行为 |
| 标记 | 被特定攻击触发额外效果       |
| 破甲 | 临时提高目标受到的伤害       |
| 击退 | 改变普通敌人的位置           |

Boss不会被完全冻结或无限控制。

## 14. 器法合鸣

### 14.1 世界观解释

武器本身只是“器”，心诀决定力量运行方式。

当二者契合时，武器会显露真正形态：

> 器有其性，法有其路；器法相合，真名显化。

### 14.2 触发条件

```
基础武器达到最高等级
+
对应心诀达到指定等级
+
开启显化宝匣
=
完成器法合鸣
```

不能满足条件后立即自动进化，必须通过精英或中段Boss掉落的显化宝匣完成。

### 14.3 Demo显化关系

| 基础武器 | 心诀   | 显化形态     | 核心变化                     |
| -------- | ------ | ------------ | ---------------------------- |
| 游风剑   | 踏风步 | 青岚流影剑   | 飞剑留下风痕，满风势产生剑影 |
| 镇邪黄符 | 清心诀 | 太一镇灵符阵 | 单发符箓转化为环形符阵       |
| 离火飞轮 | 御器篇 | 赤炉百工轮   | 增加飞轮并在回返时连锁爆裂   |
| 听潮珠   | 开域法 | 镜海潮生轮   | 涨潮吸附、退潮击退并爆发     |
| 震岳印   | 长息功 | 山河镇界印   | 形成短时安全领域并反震       |
| 灵藤种   | 采灵诀 | 地脉生春枝   | 藤丛相互连接并持续扩张       |

## 15. 升级选牌

### 15.1 槽位

- 武器槽：4个；
- 心诀槽：4个；
- 战场奇物槽：3个；
- 本命器占用1个武器槽；
- 即时战斗灵物不占槽。

### 15.2 选牌规则

每次升级展示3个候选：

- 新武器；
- 新心诀；
- 已持有武器升级；
- 已持有心诀升级；
- 无有效选项时的灵砂、治疗或临时增益。

每局默认拥有：

- 1次免费刷新；
- 1次放弃。

系统需要提供最低限度的构筑保护：

- 已持有内容必须有合理概率继续出现；
- 至少存在一条可完成的显化路线；
- 不连续多次提供完全无协同内容；
- 不保证最优构筑，仍保留随机性。

## 16. 即时战斗灵物

| -------- | -------------------------------------------- |
| 青木露   | 恢复生命，满血时少量转为护盾                 |
| 定界符   | 普通敌人短暂停止，精英和Boss大幅减速         |

## 17. 精英与战场奇物

### 17.1 异相灵核

精英死亡后固定掉落异相灵核。

规则：

- 最多装备3个；
- 同名奇物重复获得时升级；
- 最高3级；
- 普通升级池无法获得；
- 主要改变规则，不应只是简单增加伤害。

## 19. 刷怪导演

不能采用“每秒固定生成若干敌人”的简单逻辑。

导演系统根据以下条件安排敌人：

- 当前时间；
- 当前阶段；
- 场上敌人数；
- 地图区域；
- 精英和Boss状态；
- 性能实体上限；
- 随机种子。

同一生成预算可以组合为：

```
20只草灵
或
10只草灵＋2只剑傀
或
8只纸鹤＋1只石灯守卫
```

普通敌人默认在屏幕外生成。

特殊敌人可以从：

- 山门；
- 草丛；
- 机关台；
- 风脉裂隙；
- 倒塌建筑；

进入战场。

不根据玩家当前伤害实时增加敌人生命，避免强橡皮筋机制。

## 21. 地图结构

地图采用有限边界的大型手工地图，而不是无限循环地图。

建议划分为五个区域：

### 中央练剑场

- 开局区域；
- 地形开阔；
- 适合基础交战；
- 后期高压敌潮集中地。

### 西侧药圃

- 草木密集；
- 灵植和恢复道具较多；
- 触发药圃复苏事件。

### 东侧藏剑廊

- 残剑、剑架和机关敌人较多；
- 存在封存匣；
- 可触发旧剑共鸣。

### 北侧旧山门

- 最终Boss入口；
- 主要视觉地标；
- 听风剑傀驻守区域。

### 南侧迎客庭

- 亭台、浅水和石灯；
- 远程敌人较多；
- 可发现旧信和角色故事线索。

地图中心保持简洁，细节主要分布在边缘和地标附近。

------

## 22. 风脉节点

地图中存在3座风脉节点。

玩家需要在节点范围内停留并完成激活。

每激活一座：

- 获得经验；
- 获得少量恢复；
- 削弱最终Boss的一项能力。

未激活节点分别强化Boss：

1. 风场移动速度；
2. 残剑数量；
3. 剑气范围。

激活全部节点后，Boss战前提供额外显化宝匣或高品质治疗。

节点不是硬性胜利条件，玩家可以直接挑战强化版Boss。

------

## 23. 地图事件

### 风脉暴动

- 全场风向可视化；
- 敌人移动速度略微提高；
- 玩家投射物速度提高；
- 事件结束后生成聚灵葫芦。

### 药圃复苏

- 西侧药圃出现大量草灵；
- 同时生成灵植和治疗资源；
- 完成击杀目标后获得藏品线索。

### 旧剑共鸣

- 场景残剑短暂升空攻击敌人；
- 玩家在共鸣期间进入藏剑廊，可以开启封存匣。

## 25. 中段Boss：试剑傀·折枝

### 技能

#### 横枝试剑

向前方发动宽扇形横扫。

在玩家预测位置落下三道延迟剑影。

#### 演武木桩

召唤训练木桩，持续释放小型剑气。

## 26. 最终Boss：守庭剑傀·听风

### 阶段一：守门

- 定向剑气；
- 短距离冲锋；
- 扇形斩击。

目标是教玩家观察前摇并保持侧向移动。

### 阶段二：听风

生命降至70%后展开风场：

- 风场改变投射物轨迹；
- 残剑形成旋转剑路；
- 未激活节点强化对应技能。

### 阶段三：旧令不散

生命降至35%后：

- 场地出现交叉风痕；
- 延迟后爆发；
- 听风在不同安全区域之间跳转；
- 技能组合密度提高，但不单纯增加生命。

### 首次击败奖励

- 青岚境主脉印；
- 唯一藏品“听风旧铭牌”；
- 陆青野第三篇故事；
- 解锁万象阁；
- 开启下一境域线索。

最终Boss死亡后本局结束，因此不掉落只能在本局继续使用的遗器。

## 27. 胜利、失败与结算

### 胜利条件

击败守庭剑傀·听风。

### 失败条件

玩家生命降至0且没有可触发的免死效果。

### 无论胜败均保留

- 已获得灵砂；
- 唯一藏品；
- 行迹残页；
- 角色经验；
- 图鉴记录；
- 设置项；
- 挑战统计。

### 仅完成相应条件后保留

- 境主脉印；
- Boss主线篇章；
- 首通设施；
- 胜利挑战奖励。

### 结算界面

展示：

- 胜利或失败；
- 生存时间；
- 击杀数量；
- 各武器伤害；
- 最高伤害武器；
- 器法合鸣；
- 精英和Boss击杀；
- 风脉节点；
- 藏品；
- 灵砂；
- 角色经验；
- 新解锁内容。

## 30. 角色行脉图

陆青野拥有12个节点，分为三条路线。

每次出发最多激活6个节点，只能选择1个终端节点。

重置免费。

### 本命路线

- 提高游风剑索敌范围；
- 提高返回路径伤害；
- 满风势时追加剑影；
- 终端：青岚流影剑增加折返追击。

### 身法路线

- 加快风势积累；
- 快速转向获得短暂碰撞宽容；
- 受伤后获得移动加速；
- 终端：满风势移动轨迹留下风痕。

### 心性路线

- 增加一次刷新；
- 第一个异相灵核多一个候选；
- 更容易出现与本命器相合的心诀；
- 终端：开局选择御剑、游风或探寻倾向。

行脉图主要改变机制，不应提供大量永久攻击力。

## 39. 性能方案

### 目标

| 对象             | 常态          | 压力测试           |
| ---------------- | ------------- | ------------------ |
| 活跃普通敌人     | 400—800       | 1200               |
| 玩家投射物和领域 | 200—500       | 800                |
| 地面经验和掉落   | 合并后300以内 | 原始生成1000以上   |
| 高成本特效       | 60以内        | 100                |
| 帧率             | 1080p 60 FPS  | 1% Low警戒线45 FPS |

### 技术措施

- 敌人、投射物、经验球、特效对象池化；
- 使用空间网格或空间哈希；
- 集中式敌人更新；
- 屏外敌人降低更新频率；
- 经验球分区合并；
- 伤害数字设同屏上限；
- 热路径禁止LINQ和每帧分配；
- 先使用Profiler定位瓶颈，再局部迁移到Jobs、Burst或ECS；
- Demo阶段不全面DOTS化。

- 所有新内容必须通过内容校验器；
