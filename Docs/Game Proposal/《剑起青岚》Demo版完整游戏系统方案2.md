# 《剑起青岚》Demo版完整游戏系统方案

**版本：** v1.0
 **项目阶段：** 青岚旧庭垂直切片
 **技术基线：** Unity 6 LTS、Universal 2D
 **目标平台：** Windows PC
 **开发模式：** AI Agent 主导开发，人工负责产品决策、架构约束、验收与资产审核

------

## 1. 文档目标

Demo不是仅验证“角色能移动、敌人会掉血”的技术原型，而是一段完整的垂直切片。

玩家必须能够完成以下流程：

```
启动游戏
→ 进入青岚旧庭
→ 自动战斗与升级构筑
→ 探索地图与激活风脉
→ 击败精英和中段Boss
→ 完成器法合鸣
→ 击败最终Boss
→ 结算奖励
→ 返回青岚旧庭据点
→ 解锁故事与成长
→ 调整配置
→ 再次进入下一局
```

Demo需要证明：

1. 中国风世界观能够自然承载类《吸血鬼幸存者》的玩法。
2. 角色、武器、心诀、奇物之间能够形成明确构筑。
3. 青岚旧庭既能作为第一关，也能作为局外据点。
4. 地图探索、战斗成长和局外收集能够形成统一闭环。
5. 技术架构可以支持AI Agent持续扩展，而不是演化成MonoBehaviour脚本堆叠。

------

## 2. Demo产品定位

### 2.1 一句话定位

玩家扮演一名自由游历天下的少年小剑客，在被灵脉记忆重塑的中国幻想境域中自动御器战斗，通过天下百器、诸脉心诀和战场奇物形成流派，疏通失衡灵脉，并把带回的技艺、故事与藏品汇聚到逐渐复苏的青岚旧庭。

### 2.2 核心气质

《剑起青岚》不是阴沉、末日、苦大仇深的修仙故事。

整体气质应当是：

- 阳光明亮；
- 山河辽阔；
- 草木有生命力；
- 废墟中仍有新生；
- 少年自由而清朗；
- 世界危险，但值得继续行走。

核心主题为：

> 旧路已断，山海仍在生长。执剑而行，为天下重寻一条新路。

### 2.3 Demo设计支柱

#### 移动本身就是战斗

初始角色陆青野通过持续移动积累风势。玩家的路线选择不仅用于躲避，也直接影响输出。

#### 世界内容直接进入构筑

公共武器来自各地神兵、门派和机构。

公共被动来自功法、心诀、身法和观想法。

#### 地图不是背景图

地标、风脉节点、药圃、封存匣和行迹残页都要产生战斗或局外收益。

#### 局外成长增加选择而非数值碾压

行脉图、剑匣嵌片和收藏主要改变机制、构筑控制和探索方式，不提供无限叠加的攻击力。

#### 数据驱动优先

角色、敌人、武器、心诀、关卡和奖励都通过稳定数据定义接入，不复制整套业务脚本。

## 4. 世界观垂直切片

### 4.1 天衡十二脉

旧时代的天下由十二条巨大灵脉连接，统称“天衡十二脉”。

灵脉传递的不只是灵气，还包括：

- 季候；
- 水汽；
- 物产；
- 技艺；
- 记忆；
- 文明交流。

宗门、城邦、商路和机关设施都围绕灵脉建立。

百年前发生“断衡之变”，十二脉同时失衡。现实山河与灵脉中积累的记忆、职责、自然力量和执念发生重叠，形成拥有独立规则的区域——境域。

### 4.2 境域生物分类

#### 荒灵

被灵脉强化的草木、动物、岩石和自然现象。

#### 遗械

旧时代留下的机关、傀儡和自动设施。

#### 祟念

历史记忆、职责和执念形成的重复幻象。

#### 逐脉者

主动进入境域的人类组织、旅者和掠夺者。

### 4.3 青岚宗

青岚宗不是天下第一宗门，而是负责巡查、疏通和调解各地灵脉的“巡脉宗门”。

青岚剑术强调：

- 听风辨脉；
- 御剑寻路；
- 斩除灵结；
- 兼容百家；
- 调和而非一味毁灭。

断衡之夜，青岚宗主力进入天脉深处，此后失踪。

青岚山没有完全毁灭。由于木气和风气持续外溢，庭院反而草木旺盛。

### 4.4 青岚旧庭

旧庭曾包括：

- 中央练剑场；
- 西侧药圃；
- 东侧藏剑廊；
- 南侧迎客庭；
- 北侧旧山门；
- 风脉观测设施。

百年后，断墙、残亭、石灯和剑架被青苔、藤蔓、杂草和野花覆盖。

旧庭中的训练机关仍执行最后一道命令：

> 在所有宗门弟子返回以前，不得开启内山门。

旧庭的主题不是死亡，而是：

> 人已经离开，但世界仍在生长。

## 5. 初始角色：陆青野

名称暂定，可在正式美术与剧情阶段再次审核。

### 5.1 人物设定

陆青野约十八九岁，没有正式门派归属。

幼时跟随一名身份不明的老剑客生活，学到了一些不成体系的剑术。老剑客离开后，他带着一柄普通旧剑独自游历。

他可能会：

- 替村民驱赶荒灵；
- 帮商队护送一段路；
- 在山寺屋檐下避雨；
- 看见好风景便多住几天；
- 没钱时认真考虑是否卖掉自己的剑。

他的自由不是逃避责任，而是：

> 不让宗门、身份和所谓天命替自己决定道路。

### 5.2 进入旧庭的原因

陆青野在山脚避雨时听见旧庭深处连续三声剑鸣，以为有人被困，于是翻过断墙进入遗址。

青岚剑匣苏醒并选择他时，他并不接受“青岚传人”的身份。

角色台词可以是：

> “你先别急着认主，我还没答应呢。”

### 5.3 外形关键词

- 青灰、米白、少量暖棕；
- 轻便窄袖短袍；
- 束腿裤和布靴；
- 不对称短斗篷；
- 修补过的旧剑鞘；
- 略微凌乱的短发；
- 清朗、轻快、略带孤独；
- 不使用华贵门派制服。

### 5.4 独有机制：乘风

持续有效移动时积累风势。

| 档位 | 效果                             |
| ---- | -------------------------------- |
| 静风 | 无额外加成                       |
| 微风 | 本命飞剑速度提高                 |
| 疾风 | 本命器攻击间隔缩短，移动速度略增 |
| 乘风 | 本命器攻击结束后留下弱风刃       |

约束：

- 必须产生真实位移，不能贴墙原地刷取；
- 受伤只降低一档风势，不全部清空；
- 升级、暂停和剧情演出时冻结风势；
- 通过脚下风纹、衣摆和剑穗表现，避免增加复杂能量条。

### 5.5 本命器：游风剑

游风剑自动寻找附近威胁较高的敌人，沿弧线穿刺后返回。

它不是固定围绕角色旋转，而是：

```
放出
→ 穿刺
→ 转向
→ 回返
```

建议8级成长：

| 等级 | 效果                         |
| ---- | ---------------------------- |
| 1    | 一柄飞剑，基础追踪攻击       |
| 2    | 伤害提高                     |
| 3    | 攻击间隔缩短                 |
| 4    | 增加一柄飞剑                 |
| 5    | 穿透增加                     |
| 6    | 飞行速度和伤害提高           |
| 7    | 返回路径能够再次命中         |
| 8    | 数量、伤害和攻击间隔综合强化 |

## 6. 游戏整体循环

### 6.1 秒级循环

```
观察敌群
→ 判断安全路线
→ 移动并维持风势
→ 武器自动攻击
→ 躲避接触、弹幕和范围预警
→ 击杀敌人
→ 拾取经验或战斗灵物
→ 调整下一段路线
```

### 6.2 分钟级循环

```
升级选牌
→ 获得武器或心诀
→ 强化已有构筑
→ 探索地图地标
→ 激活风脉节点
→ 击败精英获得奇物
→ 满足器法合鸣条件
→ 开启显化宝匣完成进化
```

### 6.3 单局循环

```
配置角色和嵌片
→ 进入青岚旧庭
→ 建立基础构筑
→ 激活风脉节点
→ 击败精英
→ 击败中段Boss
→ 完成一至两次器法合鸣
→ 应对高压敌潮
→ 击败最终Boss
→ 结算奖励
```

### 6.4 局外循环

```
返回旧庭
→ 阅读人物故事
→ 查看新藏品
→ 激活行脉图节点
→ 配置剑匣嵌片
→ 解锁武器、心诀和设施
→ 再次出发
```

## 7. 操作与相机

### 7.1 操作

| 功能     | 键鼠           | 手柄   |
| -------- | -------------- | ------ |
| 移动     | WASD/方向键    | 左摇杆 |
| 暂停     | Esc            | Menu   |
| 地图     | Tab/M          | View   |
| 确认     | Enter/鼠标左键 | A      |
| 取消     | Esc/鼠标右键   | B      |
| 页签切换 | Q/E            | LB/RB  |

攻击自动释放。

Demo不设置：

- 通用冲刺；
- 主动技能栏；
- 通用大招；
- 多武器主动切换。

闪避、穿行、瞬步等能力保留给特定角色、心诀或奇物。

### 7.2 相机

- 正交俯视相机；
- 角色略低于屏幕中心；
- 平滑跟随；
- 不使用明显拖尾；
- Boss阶段可轻微拉远；
- 地面范围预警始终完整可见。

### 7.3 碰撞

- 玩家可以穿过普通敌人，但会受到接触伤害；
- 普通敌人不形成完全无法穿越的物理墙；
- 地图障碍主要用于边界和路线塑造；
- 不制造狭窄卡死点；
- 精英和Boss可拥有更强体积压迫，但不能永久封死玩家。

## 8. 基础战斗规则

### 8.1 核心属性字典

只允许以下核心公共属性：

| 属性       | 作用                                 |
| ---------- | ------------------------------------ |
| 最大生命   | 玩家生命上限                         |
| 生命恢复   | 按时间或条件恢复                     |
| 护甲       | 降低受到的伤害                       |
| 移动速度   | 玩家移动速率                         |
| 威力       | 所有可强化伤害的倍率                 |
| 攻击间隔   | 武器触发间隔                         |
| 作用范围   | 投射物、爆炸和领域尺寸               |
| 持续时间   | 领域、召唤和状态时长                 |
| 投射物速度 | 投射物飞行速度                       |
| 投射物数量 | 单次释放数量                         |
| 穿透       | 可额外命中的敌人数                   |
| 暴击率     | 暴击概率                             |
| 暴击伤害   | 暴击倍率                             |
| 击退       | 改变敌人位置的能力                   |
| 拾取范围   | 自动吸收掉落的距离                   |
| 经验获取   | 经验收益倍率                         |
| 幸运       | 影响稀有灵物、候选品质和宝匣附加奖励 |

幸运不影响首通脉印和唯一剧情物品。

### 8.2 伤害管线

所有武器通过统一的伤害解析器结算：

```
基础伤害
× 武器等级倍率
× 玩家威力
× 条件增伤
× 暴击倍率
× 敌人承伤倍率
× 难度倍率
= 最终伤害
```

武器不得绕过统一伤害管线直接修改敌人生命。

### 8.3 受击保护

- 普通受击保护建议0.6秒；
- 同一敌人不能在保护期内重复接触伤害；
- Boss高危技能可以使用独立伤害通道；
- 高危技能必须有明显前摇；
- 玩家受伤不会停止所有武器攻击。

### 8.4 状态效果

Demo只实现：

- 灼烧；
- 中毒；
- 减速；
- 定身；
- 标记；
- 破甲；
- 击退。

Boss不完全免疫所有控制。

控制规则：

- 普通敌人完整生效；
- 精英持续时间缩短；
- Boss具有最低移动速度和控制抗性；
- 定界符对Boss表现为强减速，而不是完全冻结整个阶段。

## 9. 构筑系统

### 9.1 构筑语言

> 角色定义“我是谁”，武器定义“我用什么战斗”，心诀定义“我如何运转力量”，器法合鸣定义“我最终形成什么流派”。

### 9.2 槽位

- 武器槽：4个；
- 本命器占1个武器槽；
- 心诀槽：4个；
- 战场奇物槽：3个；
- 即时灵物不占槽。

### 9.3 升级选牌

每次升级暂停游戏，展示3个候选。

候选包括：

- 新武器；
- 新心诀；
- 已持有武器升级；
- 已持有心诀升级；
- 满槽且无升级时的治疗或灵砂替代。

每局基础拥有：

- 1次免费刷新；
- 1次放弃。

候选系统需要保证：

1. 已持有内容有合理机会升满；
2. 至少一条显化路线理论可达；
3. 不连续多次提供完全无协同候选；
4. 不直接保证最优构筑。

## 12. 器法合鸣

条件：

```
基础武器达到最高等级
＋
对应心诀达到至少3级
＋
开启显化宝匣
=
显化真名
```

| 基础武器 | 心诀   | 显化真名     | 变化                               |
| -------- | ------ | ------------ | ---------------------------------- |
| 游风剑   | 踏风步 | 青岚流影剑   | 沿移动轨迹留下风痕，满风势分裂剑影 |
| 镇邪黄符 | 清心诀 | 太一镇灵符阵 | 单发转为符阵，符印同时引爆         |
| 离火飞轮 | 御器篇 | 赤炉百工轮   | 数量增加，回返产生连锁爆裂         |
| 听潮珠   | 开域法 | 镜海潮生轮   | 涨落潮圈交替吸附、击退与爆发       |
| 震岳印   | 长息功 | 山河镇界印   | 形成短时安全领域并反震             |
| 灵藤种   | 采灵诀 | 地脉生春枝   | 藤丛连接并向相邻区域扩张           |

### 12.1 显化宝匣

中段Boss固定掉落一个，精英低概率额外掉落。

规则：

- 有满足条件的武器时优先展示；
- 多条路线可显化时由玩家选择；
- 无显化条件时提供高等级强化、稀有灵物或灵砂；
- 宝匣不能完全无效。

## 16. 刷怪导演

采用：

```
固定阶段时间轴
＋
生成预算
＋
敌人组合权重
＋
性能实体上限
```

不采用根据玩家DPS实时提升敌人生命的强橡皮筋机制。

导演输入：

- 当前时间；
- 当前地图区域；
- 在场敌人数；
- 精英和Boss状态；
- 难度；
- 随机种子；
- 性能实体上限。

导演输出：

- 生成预算；
- 敌人组合；
- 出现方向；
- 生成距离；
- 最大在场数量；
- 地图事件插入。

普通敌人不得直接在玩家视野内凭空出现，应从：

- 屏幕外；
- 草丛；
- 旧门；
- 机关台；
- 风脉裂隙

进入战场。

## 18. 地图系统

### 18.1 地图类型

使用有限边界的大型手工地图，不使用无限循环平铺。

建议地图尺寸约：

```
180 × 120 世界单位
```

### 18.2 区域划分

#### 中央练剑场

开局和主要战斗区域，地形开阔。

#### 西侧药圃

恢复、草木、灵植和药圃事件区域。

#### 东侧藏剑廊

残剑、机关敌人和封存匣区域。

#### 北侧旧山门

最终Boss入口和大型地标。

#### 南侧迎客庭

亭台、浅水、石灯和远程敌人区域。

中心保持开阔，边缘提供探索收益，防止玩家一直绕同一块空地。

## 19. 风脉节点

地图包含3座风脉节点。

玩家进入范围后需要维持短时间激活进度。

规则：

- 每激活1座，立即获得经验和少量恢复；
- 未激活节点会保留最终Boss的一项强化；
- 全部激活后，Boss战前提供额外显化宝匣或高品质恢复；
- 节点不是硬失败条件；
- 首次游戏提供明显方向提示；
- 重复游戏可关闭部分引导。

------

## 20. 地图事件

### 风脉暴动

短时间内：

- 敌人移动略快；
- 玩家投射物速度提高；
- 风向可视化；
- 事件结束后生成聚灵葫芦。

### 药圃复苏

药圃生成大量草灵和灵植。

完成小型击杀目标后获得：

- 青木露；
- 灵植藏品线索；
- 少量灵砂。

### 旧剑共鸣

场景中的残剑短暂升空攻击敌人。

玩家若及时抵达藏剑廊，可以开启封存匣。

## 22. Boss系统

### 22.1 中段Boss：试剑傀·折枝

技能：

1. 横枝试剑：前方宽扇形横扫；
2. 落木剑影：在玩家预测位置落下延迟剑影；
3. 演武木桩：召唤低生命训练木桩释放剑气。

掉落：

- 显化宝匣；
- 大范围经验吸收；
- 首次击败解锁一条旧宗门记录。

### 22.2 最终Boss：守庭剑傀·听风

#### 阶段一：守门

- 定向剑气；
- 短距离冲锋；
- 扇形斩击。

#### 阶段二：听风

生命降至70%后：

- 展开风场；
- 改变部分投射物轨迹；
- 召唤残剑形成旋转剑路；
- 未激活节点强化对应技能。

#### 阶段三：旧令不散

生命降至35%后：

- 场地出现交叉风痕；
- 风痕延迟爆发；
- Boss在安全区之间移动；
- 不增加大量纯血量，主要提高技能组合密度。

### 22.3 Boss奖励

最终Boss死亡后本局结束，因此不掉落只在本局生效的强力遗器。

首次击败固定获得：

- 青岚境主脉印；
- 唯一藏品“听风旧铭牌”；
- 陆青野第三篇故事；
- 万象阁设施；
- 下一境域入口线索。

## 25. 行脉图

陆青野拥有12个节点，分为三支。

每次出发最多激活6个节点，只能激活1个终端节点，重置免费。

### 本命支

- 游风剑索敌范围；
- 返回路径伤害；
- 剑影追加；
- 青岚流影剑专属强化。

### 身法支

- 风势积累速度；
- 快速转向后的短暂碰撞宽容；
- 受伤后移动加速；
- 满风势留下弱风痕。

### 心性支

- 免费刷新；
- 精英奇物额外候选；
- 本命标签亲和；
- 开局选择御剑、游风或探寻倾向。

行脉图主要改变机制，不大量堆叠永久伤害。

| 地面经验和掉落 | 合并后300以内 | 原始生成1000以上       |
| 高成本特效     | 60以内        | 100                    |
| 帧率           | 1080p 60 FPS  | 1% Low低于45 FPS时警报 |

### 34.2 技术原则

- 对象池；
- 空间网格或空间哈希；
- 集中式敌人更新；
- 屏外逻辑降频；
- 经验球合并；
- 伤害数字上限；
- 热路径禁止LINQ；
- 热路径禁止反射；
- 避免每帧分配；
- 通过Profiler确认瓶颈后再局部使用Jobs、Burst或ECS。
