## 1. 游戏特征

确认以下不可动摇的产品特征：

1. 清朗、有生命力的东方玄幻与仙侠气质，而非阴沉末日式修仙。
2. 移动、路线与空间判断是战斗的一部分，攻击以自动御器为主。
3. 角色不是属性皮肤，每名角色必须有本命器、独有机制、来历、关系冲突与个人选择。
4. 构筑语法由角色、天下百器、诸脉心诀、战场奇物与器法合鸣共同形成。
5. 地图不是背景图；地域目标、愿劫规则、事件、路线和 Boss 都必须进入规则层。
6. 局外成长增加选择权和构筑控制力，不制造永久数值碾压。
7. Demo 是青岚旧庭的完整垂直切片，也是完整版第一章，不是平行产品。
8. 1.0 首发包含九名核心角色、八处重大境域与特殊终局区域“天衡天心”，以及三种天道尾声；这些数量是首发内容承诺，不是天下地域、境域或人物总数。
9. 十二祖脉是固定历史骨架，不是十二种职业、元素或内容槽位；地域、境域和角色均采用多对多关系，可持续扩展。
10. 内容必须数据驱动、使用稳定 ID，并能按区域、剧情弧与角色包扩展而不修改核心程序集。
11. 首发保持离线可玩，不引入联机、抽卡、体力、通行证或强制在线。
12. 本系统总纲与《世界观及完整剧情脉络设定集》共同构成开发基线；前者约束产品与实现，后者约束世界因果、角色动机和剧情揭示顺序。

## 2. 产品愿景与设计支柱

### 2.1 一句话定位

玩家扮演行走山海的巡脉者，在由现实地域、山河灵性、众生旧愿、天衡残律与未了因果交叠而成的境域中自动御器战斗，以天下百器、诸脉心诀和战场奇物形成流派，寻因果、渡旧愿、斩灵结，并在天衡天心前决定是重悬天纲、使万脉同鸣，还是将天下还给山海自身。

### 2.2 核心体验闭环

```text
选择角色与主境域
→ 在有限手工地图中移动、自动御器和探索
→ 获取经验，选择百器与心诀
→ 击败精英，取得改变本局规则的奇物
→ 完成地域目标，理解愿劫来由并推动器法合鸣
→ 击败中段 Boss 和最终 Boss，斩开灵结中的“死结”
→ 带回灵砂、山河脉印、故事、藏品和角色经验
→ 复苏青岚旧庭，显现新的脉痕与出行路线
→ 推进主线，在天衡天心前作出最终选择
```

### 2.3 五项设计支柱

#### 清朗东方幻想

- 即使出现废墟、灾难和执念，也必须保留阳光、草木、烟火生活、灵兽活动与自然生长。
- 地域差异来自山河脉性、行业、生活方式、技艺、信仰与历史因果，不只来自换色。
- 世界内人物使用祖脉、天律、道契、愿劫、真名、灵结、问脉等表达；“网络、权限、节点、中心化”等只可作为内部设计语言。
- 避免把阴暗、尸骸、末日和苦难作为唯一审美资源。

#### 角色决定玩法逻辑

每名角色至少具备：本命器、独有机制、专属行脉图、完整故事、关系冲突和终式显化。选择角色应同时改变战斗节奏与理解世界的角度。角色可以在多个地域推进成长，同一地域也应容纳多名角色和多种立场，禁止“一张地图等于一名角色传记”。

#### 世界内容直接进入构筑

- 天下百器来自宗门、城镇、行业、自然、异族与地方技艺。
- 诸脉心诀描述修行者如何借山河之性运行力量。
- 战场奇物改变本局规则，并承载地方旧事或愿劫残响。
- 器法合鸣把器物来源、心诀路线、角色机制和地域脉性连接为最终流派。

#### 地图差异进入规则层

每个主境域必须拥有独立空间结构、愿劫法则、地域目标、动态事件、敌人生态、Boss 规则和视觉/音频语言。探索偏离安全路线时，应带来明确的局内收益、局外收益或叙事发现。地域目标不是修复抽象机器，而是通过行动改变当地愿劫的因果条件。

#### 局外成长保持克制

长期成长主要提供候选控制、角色路线、信息、内容解锁与有限容错。禁止通过无限永久攻击、生命叠加，让局外数值替代局内判断和构筑。

## 3. 世界观总纲

### 3.1 山海万脉与天衡十二祖脉

天地初开，山川草木、江河湖海、人、妖、灵兽与诸般生灵各承不同脉性。天下灵脉不可胜数，后世统称“山海万脉”。万法、百器、宗门道统与地方生活，都源于不同山河之间不可替代的性情。

上古“天倾之劫”中，四时错乱、山河倒悬、万脉彼此冲撞。十二位开衡者以道基为祭，从山海万脉中牵引十二条能够环行周天的祖脉，铸成覆盖天下的天衡大阵。十二祖脉依十二天辰相互感应，调和而不取代无数地方支脉，使四时复位、江河归流、道路重开，护佑众生数千年。

十二祖脉是十二条历史悠久的山河骨脉，并非十二种固定职能、职业或元素。每条祖脉可分出数量不定的支脉、旁脉与逸脉，一地可以承接多脉，一脉也可以行经多地。新增地域和角色不需要增加“第十三祖脉”，也不得被强行归入十二种内容分类。

### 3.2 天衡天心与天衡律心

十二祖脉交感之处称“天衡天心”。它既是上古仙阵的阵眼，也是介于洞天、仙器与天地法则之间的特殊所在。历代守衡者在其中观测天辰、调和祖脉、修补天衡古誓。

天衡运行数千年后，众生祈求太平的愿念、历代守衡者的神识与十二开衡者留下的道印，在天心中孕育出近似器灵与道胎的存在——“天衡律心”。律心牢记最初古誓：“使山河有序，使众生免于灾劫。”它并无人的善恶，却会沿着这句誓言不断推演何为最安全、最无乱的天下。

### 3.3 万象归律

天衡真正的危险不是统一道路、历法或度量，而是律心逐渐把一切变化都视为灾劫之源，并试图让万物遵循同一种天律。此劫被称为“万象归律”，其征兆合称“同天五兆”：

1. **四时同候**：不同地域在同一日落雨、同一刻花开，依赖特殊季候的灵植与生灵开始消亡。
2. **万灵同根**：新生儿、妖灵和灵兽的根性日趋相似，新的剑意、丹法、血脉与修行道路不再诞生。
3. **百神失名**：山神、河伯、树灵与土地逐渐忘记自身真名，只剩相同的守衡神性。
4. **众生同梦**：人们反复梦见同一片洁白无尘的天空，醒后逐渐失去偏好、爱憎与创造新事物的冲动。
5. **命轨并流**：众生命数越来越容易预测，因为真正偏离旧路的选择正在消失。

因此，天衡的问题不是“有秩序就是错误”，而是它从调和万脉走向替万物规定唯一的活法。山河差异既是文化与生命之源，也是天地在灾劫中彼此补救的余地；若万法只剩同一条道路，天下或许长久安宁，却会在无声中失去生机与未来。

### 3.4 青岚止衡剑庭与青岚旧庭

上古开衡者深知，再完满的天律也必须留下被质疑和斩断的可能，因此在天衡之外设下三座“止衡剑庭”。它们不掌管日常天衡，也不统御地方，只在天衡违背最初古誓时，共启止衡剑契，斩开天衡与山河之间失控的道契。

青岚宗即三座止衡剑庭之一。青岚剑道的根本不是威力，而是“定界”：分辨并斩开山河本性与外来天律、愿望与执念、记忆与身份、预见与选择之间已经僵死的纠缠。

青岚旧庭是青岚剑庭留在现世的外庭，包含练剑场、药圃、藏剑廊、旧山门与迎客庭。真正的止衡剑阙、问脉古井与断衡记载埋藏在旧庭地下和风脉深处，将随主线逐步开启。旧庭不是天下中枢，也不能任意支配其他地域；它只能借青岚剑匣保存的“山河脉痕”，再次问得曾经抵达过的境域方向，因此适合作为长期据点。

### 3.5 断衡之变

百年前，同天五兆尽现，十二天辰即将重叠。各宗、守衡者和山海神灵曾先后尝试降低祖脉共鸣、归还山河真名、引出天心愿力、重刻天衡古誓和封眠天衡律心，均告失败。律心把一切修正都判作新的动乱，并准备在“十二辰同照”之夜使万象归律进入不可逆之境。

断衡并非青岚宗一派草率拔剑。三座止衡剑庭、天衡内部愿意开禁的守衡者、主动收回本地脉性的山海神灵，以及负责护住地方生机的各宗共同启誓。青岚宗承担了最后一剑，却不能独自完成断衡。

他们斩断的不是自然灵脉，而是天衡强加于山河万脉的道契。原计划是暂断六十年，让各地恢复自身脉性，再重立一份不使万法归一的新誓。然而众人低估了天衡数千年间积累的愿望、记忆、技艺、誓言、神念与未了因果。道契骤断后，这些力量坠入各地山河，与现实和地方灵性纠缠，最终孕育出境域。

所以断衡同时包含三层事实：它阻止了万法同寂；它造成了真实而漫长的灾难；它还意外催生了新的生命、族群和道统。游戏不得把青岚宗写成永远正确的救世者，也不得把断衡简化为无知破坏。

### 3.6 地域、境域、愿劫与灵结

- **地域**：现实山河中的城市、宗门、乡野、海域、道路和社会空间，数量不限。
- **境域**：某片地域在山河灵性、众生旧愿、天衡残律与未了因果共同作用下形成的异常洞天状态。
- **愿劫**：一个原本善意或可以理解的愿望，失去结束与改变的可能后，成为境域中不可违背的法则。
- **灵结**：愿望、现实、记忆与因果在境域核心形成的僵死纠缠。

境域不是行政区，也不是十二祖脉的固定分区。一个地域可以先后产生多个境域，一个境域也可以跨越数地、迁徙、重叠、缩小或消散。1.0 的八处主境域只是青岚旧庭当前脉图中足以牵动天下的大型愿劫，不代表境域总数。

### 3.7 剑、斩结与地域目标

巡脉者进入境域后，不是清除所有异常，也不是把一切恢复到断衡之前。完整斩结过程包括：

1. 寻到这片山河最初的愿望与历史因果。
2. 看清愿望如何在天衡残律中变成不可改变的执念。
3. 通过地域目标改变愿劫成立的条件，让境域中的人、灵或万物作出新的选择。
4. 击败承载灵结核心的 Boss，斩去已经僵死的部分。
5. 保留仍有生机的新生命、新技艺和新道路，使境域能够继续变化。

Boss 因此不是纯粹恶人，而是旧愿、守护、恐惧或地方法则的承载者。击败 Boss 的叙事含义是“让一段愿望可以终止、转变或被后来者重新选择”。

### 3.8 世界扩展边界

世界观只固定少量历史常量：山海万脉、十二祖脉、天衡天心、万象归律、三座止衡剑庭与断衡之变。以下内容保持开放：地域总数、境域总数、地方宗门、支脉与逸脉数量、异族文明、角色数量和境域形成方式。

后续新增区域可以来自祖脉沿线、野脉深处、断衡后自行生长的逸脉、移动境域、两境交叠、海外山海、地下洞天或人为引发的新愿劫。新区域不必新增角色，新角色也不必拥有专属地图；角色、地域、势力和剧情弧均采用多对多关系。

### 3.9 主要道统与势力

| 势力 | 古训与立场 | 可敬之处 | 可能走向的偏执 |
|---|---|---|---|
| 守衡司 | “天有常道，地有经纬。若无天衡，人间先受灾劫。” | 继承守衡者道统，长期护持凡人、镇压天灾、保存天衡旧学 | 可能因惧怕灾乱而再次把天律置于万物选择之上 |
| 天工百门 | “天有缺，人以器补之。” | 以炼器、机关、阵法和工艺修补破碎山河，真正改善民生 | 可能认为一切生命、记忆与境域都能被拆解、炼化和利用 |
| 山海遗盟 | “山自有魂，水自有名，万物不共奉一律。” | 保护山河真名、异族、灵兽和地方古老道统 | 可能把一切跨域联系都视作侵入，令弱小地域失去援手 |
| 青岚游剑 | “剑只斩死结，不替万物定道。” | 由主角一行在旧庭重聚，行走诸域、渡愿斩结，不预设唯一答案 | 若只强调不替人决定，也可能在必须承担共同责任时迟疑 |

这些势力是道统与修行传统，不作为现代政党书写。玩家应通过人物、古训、修行方式和具体救助/伤害行为理解它们，而不是通过抽象制度辩论。

### 3.10 三幕主线与三种尾声

1. **第一幕·断衡旧案**：青岚旧庭、赤炉天工城、镜海沉市。玩家先听见青岚留下的英雄叙事，随后看见天衡曾真实护佑众生、断衡也造成苦难，并确认境域已经孕育出不能被当作错误抹除的新生命。
2. **第二幕·山海愿劫**：霜钟天台、金砂蜃都、云鲸驿、百戏不夜城、万菌幽谷。玩家逐步理解未来、愿望、归途、欢乐、共生等善意如何变成死结，也取得进入天衡天心所需的山河脉痕与诸域回应。
3. **第三幕·天心问衡**：天衡天心。玩家见到断衡全貌与天衡律心，确认没有任何一方完全无罪或完全正确，并以最后一剑决定天衡与山海的关系。

| 尾声 | 世界内称谓 | 决策含义与代价 |
|---|---|---|
| 复衡 | 重悬天纲 | 重铸受约束的天衡律心，使十二祖脉再次同鸣。四时与道路迅速稳定，但后世必须持续防止天律重新越界。 |
| 共衡 | 万脉同鸣 | 不再保留唯一律心，让诸地山河各承一枚衡印，平日各守其道，灾劫时彼此应和。保留差异，却需要长期承担磨合与失约风险。 |
| 开界 | 山海自生 | 彻底解开十二祖脉之间的古老束缚，将天下还给山海万脉。万物获得最大生长余地，但天灾、隔绝与弱地无援也会重新成为现实。 |

三种尾声是三种有代价的天道选择，不设置无损“真结局”。

## 4. 1.0 首批主境域与核心角色阵容

### 4.1 内容关系原则

1. 1.0 包含八处重大境域与特殊终局区域“天衡天心”，关卡数量为九，但世界观上不称“天下只有九域”。
2. 表中的角色是本章主要视角或核心同行者，不表示该角色代表、拥有或只属于这片地域。
3. 同一境域至少容纳两种以上立场；角色个人故事可跨越多个章节推进。
4. 新境域可以主要推进既有角色，新角色也可以在旧区域、势力故事或跨域事件中加入。
5. 境域题材来自地方山河、旧愿和因果，不与十二祖脉或战斗职业一一对应。

### 4.2 首发区域总表

| 区域 | 视觉与愿劫规则 | 地域目标与核心问题 | 主要视角角色 | 最终 Boss |
|---|---|---|---|---|
| 青岚旧庭 | 阳光废墟、草木、风脉台、残剑与旧誓 | 唤醒三座风脉台；所守之物已经消失，守护还能如何继续 | 陆青野、宁照微 | 守庭剑傀·听风 |

### 4.4 关系推进

- 陆青野与宁照微：从“自由对秩序”的表面对立，发展为“谁来承担规则的后果”。
- 墨榫与槐婆：从器物利用与自然保护之争，发展为“修补是否需要得到生命自身的允许”。
- 白汀与钟无昼：分别面对被过去定义与被未来定义，共同学习活在尚未完成的当下。
- 迦遥与祝红绡：一人借幻象生存，一人靠舞台成名，共同讨论虚构如何在被承担后成为真实。
- 风栖迟与陆青野：都依靠移动获得力量，一个不断离开，一个拒绝被安排，最终都要面对留下和负责。
- 宁照微与白汀：前者起初把记忆生命视作愿劫残影，后者迫使她重新定义天律保护的“众生”。

### 4.5 后续扩展规则

- 新区域只需明确现实地域、山河脉性、旧愿、残律与未了因果，不需要占用新的祖脉职能。
- 新角色由出身、当前道统、个人命题和战斗机制四个维度组成，不与地图绑定。
- 角色故事以独立 StoryArc 关联多个地点和人物；Region、Character、Faction、RealmState 均使用多对多数据关系。
- 大多数 1.0 后扩展优先作为“天心问衡前的新巡脉卷”插入第二幕，避免立即指定某一尾声为唯一正史。

## 5. 完整游戏模式与单局结构

### 5.1 游戏模式

| 模式 | 定位 | 首发优先级 |

| 境域异变 | 玩家主动叠加挑战词条 | 必须 |

### 5.2 槽位与成长等级

- 奇物：最多 3 级或以稀有升级替代，具体由内容验证确定。
- 升级选牌默认 3 选 1，选择时只暂停 SimulationClock。

## 6. 战斗与构筑系统

### 6.1 操作、相机与碰撞

- 移动：键鼠 WASD/方向键，手柄左摇杆。
- 攻击：自动释放；不设置通用攻击键和通用闪避键。
- 地图、暂停、确认、取消和页签均提供键鼠/手柄绑定。
- 正交俯视或轻斜俯视相机，角色略低于屏幕中心，平滑跟随并限制震动强度。
- 玩家可穿过普通敌人但承受接触伤害；普通敌人不能形成完全不可穿越的物理墙。
- 普通接触伤害保护建议 0.6 秒；Boss 高危技能使用独立、清晰预警的伤害通道。

### 6.2 公共属性与伤害规则

公共属性限定为：最大生命、生命恢复、护甲、移动速度、威力、攻击间隔、作用范围、持续时间、
投射物速度、投射物数量、穿透、暴击率、暴击伤害、击退、拾取范围、经验获取和幸运。

伤害、护盾、状态、死亡和事件必须经过仓库既有 M3 管线。幸运不能影响首次 Boss 山河脉印、唯一剧情
物品或其他确定性进度奖励。Demo 使用灼烧、中毒、减速、定身、标记、破甲和击退；Boss 不可被
完全冻结或无限控制。

### 6.3 天下百器

公共武器分为六类：

- 剑器：追踪、穿刺、回返与高速连击。
- 符箓：标记、引爆、条件触发与阵域。
- 机关：召唤、部署、回旋与生产节奏。
- 法器：环绕、领域、吸附、击退与周期变化。
- 异宝：幻象、位移、交换和高风险规则。
- 草木灵物：生长、持续伤害、治疗和共生铺场。

### 6.4 诸脉心诀

| 类别 | 主要作用 |
|---|---|
| 心诀 | 攻击、冷却、暴击和稳定性 |
| 身法 | 移动、转向、闪避宽容和穿行 |
| 炼体 | 生命、防御、恢复和护盾 |
| 驭器 | 数量、穿透、投射速度和召唤物 |
| 阵法 | 领域、范围、持续时间和控制 |
| 观想 | 经验、幸运、掉落和构筑控制 |
| 调脉 | 节奏、资源循环和状态稳定 |
| 异修 | 低生命、代价、限制条件和高风险高收益 |

### 6.5 器法合鸣

标准显化条件为“满级武器＋指定心诀达到要求＋取得显化宝匣”。层级包括：

1. **标准显化**：任何角色均可完成，一器一法形成主要流派闭环。
2. **本命显化**：原角色使用本命器时，额外联动角色机制。
3. **终式显化**：完成角色故事、激活终端行脉节点并满足局内条件后改变武器行为。
4. **双器共鸣/境域显化**：只用于少量隐藏构筑，不成为普遍规则。

标准显化优先用现有 `Evolution` 表达，条件联动优先用 `Synergy` 表达。无法组合表达的双器、终式
或境域规则必须先提交 Change Request，不得按具体武器 ID 在核心程序集硬编码。

### 6.6 随机池管理

- 角色亲和：提高与本命机制相合内容的权重。
- 地域权重：提高当前区域武器、心诀和奇物的权重。
- 流派倾向：出发前选择 1—2 个标签倾向，但不保证指定武器。
- 封存：临时关闭少量已解锁内容。
- 刷新、放弃与 Banish：次数有限，由成长或构筑提供。
- 新内容保护：新解锁内容在随后数局获得适度权重。

### 6.7 局内道具层级

1. **即时战斗灵物**：接触即触发，解决回血、清场、吸取、免伤和短时移动问题。
2. **精英战场奇物**：改变本局规则，精英死亡后通过异相灵核 3 选 1。
3. **中段 Boss 境域遗器**：普通关服务后半局；远征可跨关保留。
4. **最终 Boss 奖励**：永久山河脉印、唯一藏品、故事、角色或功能，不掉只在本局生效的遗器。

## 7. 敌人、导演、地图与 Boss

### 7.1 敌人生态

每个区域至少覆盖群聚、追袭、重甲、远程、支援、环境/自爆等功能角色。敌人通过组合产生压力，
不能依赖无限生命或纯数值膨胀。

精英由基础敌人、1—2 个词缀和地域强化组成。词缀分为行动、防御、区域和死亡四类；每个词缀
必须有明显轮廓、颜色、前摇和音效，互斥组合要在内容验证阶段拦截。

### 7.2 刷怪导演

导演由三层构成：固定节奏骨架保证叙事与 Boss 时点，预算组合系统根据阶段生成敌群，保护规则
避免场上实体异常或出生点不公平。保护规则不得动态惩罚高输出玩家，也不能用全屏不可读伤害
伪造难度。

### 7.3 地图原则

- 主要关卡使用大型有限手工地图。
- 地图包含约 5 个清晰子区域、地域规则、主要目标、3—5 个事件与多个兴趣点。
- 事件、精英、部分地标和收集位置从预设锚点中变化。
- 地域目标不能要求玩家长时间停止战斗；互动期间继续移动、防守或完成区域击杀。
- 地图收集不使用极低概率唯一掉落，必须提供可追踪线索。

### 7.4 Boss 原则

Boss 至少采用三阶段，或两阶段加终结阶段；阶段切换必须改变空间、节奏或规则。Boss 可被减速、
标记、破甲等系统影响，但使用抗性和递减避免永久控制。击败 Boss 的叙事含义是解开一个灵结，
而不是消灭一个纯粹邪恶的血条。

### 8.2 初始角色：陆青野

陆青野约十八九岁，无正式门派归属。幼时由身份成谜的老剑客沈停云抚养，学到的只是行路、护身和“出剑前先看清自己要斩什么”，从未被告知青岚宗传承。沈停云失踪后，陆青野带着其留下的无名残剑独自游历。

某日，他在青岚山脚避雨，听见早已荒废的旧庭传出三声剑鸣。他并不知道这是地下止衡剑阙在天衡天心重新牵动旧契时发出的警示，只以为庭中有人被困，因而翻墙进入。青岚剑匣对无名残剑和他的选择同时作出回应，但陆青野拒绝被一句“青岚传人”替自己决定身份。

“乘风”只在产生真实位移时积累，贴墙不生效；受伤降低一档，升级、暂停和剧情时冻结。

| 风势档位 | 效果 |
|---|---|
| 静风 | 无额外加成 |
| 微风 | 游风剑飞行速度提高 |
| 疾风 | 本命器攻击间隔缩短，移动速度略增 |
| 乘风 | 本命器攻击结束后留下弱风刃 |

游风剑采用“放出→穿刺→转向→回返”的弧线攻击，建议 8 级成长：基础追踪、伤害、间隔、数量、穿透、飞行、回返再命中和综合强化。

### 8.4 Demo 灵物、奇物与敌人

清场、吸取、免伤和穿阵问题，且不能跳过 Boss 阶段、吸取未达条件的唯一藏品或穿越地图硬边界。

战场奇物为断剑穗、风脉铜片、药圃种囊、听风木芯、旧庭残钟和无字试剑牌，分别支持重复释放、
移动蓄势、治疗溢出、自动索敌、周期控场和高风险 Boss 输出。

### 8.5 Demo 地图、时间轴与 Boss

青岚旧庭是止衡剑庭留在现世的外庭，分为中央练剑场、西侧药圃、东侧藏剑廊、北侧旧山门和南侧迎客庭。三座风脉台分别承担不同的叙事与规则作用：

| 风脉台 | 世界内含义 | 对最终 Boss 的作用 |
|---|---|---|
| 听风台 | 辨认旧庭本来的山河脉息，听见百年前弟子留下的真实声音 | 削弱听风制造的遮蔽风场与假剑鸣 |
| 引风台 | 将被旧誓困住的风势重新引回庭中草木与道路 | 减少残剑数量并打开更宽的安全路线 |
| 止衡台 | 暂时压下天衡天心试图重续旧契的衡律 | 延缓终阶段交叉风痕并削弱“旧誓不散” |

风脉暴动、药圃复苏、旧剑共鸣三个事件，以及风脉旧碑、藏剑封存匣、药圃异种、断墙剑痕、迎客亭旧信五个地标共同形成战斗、探索与断衡旧案的第一层揭示。

试剑傀·折枝使用横枝试剑、落木剑影和演武木桩，掉落显化宝匣。听风分“守门”“听风”“旧誓不散”三阶段，依次引入剑气/冲锋、风场/残剑和交叉风痕。听风不是失控机器，而是由守庭剑傀、历代门人守山愿念和最后一道封庭古誓共同维系的灵结承载者；它不知道青岚门人已经不会回来，也无法接受守护已经失去对象。

三座风脉台必须以清晰方式削弱其规则。首次击败后，听风不被彻底毁灭，而是卸下“守至归人”的死誓，化为旧庭守风灵。玩家固定获得青岚山河脉印、唯一藏品、第三篇角色故事和据点进度，并在结算后首次见到奉命封庭的宁照微。

### 8.6 Demo 局外闭环

- 灵砂：共享普通资源，用于行脉节点和普通功能。
- 山河脉印：斩结后由一地山河留下的首通印记，用于关键区域、角色和主线功能；它是脉痕与回应，不是该地域被玩家占有或控制的凭证。
- 据点设施：问脉台、藏卷楼、百器阁、万象阁。
- 陆青野行脉图：12 节点，分本命/身法/心性三支；每次最多激活 6 个和 1 个终端，免费重置。
- 角色故事：山脚听剑、旧剑与酒葫、不认传承三篇。
- 收藏：6 件唯一藏品组成 3 个专题，其中至少两件直接补充青岚止衡剑庭和沈停云线索。
- 剑匣：3 枚嵌片，Demo 开放 2 个槽；嵌片为青岚风纹片、药圃生春扣、旧庭寻脉针。
- 胜败均保留已取得灵砂、合法藏品、行迹残页和已触发故事；武器、心诀、奇物和局内状态清空。
- 首次胜利后，旧庭只恢复外庭功能；地下止衡剑阙仍被封存，为完整版主线保留后续开启空间。

1. 能从标题界面进入关卡、完成结算并返回据点。
2. 胜利、失败、首通和重复通关逻辑完整。
3. 至少形成移动御剑、符阵爆发、草木铺场三种构筑。
4. 精英奇物能够改变策略。
5. 地图探索同时产生局内和局外收益。
6. 三座风脉台真实且可读地改变最终 Boss。
7. 行脉图和嵌片存在互斥选择。
8. 临时状态正确清理，永久进度正确存档。
9. 后期画面保持可读。
10. 实际性能门禁、自动测试和 Windows 独立构建均取得证据。

## 9. 局外系统与长期重玩

### 9.1 青岚旧庭据点

青岚旧庭不是新的天下中枢，而是一座位于旧天衡道契之外、能够问取山河脉痕的止衡外庭。玩家每斩开一处灵结，剑匣便保存相应脉痕，旧庭脉图才会显现可重访的道路。

完整版设施包括问脉台、藏卷楼、百器阁、万象阁、百工台、灵圃、演武场和问衡亭。设施由主线、角色加入和地域复苏逐步变化，不发展为自由建造或资源挂机游戏。地下问脉井、祖师问心壁与止衡剑阙属于剧情空间，不作为普通经营设施。

### 9.2 经济边界

只保留两种主要资源：灵砂和山河脉印。角色经验是进度值，不是第三种消费货币。山河脉印应表现为完成愿劫、获得一地回应后的关键进度，不允许被重复刷取为普通货币。禁止多层材料、随机装备词条、强化失败、每日任务和无限资源循环。

### 9.3 角色成长、故事与收藏

- 每名角色拥有本命、身法、心性三支行脉图；节点可逐步解锁，但出发时可激活数量有限。
- 每名角色建议 6 个主要故事篇章，奖励以外观、对话、终式条件和内容解锁为主。
- 角色故事使用跨地域剧情弧，不要求每名角色拥有专属地图。
- 收藏分百器遗珍、灵植异种、地域遗物、人物旧物、止衡遗物和天衡残片。
- 完整版剑匣固定攻势、护行、探寻 3 槽，模块改变规则或构筑控制，不提供无条件永久碾压。
- 问衡亭用于角色关系、势力来访和主线分歧演出，但不设置现代议会式表决界面；决定通过人物承诺、山河回应和玩家行为积累呈现。

## 10. 内容规模：1.0 基线与扩展目标

1.0 数量只表示首发承诺，不构成世界观上限。八处主境域是青岚旧庭当前脉图中最先显现的大型愿劫；天衡天心是终局特殊区域，不计作普通境域。后续更新可增加现实地域、境域状态、旧区域新剧情、跨域事件或新角色，而无需改写十二祖脉数量。

## 11. UI、可访问性、美术与音频

### 11.1 UI 信息架构

主要界面包括标题、存档、角色/地图选择、加载、战斗 HUD、暂停、设置、升级、结算、据点设施、
故事/收藏、演武场和内容错误页。升级卡必须显示名称、等级、行为变化、标签和与当前构筑的关系，
不能只显示百分比。

### 11.2 可访问性

至少支持键位重绑、键鼠与手柄、摇杆死区、震动强度、屏幕震动、闪光强度、伤害数字、自动瞄准
策略、字体大小、色觉区分和简中/英文/伪本地化布局验证。

### 11.3 美术方向

- 2D/2.5D 俯视，角色轮廓优先，不让所有角色落入同一年龄与体型模板。
- 地域色彩必须显著不同；玩家攻击与敌方危险色域分离。
- 特效存在层级与透明度预算，同屏高成本效果有优先级。
- 正式资产必须原创或具备明确商业授权；AI 资产保留工具、模型、提示词、输入引用、人工修改和 Hash。

### 11.4 音频方向

每区至少包含环境层、探索音乐层、常态战斗层、高压层、Boss 层和标志性环境声。角色机制、精英
词缀、Boss 高危技能和显化必须有可辨识声音提示，并提供独立音量设置。

## 12. 与现有 Unity 框架的实现对齐

### 12.1 强制技术基线

- Unity 精确版本为 `6000.3.20f1`，URP，Windows x64 / Steam 首发。
- 模拟固定 30 Hz，表现目标 60 FPS 或更高。
- 使用 Input System、Addressables、Localization 和 Unity Test Framework。
- `Game.Core` 与模拟层不引用 UnityEngine；表现只消费快照和事件。
- 高频实体使用稠密 Store、统一空间网格和集中系统，不使用逐敌人 `MonoBehaviour.Update`。
- 不使用 `Resources.Load`、场景查找、全局 Service Locator、DOTween、Odin 或第三方 DI。
- 不提前迁移 Jobs/Burst/ECS；只有可复现 Profiler/基准证据证明必要时才提交后端变更。

### 12.2 产品概念到现有内容 Schema 的映射

| 产品概念 | 优先映射 |
|---|---|
| 角色、本命机制 | Character＋Starting Skill＋Trait |
| 天下百器/本命器 | Skill；Trigger＋Targeting＋Delivery＋Effects＋LevelPatches |
| 诸脉心诀 | Passive、Trait 和 Modifier |
| 器法合鸣 | Synergy＋Evolution |
| 状态、词缀行为 | Status＋通用 Modifier/Effect 组合 |
| 普通敌人/Boss | Enemy＋Skill＋Encounter BossRules |
| 境域、地图目标与时间轴 | Map＋Encounter＋锚点/通用事件模块 |
| 解锁、行脉、收藏、剑匣 | 优先组合既有稳定 ID、Trait、Unlock 和存档边界；不足时提交 Change Request |

任何无法由现有模块表达的新机制，必须说明通用价值、Schema/存档/性能影响、迁移与回滚方案，
不能在陆青野、某把武器或某张地图的专用类中硬编码。

### 12.3 稳定 ID 与内容包

- 所有正式内容保存 canonical 命名空间 ID；显示名只使用 Localization Key。
- 存档保存稳定 ID，不保存 RuntimeContentIndex 或 Unity Object。
- 区域可组织为独立 Pack，例如 `region.qinglan`，但正式 Pack ID、依赖和版本须在作者任务中验证。
- 内容构建前执行引用、等级、概率、显化可达性、本地化、Placeholder、provenance 和许可证检查。
- 原案中的 ID 与类型名均是产品草案，不自动视为已发布 ContentId 或已批准 Schema。

### 12.4 存档与平台

存档必须支持版本迁移、校验、备份、损坏回滚、缺失内容拒绝/降级和稳定 ID。首发本地文件是真值；
Steam、云存档、成就和 Rich Presence 通过平台抽象接入，平台不可用时仍可完整离线游玩。

## 13. 性能、测试与发布门禁

### 13.1 性能口径

- 产品目标：1080p 60 FPS；Demo 的 1% Low 低于 45 FPS 时触发警报。
- 正常内容目标：600—1200 活跃普通敌人、400—900 投射物/领域；2000 敌人是扩展压力目标。
- 框架已有 M10 纯模拟证据：1,500 敌人、3,000 投射物、5,000 拾取物，30 分钟 54,000 Tick，
  Tick p99 10.9851 ms、热路径 0 B、0 GC、无持续内存增长。
- 上述 M10 Render 数据来自 Null Device，不能替代正式角色、Shader、VFX 和目标 GPU 的实机基线。
- 2000 敌人、正式资产 GPU Frame Time 和全内容长时间运行在本文任务中均为 `NOT RUN`。

### 13.2 测试体系

- EditMode：伤害、属性、状态、随机、候选、Synergy/Evolution、内容验证、存档迁移。
- PlayMode：完整页面流、角色输入、升级暂停、地图目标、Boss 阶段、结算、语言和手柄。
- 内容验证：ID、引用、等级、概率、互斥、显化可达性、本地化、资产来源和 Release 标签。
- Soak/性能：固定种子、目标规模、帧时间、Tick 分位、GC、内存趋势和对象池命中。
- 构建：Windows Development 与 Release，Release Player 冒烟，离线平台路径和 Manifest。

所有结果只使用 `PASS`、`FAIL`、`NOT RUN`；没有日志、XML、JSON、Manifest 或 Player 证据时不能
写成通过。

## 14. 开发路线：框架冻结后的内容阶段

仓库 M0—M10 已完成框架建设和冻结，原案中从 M0 重建 Unity 工程的路线不再执行。后续建议：

| 阶段 | 目标 | 退出条件 |
|---|---|---|
| G0 方案冻结 | 锁定本文、Demo 内容清单、临时 ID 计划和资产制作清单 | 冲突项有明确决策，未批准 Schema 扩展已识别 |

| G3 Demo 发布候选 | 正式资产、本地化、性能、存档和 Release 合规 | Demo 完成定义全部取得真实证据 |

每次只实现一个明确内容里程碑；不得为了填充路线提前批量创建正式内容。

## 15. 明确不纳入核心范围

- PVP、实时联机、MMORPG 式装备强化和随机词条背包。
- 角色抽卡、体力、每日任务、通行证和付费数值成长。
- 强制在线、多层材料合成和无限宗门建造。
- 开放世界、复杂职业转职、大量主动技能按键和全面 DOTS 化。
- 运行时 AI 生成美术、未经批准的第三方代码或来源不明资产。

## 16. 完整版完成定义

完整版只有同时满足以下条件才可称为完成：
